# 公考助手 小程序 v2 视觉规范（tokens）

> 设计稿：本目录下各 `*.html`（375px 视口，rpx→px 按 2:1，即文中 px ×2 = WXSS rpx）。
> 落地目标：`miniapp-native/miniprogram/app.wxss` 的 design token 全量替换 + 各页 wxss 按组件样式对齐。

## 一、竞品调研结论（粉笔 / 小猿口袋 / 腾讯自选股等）

现代刷题类小程序的共同视觉语言：

1. **沉浸式品牌头部**：首页/我的页顶部用品牌渐变色一直延伸到状态栏后面（自定义导航栏），白色卡片"浮"在渐变上，形成明确的前后层次；而不是白底+彩色小卡。
2. **无边框卡片 + 大圆角 + 低饱和大范围阴影**：卡片不用 1px 边框，靠背景色差（#F5F7FB 底 vs #FFF 卡）+ 柔和阴影分层；主卡圆角 18–24px（36–48rpx）。
3. **数字即主角**：题数/正确率/连续天数等核心数字用超大字重（800）+ tabular-nums 等宽数字，字号是正文的 2–3 倍，配 11px 小灰标签，形成强对比字阶。
4. **一屏一主 CTA**：每屏只有一个渐变主按钮（胶囊形+品牌色投影），其余动作降级为浅底 ghost / 文字链，避免多个实心按钮打架。
5. **功能色系统化**：正确/错误/警示各有「深色文字 + 极浅底色」成对出现（如 #059669 on #E8FAF3），从不用纯色大面积铺底；五大模块各有专属色+浅底，贯穿标签、图表、图标。
6. **激励体系用暖色点缀**：连续打卡/火焰/徽章统一用橙金渐变（#FFD08A→#FF8A3D），与品牌蓝形成冷暖对比，成为页面的情绪焦点。
7. **数据可视化轻量化**：热力图/柱状图/环形进度用品牌色阶（50→700）表达强度，不引入第三方图表库配色；圆角柱、细进度条（6px）+ 大百分比数字。
8. **对齐纪律**：全局统一 16px 页边距、12px 卡片间距、卡内 16px padding，所有间距 4 的倍数；行内元素基线对齐，「›」箭头统一右侧 12–16px。

## 七、组件样式

- **卡片 `.card`**：白底 / r-l(18px) / sh-1 / padding 16 / 间距 12，无边框。
- **主按钮 `.btn-primary`**：`--brand-grad-btn` 渐变 / 胶囊 / 高 48px(96rpx) / 16px 700 白字 / sh-brand。每屏至多一个。
- **次按钮 `.btn-ghost`**：`--brand-50` 底 / 品牌色文字 / 胶囊，无阴影。
- **小操作按钮**（去复习/开考）：品牌浅底 + 品牌色 12px 700 / 胶囊 padding 6×12。
- **标签 `.tag`**：高 20px / r-xs / 11px 600 / 语义或模块浅底+深字。
- **选项 `.opt`**：1.5px 边框（唯一用边框处，默认 `--border`）/ r-m / 字母圆徽章 24px；答对=绿边+绿浅底+实心绿徽章；答错=红系同理；未选降透明度 .5。
- **进度条**：高 6px（hero 8px）/ 全圆角 / `--fill` 底；品牌渐变（学习进度）或橙金渐变（打卡）。
- **图表**：热力图用 brand 50/100/300/500/700 五档；柱状图圆角柱（`--brand-200`，当前项渐变）；环形进度 `conic-gradient`（WXSS 支持）+ 内嵌白圆。
- **判分横幅**：底部悬浮（bottom 12px）/ r-l / sh-2 / 对=绿渐变、错=红渐变 / 白色胶囊次按钮。
- **导航**：首页/我的用沉浸式品牌渐变头（`--brand-grad` 延伸到状态栏），文字白色；内页白底黑字。
- **TabBar**：白底 + 0.5px 上边线 / 图标 22px + 10px 文字 / 选中品牌色。

## 八、落地注意

- 全部效果仅用 WXSS 支持的属性：`linear-gradient` / `conic-gradient` / `box-shadow` / `border-radius`，无 `backdrop-filter`、无复杂 `filter`。
- 深色模式沿用现有 `@media (prefers-color-scheme: dark)` 方案，替换为本文深色列的值。
- 设计稿中的 emoji 图标（📘🔥🏅等）落地时可保留 emoji 或替换 TDesign icon，尺寸/布局不变。
