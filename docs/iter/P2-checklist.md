# P2 改造清单 — 考公刷题/错题助手（kaogong.zalize.com）

> 范围约束：全部可在现有 uni-app Vue3 H5 + FastAPI 架构内实现；不引入注册登录；不做原生 App。
> 优先级：P2a（高）/ P2b（中）/ P2c（低）。每项含：来源/依据（附链接）、改造描述、验收标准、涉及页面。

## A. AI 讲解页展示增强（用户点名的重点方向）

### 1. 答案首屏大卡（Answer-first Card）— P2a
- **来源/依据**：Gauth/Question.AI 的"先给答案+步骤"模式：拍题后首先呈现明确答案，再展开逐步讲解（Gauth 使用指南 https://tecnobits.com/zh-CN/如何使用-Gauth-及其替代方法解答练习题/ 、Question.AI 介绍 https://www.kelifei.com/question-ai.html ）。粉笔解析也是"结论先行、思路拆解在后"（网易评测 https://www.163.com/dy/article/KV0LCH0G0556MU3O.html ）。
- **改造描述**：讲解页顶部固定一张"答案大卡"：正确选项（大号字）、题型标签、一句话核心思路（≤30字）、方法名（如"截位直除"）。流式输出时先由后端在 prompt 中要求模型第一段输出结构化答案块（如 `【答案】B 【方法】截位直除 【一句话】…`），前端解析后渲染成卡片，其余内容继续流式。
- **验收标准**：拍题讲解开始 3 秒内首屏可见答案卡；答案卡在滚动阅读长讲解时吸顶（sticky）；100% 讲解响应能解析出答案块（后端做格式校验与降级）。
- **涉及页面**：拍题讲解页、题库答题后的 AI 讲解页。
### 2. 分步卡片式讲解（Step Cards）— P2a
- **来源/依据**：Gauth"每步标注所执行的操作（如'分离变量''应用公式'）"的逐步讲解（同上 Gauth 链接）；ChatGPT Study Mode 的 step-by-step 引导（https://help.openai.com/en/articles/11780217-study-mode ）；Khanmigo 将问题拆解为更小步骤的做法（https://blog.khanacademy.org/khanmigo-math-computation-and-tutoring-updates/ ）。
- **改造描述**：后端 prompt 约定讲解按 `### 第N步：<动作名>` 输出；前端把 markdown 按步骤切分为独立卡片（编号+动作名标题+内容），卡片间留白，替代现在的整页长文。
- **验收标准**：数量关系/资料分析/判断推理题讲解 ≥90% 呈现为 2~6 张步骤卡；步骤解析失败时优雅降级为原 rich-text 长文。
- **涉及页面**：AI 讲解页。

### 3. 速算/公式高亮块 — P2a
- **来源/依据**：资料分析速算是行测核心痛点，粉笔官方备考资料以"截位直除/化除为乘"等公式块教学（粉笔资讯 https://fenbi.com/page/exam-preparation-material-detail/178/439669137633282 ）；Question.AI"列出公式、说明思路"（链接同上）。
- **改造描述**：讲解中的公式与速算过程用专门样式块渲染：等宽字体、浅色底、左侧色条；prompt 约定用代码块或 `【速算】…` 标记包裹计算过程，前端识别后渲染为"速算块"。
- **验收标准**：含计算的讲解 100% 有独立速算块；速算块内数字不换行错位（移动端 375px 宽下验证）。
- **涉及页面**：AI 讲解页。
### 4. 关键数字/关键词高亮 — P2a
- **来源/依据**：粉笔解析"把题干关键词怎么抓、选项怎么排除拆开讲"被评为新手友好核心（网易评测 https://www.163.com/dy/article/KV0LCH0G0556MU3O.html ）；小红书高赞对比"好解析像一对一私教"（对比评测 https://www.wsisp.com/helps/86424.html ）。
- **改造描述**：prompt 约定用 `==高亮==` 或粗体标记题干关键词与关键数字；前端渲染为荧光笔底色（关键词黄色、数字蓝色单独样式）。题干展示区同步高亮讲解中引用的关键词（前端字符串匹配即可）。
- **验收标准**：讲解中关键数字/关键词有视觉高亮；题干中至少能同步高亮首个关键信息。
- **涉及页面**：AI 讲解页（含题干展示区）。

### 5. 方法标签可点击 → 方法卡片弹层 — P2b
- **来源/依据**：粉笔解析做"考点归纳+考点延伸，便于举一反三"（对比评测 https://www.wsisp.com/helps/86424.html ）；花生十三方法体系本身是结构化方法名集合，适合做成可点击标签。
- **改造描述**：讲解中出现的方法名（截位直除、代入排除、图形规律类别等）渲染为可点击 chip；点击弹出底部抽屉（uni-app popup）展示该方法的简介卡（定义、适用题型、1 个极简示例），内容来自 FastAPI 维护的静态方法库 JSON（一次编写，无 LLM 成本）。
- **验收标准**：方法库覆盖 ≥30 个高频方法名；讲解中命中方法名的自动变为标签；弹层打开 <300ms，不打断讲解阅读位置。
- **涉及页面**：AI 讲解页；可复用到题库解析页。
### 6. 折叠段落：默认收起"背景/延伸"，展开看详情 — P2b
- **来源/依据**：在职考生"通勤/睡前看解析，写太绕直接跳过"的碎片化阅读痛点（网易评测 https://www.163.com/dy/article/KV0LCH0G0556MU3O.html ）；中公被吐槽"解析模板化、太长没重点"（128QR 调查文 https://128qr.com/post/7045.html ）。
- **改造描述**：讲解结构约定为「答案卡+步骤卡（默认展开）+ 错项分析/考点延伸/易错提醒（默认折叠，点击展开）」；折叠区显示标题和一行摘要。
- **验收标准**：讲解页首屏只含答案卡+第一步；折叠段展开状态在返回再进入时保持；折叠不丢失流式输出内容。
- **涉及页面**：AI 讲解页。

### 7. 逐步展开模式（"先想一步"渐进披露，可开关）— P2b
- **来源/依据**：ChatGPT Study Mode 的苏格拉底式"先提示后揭示"（UF 指南 https://businesslibrary.uflib.ufl.edu/chatgpt-quick-start/study-mode 、OpenAI Help https://help.openai.com/en/articles/11780217-study-mode ）；Khanmigo 引导式解题而非直接给答案（链接同上）。
- **改造描述**：讲解页顶部提供"直接看 / 逐步看"开关（本地存储记忆偏好）。逐步模式下步骤卡逐张显示，每张底部"下一步"按钮；答案卡在逐步模式下默认模糊遮罩，点击揭示。纯前端实现（内容已流式拿到，只控制显示）。
- **验收标准**：模式偏好跨会话记住；逐步模式不产生额外 API 调用；错题本复习进入的讲解默认逐步模式。
- **涉及页面**：AI 讲解页、错题本复习流。
### 8. 错项逐一击破区（为什么其他选项不对）— P2b
- **来源/依据**：粉笔解析"不仅说明正确选项，也解释其他选项错在哪里"被列为口碑要点（对比评测 https://www.wsisp.com/helps/86424.html ）；中公被吐槽"解析缺典型错误思维路径"（128QR https://128qr.com/post/7045.html ）。
- **改造描述**：prompt 约定输出 `【错项】A：…` 结构；前端渲染为每个错误选项一行的紧凑列表（选项字母红色圆标+一句话），放入第 6 项的可折叠"错项分析"区。
- **验收标准**：选择题讲解 ≥90% 含全部错项的一句话分析；每条 ≤50 字。
- **涉及页面**：AI 讲解页。

### 9. 讲解页"追问"快捷入口 — P2c
- **来源/依据**：Question.AI"看不懂就追问、同一题可要求不同解法"（https://www.kelifei.com/question-ai.html ）；Gauth 的追问式辅导（链接同上）。
- **改造描述**：讲解底部固定 3 个预设追问 chip："换个方法讲"、"再讲细一点"、"这类题怎么快速识别"，点击即以当前题上下文发起一次追加流式请求，结果追加为新卡片。不做自由聊天（控成本、免登录场景防滥用：按设备指纹限每题 2 次追问）。
- **验收标准**：追问结果 5 秒内开始流式；每题追问次数受限并有友好提示。
- **涉及页面**：AI 讲解页。
## B. 交互优化（减少点击/等待/迷失）

### 10. 流式等待期骨架屏 + 阶段文案 — P2a
- **来源/依据**：华图 App 高频差评"加载慢、解析打不开、心态受影响"（对比评测 https://www.wsisp.com/helps/86424.html 、华图 App Store 评论"会比较慢" https://apps.apple.com/cn/app/id940376535?see-all=reviews ）。
- **改造描述**：拍题上传→OCR→生成的等待期显示分阶段进度（"识别题目中→已识别，正在生成讲解…"），答案卡与步骤卡位置先渲染骨架屏；OCR 完成后立即回显识别出的题干供用户核对（可点"识别有误"重拍）。
- **验收标准**：从拍照确认到首字节渲染期间无白屏；OCR 结果 2 秒内回显；识别有误可一键重拍不回退多级页面。
- **涉及页面**：拍题页、AI 讲解页。
### 11. 答题即时反馈微交互（对/错色彩+触感）— P2b
- **来源/依据**：多邻国答对绿色+鼓励语、答错红色+正确答案的即时多模态反馈被公认为其核心体验（人人都是产品经理拆解 https://www.woshipm.com/evaluating/6323616.html 、UX Planet 分析 https://uxplanet.org/analyzing-duolingo-from-product-design-perspective-after-400-days-of-non-stop-practice-c4d4809bdb37 ）。
- **改造描述**：刷题作答后选项立即着色（绿/红）+轻微缩放动画+`uni.vibrateShort` 触感；底部滑出"对了/错了+正确答案+看讲解"条，替代跳页确认。连对 3/5/10 题给一次性鼓励 toast。
- **验收标准**：作答到反馈 <100ms；反馈条不遮挡题干；连对鼓励不重复打扰（每次刷题会话上限 3 次）。
- **涉及页面**：题库刷题页。

### 12. "背题模式"（题+答案直接连看）— P2b
- **来源/依据**：华图在线"做题/背题模式任意切换"是官方功能特色，用户好评"一道题出来一次答案，马上校对印象更深，适合碎片化"（小米商店介绍 https://app.xiaomi.com/details?id=com.huatu.handheld_huatu 、华图 App Store 评论 https://apps.apple.com/cn/app/id940376535?see-all=reviews ）。
- **改造描述**：刷题设置加"背题模式"开关：题干+正确答案+核心解析一屏直出，上滑切下一题，无作答步骤。错题本也支持背题模式过一遍。
- **验收标准**：背题模式下切题仅需一次滑动；模式偏好本地记忆；背题浏览不污染正确率统计。
- **涉及页面**：题库刷题页、错题本。
### 13. 错因标注一键化 + 按错因复习 — P2b
- **来源/依据**：错题调研显示"73% 错题未标注错误类型（计算错误/概念混淆/审题失误）"是复盘失效主因（128QR 调查文 https://128qr.com/post/7045.html ）；粉笔错题本以"错因标注+同类题推荐"为核心卖点（粉笔错题本解析 http://cnnetsun.cn/a/3562594 ）。
- **改造描述**：现有错因功能前置：答错后的反馈条上直接给 4 个错因 chip（审题不清/方法不会/计算失误/纯蒙的）一键标注，不必进错题本再补；错题本增加"按错因筛选复习"入口，薄弱分析页展示错因分布。
- **验收标准**：答错后标注错因 ≤1 次点击；错因标注率（有标注错题/总错题）可在后台统计并 ≥40%；按错因筛选可直接发起复习。
- **涉及页面**：刷题页、错题本、薄弱分析页。

### 14. 错题"同类题再练 3 道" — P2a
- **来源/依据**：粉笔"同类题推荐（3~5 道同考点、难度相近）+ 错题回顾组合"被学员评为提分最快工具（粉笔错题本解析 http://cnnetsun.cn/a/3562594 ）；对比研究称智能同类推送是粉笔对中公的核心优势（128QR https://128qr.com/post/7045.html ）。
- **改造描述**：讲解页/错题详情页底部加"练 3 道同类题"按钮：FastAPI 按二级题型+难度从 6254 题库中抽 3 题组成迷你练习流，做完回到错题并更新掌握度。纯题库检索实现，零 LLM 成本。
- **验收标准**：同类题与原题二级题型一致率 100%；迷你流做完有小结（3 题对几题+是否建议"斩"）；入口点击一次即开始。
- **涉及页面**：AI 讲解页、错题本详情、刷题结算页。
### 15. 每日 10 题打卡 + 连续天数（streak）— P2b
- **来源/依据**：多邻国 streak/每日目标是其留存核心机制（人人都是产品经理拆解 https://www.woshipm.com/evaluating/6323616.html ）；华图用户"经常没有时间也要登录打个卡"（App Store 评论 https://apps.apple.com/cn/app/id940376535?see-all=reviews ）。现有勋章体系可直接挂接。
- **改造描述**：首页顶部加"今日 10 题"入口（智能组卷：6 新题+2 到期复习错题+2 薄弱题型），完成后显示连续打卡天数火焰图标；数据存现有免登录设备标识下，日历页复用薄弱分析的日历组件。
- **验收标准**：一次点击开始今日 10 题；完成页展示 streak 与最长纪录；断签不清零历史最长纪录。
- **涉及页面**：首页、薄弱分析（日历）。

### 16. 到期复习角标与"今日待复习"直达 — P2b
- **来源/依据**：墨墨/Anki 间隔重复的核心是"到期队列每天清"（墨墨记忆算法研究 https://memodocs.maimemo.com/docs/2021_study/ ）；"错题本只进不出变错题坟墓"的普遍问题（粉笔错题本解析 http://cnnetsun.cn/a/3562594 ）。
- **改造描述**：现有间隔复习到期数在首页 tab/入口以红点角标显示（如"错题本·7"）；点击直达"今日待复习"队列逐题模式（第 7 项的逐步讲解默认开启），完成后角标清零并显示"今日已清"。
- **验收标准**：到期数实时准确；从首页到开始复习 ≤2 次点击；清空后有完成反馈。
- **涉及页面**：首页、错题本。
### 17. 刷题断点续做 — P2c
- **来源/依据**：粉笔"操作路径顺、打开就知道下一步做什么"被评为核心体验优势（网易评测 https://www.163.com/dy/article/KV0LCH0G0556MU3O.html ）；H5 免登录场景下"迷失"成本更高。
- **改造描述**：练习中途退出自动保存进度（本地+服务端设备标识）；再次进入题库页顶部显示"继续上次：资料分析 第8/20题"卡片一键续做。
- **验收标准**：断点恢复准确到题号与已作答记录；续做卡在无断点时不显示。
- **涉及页面**：题库首页、刷题页。

### 18. 讲解页阅读进度与回顶导航 — P2c
- **来源/依据**：移动端长内容阅读的"迷失"问题；粉笔解析"层次清楚"被评为移动端体验优势（网易评测 https://www.163.com/dy/article/KV0LCH0G0556MU3O.html ）。
- **改造描述**：讲解页顶部细进度条显示阅读位置；步骤卡右侧悬浮迷你目录点（第1步/第2步/错项/延伸），点击跳转；流式输出中新增内容时若用户已上滑阅读则不强制滚底，显示"有新内容↓"气泡。
- **验收标准**：流式期间用户上滑后页面不跳动；目录点定位准确；气泡点击回到最新内容。
- **涉及页面**：AI 讲解页。
