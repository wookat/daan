# 轮21 增长线：竞品裂变玩法对标 + 裂变链路 P0 打磨

日期：2026-08-09 ｜ 范围：粉笔 / 华图砖题库 / 腰果公考 / 小猿口算 ｜ 约束：无预算、无支付、H5 优先

## A. 竞品裂变玩法调研（时间盒 2-3h，公开资料）

### A.1 各家玩法盘点

**粉笔（公考头部）**
- 刷题打卡 + 连续打卡天数 + 成就勋章体系（如连续打卡 7 天解锁称号）；打卡里程碑赠资料（连续打卡 N 天送高频考点手册/真题卷）。
- 学习小组 PK：组内成员互相监督、朋友圈打卡模板（含备考进度可视化图）。
- 模考排行榜：全站排名制造竞争与晒分动机。

**华图砖题库**
- 竞技 PK 场（4 人/8 人实时对战）+「我是砖王」单日冠军榜，冠军奖状截图晒朋友圈领奖——**晒奖状/晒成绩截图**是核心传播素材。
- 国考「晒分赢红包」：估分截图 + 转发微博参与，把成绩单变成裂变物料。
- 站点长期挂 PK 场次排行榜（荣誉激励，零成本）。

**腰果公考**
- 每日 Mini 模考（老师人工组卷）+ 排行榜 + 考试倒计时 + 每日做题提醒，强在「每日仪式感」留存钩子；裂变玩法弱，主要靠免费直播课导流。

**小猿口算（跨品类标杆，芥末堆案例拆解）**
- 「邀请 3 位好友注册得实物题卡」阶梯邀请 + 不想邀请可「连续签到 7 天」兜底——**拉新与促活闭环**。
- 口算 PK 随机匹配 + 冲榜，2024 年因「大学生虐小学生」出圈：**低门槛实时对战 + 排行榜本身就是传播事件**。
- 风控严：识别老用户/未注册，防羊毛党。

### A.2 对我们的适配结论（无预算、无支付）

| 玩法 | 来源 | 适配性 | 优先级 |
|---|---|---|---|
| 分享题目「先答后揭示」+ 击败 X% 作答者 | 华图晒分 / 小猿 PK | 已有 share-q 落地页，加击败率即成挑战闭环 | **P0（本轮）** |
| 分享落地页一键组队（邀请码随分享传播） | 小猿邀请阶梯 | 把单题分享转成小队拉新，零成本 | **P0（本轮）** |
| 队内周排行榜 + 卷王标记 | 粉笔小组 PK / 华图砖王 | 面板已有周数据，纯前端聚合 | **P0（本轮）** |
| 小队周战报一键复制（微信群转发物料） | 粉笔朋友圈模板 | 群转发是公考人群主阵地 | **P0（本轮）** |
| 分享文案带模块 +「你能做对吗」挑战语 | 华图/小猿挑战话术 | 纯文案改造 | **P0（本轮）** |
| 连续打卡里程碑徽章（7/30 天）+ 打卡海报晒图 | 粉笔勋章 | 已有打卡海报，补里程碑文案即可 | P1（下轮） |
| 实时/异步 PK 对战入口外露 + 全站 PK 榜 | 华图竞技场 / 小猿 PK | 已有 pk 模块，可把 PK 战绩做成可分享落地页 | P1（下轮） |
| 邀请阶梯奖励（邀 N 人解锁虚拟权益，如专属称号/皮肤） | 小猿题卡 | 无预算下用虚拟荣誉替代实物 | P1（下轮） |
| 邀请返现 / 实物奖励 | 小猿 / 华图红包 | 需预算与支付，不做 | 不适配 |

**核心判断**：我们没有预算做利益型裂变，可复用的是三类零成本机制——①挑战型内容裂变（题目即物料，答完出击败率刺激转发）；②关系型组队裂变（分享链路上处处带邀请码）；③荣誉型排行榜（队内周榜 + 卷王 + 周战报群转发）。本轮 P0 全部围绕「让每一次分享都自带下一次分享的钩子」。

## B. 本轮实现（P0）

### B.1 后端（backend/app/team.py）
- `GET /api/share/{sid}` 与 `POST /api/share/{sid}/answer` 新增：
  - `q_stats`：该题在 answer_log 的全量作答统计 `{total, acc, beat_pct}`（beat_pct=答错人数占比，答对者展示「你击败了 X%」）；仅作答后/分享者可见。
  - `team_invite`：分享者所在小队 `{code, name, n_members}`（优先分享绑定的 team_id，否则最近加入的队；满员不返回），用于落地页「和 TA 组队刷题」一键加入。
- `POST /api/share/create` 返回新增 `module/submodule`，供前端生成带模块钩子的分享文案。
- `/api/track` 事件白名单新增：`share_copy`、`share_team_join`、`team_invite_copy`、`team_report_copy`。

### B.2 H5 前端
- `pkgA/share/share-q`：作答揭示后新增「🏆 你击败了 X% 的作答者」（答错则显示全网正确率 + 再战引导）；新增「和 TA 组队刷题」卡片（一键加入分享者小队，成功后可直达小队面板）；复制分享文案升级为【模块】+「你能做对吗」挑战语；微信内 title 改为「XX 考了你一道XX题，你能做对吗？- 考公助手」。
- `pkgA/team/team`：小队面板新增「本周队内排行」（按本周题数排序，榜首标「卷王」）+「复制周战报」（本周全队 N 题、打卡 M 人天、卷王是谁 + 邀请码/链接，供微信群转发）。
- `pages/team/join`：微信内 title 改为「队友邀请你加入刷题小队，一起打卡冲上岸 - 考公助手」。
- 题卡/错题本「分享给队友」复制文案统一升级为【二级模块】挑战体。
- 埋点：share_copy（source=share_q）、share_team_join（source=share_q）、team_invite_copy / team_report_copy（source=team），全部走既有 `/api/track`。

### B.3 下轮候选（P1）
1. 连续打卡里程碑徽章 + 打卡海报里注入「连续 N 天」荣誉位。
2. PK 战绩分享落地页（战绩卡 + 敢来挑战），复用 share-q 模式。
3. 邀请阶梯虚拟荣誉：邀 3 人入队解锁「小队发起人」称号显示在排行榜。
