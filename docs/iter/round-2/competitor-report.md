## 2. 本轮专项调研 A：「每日一练」最佳实践

### 2.1 竞品做法拆解

| 维度 | 粉笔（每日一练） | 腰果（每日 Mini 模考） | 华图（每日特训） | 一起公考（每日闯关任务） |
|---|---|---|---|---|
| 组卷方式 | 精选组卷 10-15 分钟量级，作为每天学习的「启动仪式」 | **资深老师人工组卷**，每天一套，主打「5 分钟保持手感」；精选历年真题常考点 | 同科目每日可练 5 次，完成首次给成长值 | 每日闯关任务嵌入 AI 路径 |
| 全站同题 | 是（同日所有用户同卷，可比较） | 是 | 否（个人化抽题） | 否 |
| 历史可回看 | 是 | 保留**一周**历史记录 | — | — |
| 完成激励 | 计入打卡/连续天数；学习小队组队完成任务领福利 | 排行榜 + 考试倒计时氛围 | 成长值（可兑图币抵扣购课） | 连对升级、闯关进度 |
| 反馈 | 当日正确率、击败比例 | 得分 + 历史对比 | 成长值到账 | 升级/掉级 |

### 2.2 提炼的设计要点（用于我方 P1-2「今日一练」）

1. **全站同卷是灵魂**：每日一练与普通刷题的差异不在题目，而在「今天大家做同一套题」带来的社会比较（当日正确率分布、击败百分比）。个人化抽题反而稀释仪式感。
2. **短且固定**：5-15 分钟 / 10 题左右，明确告知预计用时；作为「今天学习的第一件事」设计，不承担提分主力。
3. **组卷质量口径**：腰果强调「人工组卷、真题常考点」。我方无人工编辑资源，可用规则替代：按日期种子确定性抽题 + 约束（五模块配比 2/3/1/2/2、真题优先、全站正确率 0.3-0.85 之间、近 90 天未出过）。
4. **历史留存有限期**：保留 7-14 天即可制造「错过不补」的轻度稀缺，同时避免变成第二个题库入口。
5. **与打卡/任务耦合**：完成每日一练自动点亮当天打卡、计入今日计划，是低成本高频召回钩子。

## 3. 本轮专项调研 B：「模考报告深化」最佳实践

### 3.1 竞品报告结构拆解

华图万人模考报告（官方口径）字段：秒出分、全国/全省/圈层排名与百分位、各模块正确率、**用时分析**、强弱项诊断、**与上岸分数的差距**；付费层加：更细能力维度（如「图形推理-对称性」薄弱）、班内排名、进步率排名、错题直接标注「需复习教材第 X 页」。

华图分层排名体系（笔试班公开介绍）：班内 → 同考种/同地域 → 同目标分数段（如「80 分目标组」）三层，并给出「与班级平均分差」「与前 3 名分差」这类**可行动的分差**而不只是名次。

粉笔模考报告与官方复盘方法论（fenbi.com 资讯页）：报告中心按考季聚合历次报告 → 总分曲线；官方明确引导四步复盘：①看总分与排名 → ②看模块（资料是否做完、言语是否超时、数量是否合理取舍）→ ③看错题原因 → ④看申论完成度。核心观点：「排名是体检结果，模块×用时×错因才是处方」。

一起公考：模考记录各模块用时并与全省平均对比。

### 3.2 提炼的设计要点（已并入 spec-01 模考大赛 & 后续 P1-3）

1. **报告 = 排名 + 处方**：竞品共识是排名只做「定位」，报告必须落到「下一步做什么」。我方报告页每个薄弱模块要给一键深链（直达该模块/考点定向练习），复用 plan 任务深链参数族。
2. **用时维度是我方最大缺口**：`answer_log.secs` 与 `exam_attempts` 时间戳已有数据，但报告未展示「每模块用时 vs 建议用时 vs 全场均值」。华图/一起公考都把用时对比作为标配。
3. **分差比名次可行动**：展示「与目标分差 X 分（画像 `target_score` 已采集）」「与全场前 25% 分差 Y 分」，比「第 137 名」更能转化为行动。
4. **趋势聚合**：按「考季/系列」聚合历次模考的总分曲线与模块曲线（粉笔报告中心模式），单场报告尾部给「与上次同系列模考对比」。
5. **秒出分 + 延迟排名**：客观题交卷即出分；排名在场次窗口关闭后冻结定榜，窗口内先显示「实时暂列」，避免早交卷者排名失真（华图为实时排名，随交卷人数变动，考生对此有困惑，我方明示口径更好）。

## 4. 竞品增量盘点（相对轮 1 的新信息）

- 粉笔学习报告为**日报/周报/月报三级**体系：日报微观反思、周报策略调整、月报趋势评估；官方建议「每周日晚 15-20 分钟读周报并制定下周计划」。周报核心指标：模块正确率变化、雷达图形态变化、知识点覆盖度、学习连续性（打卡热力图）。→ 直接支撑 spec-04 周报的结构设计。
- 粉笔知识点覆盖度口径：已练知识点/全部知识点，基础阶段目标 ≥80%；智能推荐优先推**未覆盖**知识点。→ 掌握度地图（spec-02）必须区分「未接触」与「掌握低」两种状态，未接触不是 0 分而是空白格。
- 粉笔模考大赛运营细节（官方 Q&A）：按考季分季运营、往期报告按季聚合查看；联考类模考提供**职位/试卷下拉选择**；错过场次 1 小时后可自行作答但无排名。→ spec-01 采用同口径：「窗口内交卷计排名，窗口后转普通卷」。
- 华图错题本闭环：错因分类 + 考点分布图 + **同类题推送** + 关联精讲 + 错题重练任务化 + 可导出。同类题推送是错题本从「仓库」变「流水线」的关键一步。→ spec-03。
- 一起公考分级练习：L1-L5 连对 5 题升级、逐节解锁地图。掌握度的游戏化表达（等级/解锁）比百分比更有驱动力，spec-02 采用「未接触/入门/巩固/熟练/精通」五档色阶。
