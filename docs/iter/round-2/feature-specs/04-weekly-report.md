# Spec 04 · 周学习报告

对应轮 1 P0-4。竞品参照：粉笔日报/周报/月报三级报告体系（周报=策略调整层：模块正确率变化、雷达形态、覆盖度、连续性；官方引导「周日晚 15-20 分钟读周报定下周计划」）、华图模考后 1 小时报告的「报告→直达练习」转化。

## 1. 产品定义

每周一 0 点（东八区）起可查看「上周学习报告」：一页式回顾 + 可分享图 + 下周行动任务深链。定位是**留存钩子 + 行动转化器**：把已有统计数据转化为「下周做什么」，而不是第二个统计页。

- 生成方式：**惰性即时计算**（首次访问按周窗口聚合并落缓存表），无 cron 依赖；数据全部来自现有表（answer_log / review_log / exam_attempts / mistakes / 打卡口径），无新增埋点。
- 周口径：`insights._week_start()` 周一 0 点，报告覆盖 [上周一, 本周一)。
- 触达：首页周报卡（周一~周三显示未读态）；学习提醒周一首触发时带「周报已生成」文案。

## 2. 报告内容区块（页面 `pkgA/stats/weekly-report.vue`，新）

```
1. 头部：第 N 周（date range）· 学习 x 天 · 共 y 题 · 正确率 z%（环比 ↑↓）
2. 亮点徽章（规则命中即发，最多 3 枚）：
   「连续 7 天」「正确率新高」「模考完成」「掌握度晋级 x 个考点」…
3. 本周 vs 上周：题量/正确率/用时 三组环比条
4. 掌握度变化 Top3：晋级考点（↑巩固→熟练）与退步考点（久未练衰减）
   —— 调 spec-02 mastery_snapshot 本周末 vs 上周末两个时点
5. 错因分布：本周错题四类错因占比 + 环比（自评数据已有）
6. 模考回顾：本周模考得分与百分位（无则显示「本周未模考」+ 下周场次预告，联动 spec-01）
7. 下周建议（行动区，plan 引擎生成）：
   - 「继续清错题：到期 x 道」→ review 深链
   - 「主攻 XX 考点」→ tag3 定向练深链（取 mastery 最低前 2）
   - 「周六模考大赛第 N 期」→ 场次页深链
8. [生成分享图] —— 复用打卡海报管线（RepaintBoundary/canvas 同链路），
   模板：周数据大字 + 亮点徽章 + 品牌码
```

## 3. 数据模型

```sql
CREATE TABLE IF NOT EXISTS weekly_reports (
    uid TEXT NOT NULL,
    week_start REAL NOT NULL,         -- 周一 0 点时间戳（东八区口径）
    payload TEXT NOT NULL,            -- 报告 JSON 快照（含掌握度两时点对比）
    created_at REAL NOT NULL,
    read_at REAL,                     -- 未读态控制
    PRIMARY KEY (uid, week_start)
);
```

- 快照化原因：掌握度「上周末时点」值依赖时间衰减，事后重算会漂移；首次生成即冻结，保证用户两次打开看到同一份报告。
- 保留最近 12 周，超期惰性清理。

## 4. API 草案（新文件 `backend/app/report.py`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/report/weekly?uid=&week=` | week 缺省=上周。存在快照直接返回；否则聚合生成→落表→返回。上周无任何学习行为时返回 `{status:"empty"}`（前端显示轻空态+开练入口） |
| GET | `/api/report/weekly/list?uid=` | 近 12 周报告索引（周起止、题量、正确率、未读标记），入口页历史列表 |
| POST | `/api/report/weekly/read` | body `{uid, week}`；标记已读（消首页红点） |

聚合实现要点：
- 题量/正确率/用时：answer_log 按周窗口 SUM；环比取前一周同口径。
- 学习天数/连续性：answer_log+review_log 按日去重（与打卡口径一致）。
- 掌握度对比：`mastery_snapshot` 增加 `as_of` 参数（只统计 created_at < as_of 的作答，衰减基准也用 as_of），分别以本周一 0 点 / 上周一 0 点调两次取 diff。
- 下周建议：直接调 `plan.today_plan` 的弱项/到期错题分量拼装，不另造口径。

## 5. 验收标准

1. 周一 0 点后访问即可看到上周报告；同一周内多次访问内容完全一致（快照生效）。
2. 8 个区块齐全；上周零行为用户显示空态而非全 0 报告。
3. 环比箭头方向与手工核算一致；掌握度 Top3 的「晋级/退步」与 spec-02 档位定义一致。
4. 行动区 3 类深链均可点击直达（review / tag3 练习 / 模考场次），无模考场次时该行降级隐藏。
5. 首页周报卡：周一~周三且未读时显示红点，读后消失（read 接口生效）。
6. 分享图生成成功（H5 canvas / 小程序保存相册 / Flutter share_plus 三端各自现有链路），含周核心数据。
7. 生成接口 P95 < 800ms（含两次 mastery_snapshot）；weekly_reports 超 12 周记录被清理。
8. 小程序构建通过；`docs/parity-matrix.md` 增补该页三端行。
