# Spec 02 · 考点掌握度地图

对应轮 1 P0-2。竞品参照：粉笔知识图谱/能力评估报告（覆盖度口径：基础期已练考点 ≥80%，推荐优先未覆盖考点）、华图考点掌握率（与均值对比）、一起公考逐节解锁地图（游戏化档位）。

## 1. 产品定义

把 `recommend_stats` 内部的弱项评分产品化为用户可见的「掌握度地图」：**模块 → 二级题型 → 三级考点(tag3)** 三级树，每个节点一个掌握度档位色块，点击直达定向练习。核心原则：

- **与推荐引擎单一口径**：掌握度函数与 `db._score_skill` 共用平滑正确率 + 时间衰减分量，避免「地图说熟练、推荐说薄弱」的双口径打架。
- **「未接触」≠「掌握 0%」**：无作答记录的考点显示空白格（灰色虚线），并单独给出「考点覆盖度 x%」指标（粉笔口径）；这也是推荐引擎后续「优先未覆盖」的数据基础。
- 现有统计页已有「考点地图（二级题型掌握度矩阵）」（parity-matrix §5），本 spec 是其升级：下钻到 tag3 + 统一口径 + 五档色阶 + 覆盖度。

## 2. 掌握度口径（公共函数，spec-03/04 复用）

新增 `db.mastery_snapshot(uid) -> dict`：

```
对每个 (module, submodule, tag3) 技能点（聚合规则与 recommend_stats 相同：
tag3 作答 < TAG3_MIN_N 归入二级题型）：
  acc_s   = 贝叶斯平滑正确率 (c + 12*0.55) / (n + 12)        # insights._smooth 同参
  decay   = 0.5 ** (days_since_last_answer / 30)             # 30 天半衰
  mastery = acc_s * (0.6 + 0.4 * decay)                      # 久不练最多打 6 折
  level   = 未接触(n==0) / 入门[0,0.55) / 巩固[0.55,0.7) / 熟练[0.7,0.85) / 精通[0.85,1]
返回：{coverage: {practiced, total, pct}, modules: [{module, name, mastery, levels…,
      subs: [{submodule, mastery, level, n, acc, tag3s: [{code, name, mastery, level, n, due_mistakes}]}]}]}
```

- 考点总数与名称来自 `taxonomy.topic_index()`；各考点题量参考 `db.tag3_counts()`（题库为 0 的考点不进地图）。
- `due_mistakes`：该考点当前到期错题数（join mistakes），地图上叠加小红点，衔接 spec-03。
- 性能：单用户 answer_log 全量一次扫描内存聚合（与 recommend_stats 同量级）；接口加 60s 内存缓存即可，不建物化表。

## 3. 页面结构（H5）

### 3.1 入口

- 统计页现有「考点地图」卡升级为新版（入口文案「考点掌握度地图」+ 覆盖度环形进度）。
- 首页今日计划弱项任务的 sub 文案尾部加「查看地图 ›」。

### 3.2 地图页 `pkgA/stats/mastery-map.vue`（新）

```
┌ 头部：覆盖度环(已练 x/y 考点) + 五档图例 ┐
├ 模块 tab（资料/数量/言语/判断/常识）      │
│ ┌ 二级题型分组卡 ────────────────┐        │
│ │ 片段阅读  mastery 72% ●熟练    │        │
│ │ ├ tag3 色块网格（每格：考点名+  │        │
│ │ │  档位色 + 到期错题红点）      │        │
│ │ └ 未接触考点=灰虚线格           │        │
│ └───────────────────────────────┘        │
├ 底部吸底条（选中考点时）：                 │
│ 「XX考点 · 巩固 · 做过 n 题 acc x%」       │
│ [定向练 10 题] [复习该考点错题(m)]         │
└──────────────────────────────────────────┘
```

- 色阶：未接触 `#E5E7EB` 虚线 / 入门 `#F87171` / 巩固 `#FBBF24` / 熟练 `#34D399` / 精通 `#059669`（与设计线 tokens 对齐时以 design-benchmark 为准）。
- 定向练深链：`/pages/practice/practice?module=..&submodule=..&tag3=..&count=10`（tag3 取题链路 B6 已贯通）。
- 空态（作答 <30 题）：显示地图骨架 + 「再做 x 题解锁掌握度」，与 `api_predict` 冷启动口径一致（COLD_START_N=30）。

## 4. API 草案

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/mastery/map?uid=` | §2 的 mastery_snapshot 全量（按模块组织） |
| GET | `/api/mastery/topic?uid=&tag3=` | 单考点详情：近 20 次作答序列、trend、到期错题列表、同考点可练新题数（供吸底条与 spec-03 复用） |

实现位置：聚合函数在 `db.py`，路由并入 `insights.py`（同为洞察类只读接口）。

## 5. 验收标准

1. 地图页三级下钻完整：模块 tab → 二级题型卡 → tag3 色块；档位与 §2 公式一致（抽 3 个考点手工核算）。
2. 覆盖度 = 有作答记录的 tag3 数 / 题库有题的 tag3 总数，与头部环形一致。
3. 未接触考点显示灰虚线格且不参与模块均值计算；点击也可直接开练。
4. 色块点击 → 吸底条 → 「定向练 10 题」进入练习页且题目 tag3 匹配；「复习该考点错题」仅在 due>0 时显示。
5. 同一考点在地图与首页弱项推荐中的强弱结论方向一致（口径共用验证：推荐 Top1 弱项在地图上必为入门/巩固档）。
6. 作答 <30 题时展示冷启动空态；接口 P95 < 300ms（13 万题库、单用户万级 answer_log 下）。
7. 小程序构建通过；`docs/parity-matrix.md` §5 更新该行。
