## 2. 被拒发现与理由（11 条）

1. 「H5 UTC 日键 / 背题模式底部留白 / 首页 11万+ 文案」——PR #561（R356，生产 rev ≥7a9bb2f）已完成；本轮 home.vue / stats.vue / reminder 不再改动，仅 home.vue 之外的口径残留另立 W2-B。
2. 「hs 自检词表含数据矛盾 / 伪中文 yanyu 批次」——PR #559（C1b）已完成并生产 apply（yanyu 18294、ziliao 4698 与本轮实测一致）。
3. 「复习会话恢复 / 首页续卡 / review_cur 等功能缺失或 404」——属 PR #558 旧基线覆盖回退窗口内的过期取证，R355（PR #560）已恢复，origin/main 上功能存在；本轮生产未复测到缺失。
4. 「模考大赛每周场次可能断档」——`mock_event.api_events` 每次 GET 先 `ensure_weekly_event()` 兜底建当周场次，past 仅返回当前 uid 参与过的往期，匿名 past=[] 属设计；生产 next=第 3 期正常。
5. 「注册验证码桩恒通过」作为本轮代码缺陷——`auth.py` 注释明示为资源缺口桩，修复依赖外部短信凭证 → 转 deferred 资源申请。
6. 「hs 模板腔」作为 P1 批量改写项——250 条抽样中真正的管线元句仅 1 条（已并入 W2-A 剥离规则），其余「确认答案为X。」类为花生体系风格收尾（199/250），非可信度缺陷；不立 LLM 重写项。
7. 「hs 英文残留」——非 yanyu 模块抽样 200 条 0 命中；yanyu 英文多为题干本身外语词，无证据。
8. 「首访 60 秒等待」——W2 走查未复现，无新证据，保留 backlog 观察项。
9. 竞品宣传题量 / 媒体数字——不是本产品缺陷的一手证据，仅作口径对齐参考。
10. 「小程序 25 分钟 / navigationBarTextStyle」类视觉发现——源码 grep 无对应硬编码且报告自述开发者工具可能加载旧 .js 产物，无法复现。
11. Linux Chrome 下字体 / emoji 渲染差异——缺真机证据，不能定为缺陷。
