## 3. 方案与实施（W15-H1，`368ac416`）

### 3.1 请求层 `frontend-uni/src/api.js` + 新增 `frontend-uni/src/api-get-cache.js`
- `createGetCache()`：`inflight: Map<key, Promise>`（settle 后删）+ `fresh: Map<key,{t,d}>`（TTL 命中直接 resolve）+ `gen` 世代号（`clear()` 后在途请求完成不再回写缓存）；uid 变化整体作废。
- `getTtl(path)`：在既有 `snapCacheable` 白名单之上再收窄 `READ_ONLY` 正则（`home_bundle|growth|daily_plan|plan/*|today|predict|checkin/*|summary|stats|profile|announcement|question_counts|daily_set|recommend|mastery/map|shenlun/stats|exam/attempts`，均经 backend 源码核对为纯 SELECT），默认 3000 ms；`questions/*`、`*/resume`、`review*` 只做 in-flight 合并**不缓存**（ttl=0）。
- `request()` 接线（`api.js:324-345`）：非 GET 且非 `/api/track` → `getCache.clear()` 后走原 `withAuthRetry(rawRequest)`；`/api/track` 埋点例外（只写 events 表，若清缓存会把每次切 tab 的缓存打掉）；带 `opts.timeout` 的 GET 不进合并层；GET key = `path`（有 `opts.data` 时 `path#JSON`）。12s→20s 超时重试、`guardStaleUid`、`snapSave`、24h 快照回退顺序与原实现一致，未引入依赖。
- 有意不做：TTL 不放宽到 >3s、不缓存非幂等端点、不改 practice/home/book 页面层（见 §4 请求计数与 §6 遗留）。

### 3.2 `</style>` 外孤儿 CSS 三文件
- `pkgA/exam/exam.vue`：`.multi-tip` 搬回 `<style scoped>` 并 token 化（`--fs-caption/--brand-text/--brand-soft/--r-xs/--sp-*`）。
