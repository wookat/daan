### 2.3 抽题分发互斥——最简实现（不加列）

现状：`db.random_questions` 的 `_pick_pools/_draw` 只按 module/submodule/tag3/year/region/disabled/近期 answer_log 过滤，再按 `is_real×has_hs` 分层；`grouped_ziliao_questions` 用 `_ZILIAO_HASHES_SQL` 按 `material_hash` 随机取组。两条路径都没有「同族/同克隆键只出一题」的约束。

方案 A（推荐，零 schema）：**只读视图 + 会话内去重键**
1. 在 `db.py` 建 `CREATE VIEW IF NOT EXISTS v_question_family AS SELECT id, module, CASE module WHEN 'ziliao' THEN material_hash ELSE <clone_key 表达式> END AS fam FROM questions WHERE disabled=0`。`clone_key` 表达式复用 W13 `quality.clone_key`（数字→`#`、实体词→`*`、去标点后取前 40 字）；SQLite 表达式做不了正则时改为 W13 dry-run 脚本把 `clone_key` 写进已有 `tag` 字段（前缀 `fam:`），仍不加列。
