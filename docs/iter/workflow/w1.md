## 2. 被拒发现与理由（7 条）

1. 「limit<=0 进入 SQLite LIMIT -1 不限行」：生产实测 `/api/questions?limit=0` → 1 条、`limit=-5` → 1 条、`limit=1000` → 50 条、`limit=abc` → 422；qbank_api 各分支 min/max 钳制。未复现。
2. 「hs 正文选项字母与 answer 矛盾（P1）」：全库扫描在线 113105 条 hs 中 90887 条以「确认答案为X」结尾，与 answer 不一致 0 条。未复现。
3. 「H5 practice.vue 解析态结果条遮挡正文」：`practice.vue:2328/2499` 已有 `.wrap.has-banner{padding-bottom:…}` 且 `:2` 绑定 picked，普通作答态不成立；仅背题模式漏绑 → 降为 deferred H5 一行修。
4. 「H5 403 账号失效锁死」：R39 已修（`api.js:253`），生产 bundle 为该版本；仅小程序仍存在 → 并入 M1。
5. 「badges.streak 与 summary.streak 算法矛盾」：两接口同用 CN_DAY_SQL + 同一算法，差异仅 summary 计入 review_log → 作为口径统一并入 B1。
6. 「explanation OCR 符号乱码、断字（P1）」：全库扫描 □/�/|| 等常见 OCR 残留在线 0 命中；报告未给 id。
7. 「quality_score/disabled 未拦截问题内容」作为独立缺陷：quality_score 按设计只服务 admin 排序（`db.py:1740-1749`），闸门是 disabled；问题实质是内容未被禁用，已在 C1 通过 disabled 处理。

## 3. 方案（三个文件互斥工作项）
