## 2. 被拒发现与理由（8 条）

1. 「超大整数参数 500（OverflowError）」—— 并行 R511（`0c532532`）已在 main.py 挂同一 400/404 处理器并上线，生产 `/api/exam/papers?year=99999999999999999999` 等实测 400；不重复立项。
2. 「小程序 practice 深链解析 count 不解析 n」—— 全仓 grep 所有 `practice?` 生产者无一产出 `n=`，H5 同样只读 count；无生产者即无缺陷。
3. 「kg-card `.kg-card + .kg-card` 兄弟边距泄漏进 grid」—— 生产 1440 `/pkgA/exam/list` 四张卡 marginTop 均 0（list.vue 已页面级覆盖）；未找到可复现组件级问题，favorites 网格转 deferred 待数据截图。
4. 「小程序 navbar 标题省略号不生效」—— `.nav-title` 已有 `min-width:0; overflow:hidden; text-overflow:ellipsis; white-space:nowrap`，flex 子项默认 shrink:1；源码级不成立且无运行时截图。
5. 「`_ensure_*` 懒迁移每请求 CREATE TABLE 为 P0/P1」—— W3 台账已登记 P3 待量化，本轮无新证据；唯一确定性问题（新库无 correct_ratio）缩为 W9-A 一行修。
6. 「解析重复模板/机器味应立项清洗」—— W2/W3 台账已判「先统计」；本轮无新频次统计，结论字母冲突仅 ≈1‰，不构成批量清洗依据。
7. 「H5 weak-module 与 buildPaceRows 一起坏」—— paceRows 已由 W3-B 读 answered，范围收窄到 weakModule/modules()（W9-B(3)）。
8. 「其他 body:dict 端点也可表单绕过」—— FastAPI 对 `body: dict` 在非 JSON Content-Type 下 422，逐文件核实只有 push_api 用裸 `await request.json()`。

## 3. 方案（三个文件互斥工作项）

### W9-A backend（P1）
1. `push_api.py`：两端点改 `def (body: dict)`（非 JSON Content-Type → FastAPI 422；同步 def 走线程池），subscribe 内显式 `auth.owns_uid(uid, authorization)` 不通过 → 403「无权访问该账号数据，请重新登录」；unsubscribe 仍只按 endpoint 删。
2. `main.py guard_account_uid`：`await run_in_threadpool(auth.owns_uid, ...)`。
3. `exam_api.py api_scan_sheet`：owns_uid 与 `omr.recognize` 均 `run_in_threadpool`。
4. `db.py init_db`：建 `idx_q_reinforce` 前调用既有 `_ensure_question_stat_cols(conn)`。
5. `quality.py`：`answer_letter_conflict(row)` 只取 explanation/hs_explanation **最后一处**结论式措辞（故选/因此选择/正确答案为/所以 X 项当选…）的字母与 answer 比较，仅单选 `^[A-D]$` 判定；「排除 A、B」「若选 A 则…」中间句不入；`PENALTY_ANSWER_CONFLICT=30` 只降分不下线。
- 不新增表/实体、不改契约。

### W9-B frontend-h5（P1）
1. `App.vue` 768 段 `padding-left:208px` 与 `.banner/.mask left:208px` 改为仅 `uni-page[type="tabBar"] …`；1280/1366 壳段 fixed 元素拆为「壳边基线 calc」+「tab 页 +208px」两条；不引入 JS，不改 `.uni-tabbar` 侧栏与桌面 label 15px。
2. `pages.json tabBar` 增 `"fontSize":"12px"`，高度保持 50。
3. `exam-weak.js`：过滤/判定按 `answered`（缺省回落 n），正确率 `ansPct → correct/answered → pct` 三级回落，`answered=0` 或 `<3` 永不判薄弱，兜底文案 answered<n 时附「（按已答 a/n 题折算）」；`report.vue modules()` 增 `answered`/`ansPct`。
4. `a11y-focus.js` 焦点环 `#2e5bff → var(--brand)`。

### W9-C miniapp（P2）
1. `kg-exam-report.ts`：`ModuleRow` 增 `answered?/ansPct?`，`judgePct()` 与 H5 同规则；`report.ts` modules 映射补 `answered`/`ansPct`。
2. `api/index.ts postPracticeResult` data 增 `uid: anonUid()`。
3. `profile.ts` 抽 `refresh()` 供 onShow/onLogout 共用，退出后先清角标再按匿名 uid 重拉。
4. `git rm utils/exam-progress.ts`。
