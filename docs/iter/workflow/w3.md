## 2. 被拒发现与理由（8 条）

1. X-Kg-Ip 可伪造/边缘绕过 —— 误报。`kaogong-origin.zalize.com` 直连无 X-Kg-Edge 密钥回 403（实测）；`deploy/cf-pages/functions/[[path]].js:180-181` 用 CF-Connecting-IP `headers.set` 覆盖客户端自带的 X-Kg-Ip。
2. SEO 页脚仍「13万+行测真题」—— 误报。带 nocache 参数请求 `/tiku/q/235535` 已是「10万+ 行测题 · 1.5万+ 历年真题」，之前旧值为 CF 300s 边缘缓存。
3. W2 相关生产缺陷（mistakes question_id 数组 500、profile/rate 非法参数 500、小程序连签本地覆盖、模考加载无错误态、page-scroll 高度）—— 已完成。生产 rev e58779f 含 #564，实测三接口均 400「参数格式错误」；`app.wxss:68-71` 已加 page 高度约束；连签/错误态在 W2-C e3e871f。
4. 小程序 saveWrong 把选项拼进 question_text —— 非缺陷。H5 `practice.vue:1180/1195/2130/2149` 同一口径，后端按 uid+question_text 合并依赖此格式。
5. 小程序 navbar `position:relative` 非 fixed —— 非缺陷。自定义导航栏在正常流 + scroll-view flex:1 是有意布局（沉浸式 hero-bleed 依赖），无遮挡证据。
6. `/api/rate` 缺参 500 —— 已完成（W2 ValueError 处理器生效，生产 question_id=abc 回 400）；本轮只保留「无限速」子项。
7. H5 模考报告按钮 gap 16rpx 过密、报告页/统计页纯视觉微调 —— 证据不足（无截图对比稿与设计规范依据，W2-B 已做一轮 UI 清理）。
