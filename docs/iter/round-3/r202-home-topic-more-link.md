# R202：首页考点截断补「全部考点」入口

## 取证（2026-08-29，生产一手）

- `/tiku/` 首页每模块「按考点刷题」标签列表截断 `topic_links[:12]`（seo.py L293），
  数量关系 56 个有题考点只展示 12 个，且截断处**无任何「更多」入口**。
- R201 后模块 hub 页（`/tiku/{module}/`）已有全量考点卡，但首页截断列表与其之间
  没有显式引导——用户/爬虫在首页看到 12 个考点后无从得知还有 44 个（只能靠模块
  标题链接间接进入）。
- 生产复核：`curl /tiku/ | grep -o '更多\|查看全部'` 零命中。

## 方案

- 首页每模块考点标签被截断时（`len(topic_links) > 12`），在标签列表尾部追加
  `<a href="/tiku/{module}/">全部 {N} 个考点 →</a>` 链至 R201 模块 hub 全量考点卡。
- 不截断（≤12）时不加，避免冗余链接。
- 不动：截断阈值 12、模块 hub/考点/年份页渲染、路由/canonical/sitemap/JSON-LD。

## 验证计划

- pytest：首页含「全部 N 个考点」链接且 href 指向模块 hub；≤12 考点模块不出现。
- 部署后生产复验五模块入口 + 1440/375 溢出/console + R196 性能预算。
