## 2. 社交栏（练习页/错题卡下方 `q-social-bar`）P2 收口

R410 审计遗留：「📝 写笔记 / 💬 讨论 / 🔗 分享给队友」文字链高度 ≈17px（`text` 行高即热区），笔记编辑「取消/删除笔记/保存」同形态；热评 tag/昵称/点赞 21–22rpx、抢首评 23rpx（375 下 <12px）。

改法（只改该组件样式，不改结构/事件）：
- `.qsb-link` / `.nop`：`min-height:40px; display:inline-flex; align-items:center; padding:0 8rpx; margin:0/-6px -8rpx`——热区 ≥40px，负外边距抵消横向内边距使视觉起点不变；`.qsb-row` 允许换行、行间距 `margin-top` 14→8rpx 补偿高度增长。
- `.edit`（我的笔记「改」）：`padding:8px 8rpx` + 负纵向外边距。
- 组件内全部 20–23rpx 字号 → 24rpx（同 R411 口径）。
