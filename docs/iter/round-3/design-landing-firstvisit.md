# R4 设计方案：新访客价值主张首屏（P1-4 未登录落地页）

日期：2026-08-29 ｜ 轮次：本会话第 4 轮 ｜ 对应差距：competitor-audit.md P1-4

## 差距回顾（一手证据）

- 粉笔 fenbi.com/page/home 为完整营销首页（考试品类导航、考试日历、题库/课程/APP 下载入口），未登录访客到达即可理解产品价值（2026-08-29 实测抓取正文确认）。
- 我方根路径直接进 H5 应用「首页」tab：新访客首屏是「今日已练 0/20 题」目标卡 + 空任务列表，没有任何「这是什么产品、为什么用」的表达（生产实测）。
- /tiku/ SEO 页族已有「进入刷题主站 →」「在线刷 XX 年真题（免费）→」CTA（seo.py L215/L375 实测确认），回流链路存在——缺口只在根路径首屏本身。

## 架构决策

1. **不做独立营销路由**：产品免注册、匿名 uid 即用，「未登录落地页」在本产品语义 = 「无练习历史的新访客首屏」。在 SPA 首页 tab 顶部渲染一块价值主张 hero，避免新增 SSR 路由 + CF Functions 代理配置 + 双首页维护成本；SEO 获客继续由既有 /tiku/ SSR 页族承担（其本身已是完整落地页集群）。
2. **触发条件纯本地判断**：`pstats.days` 无任何作答记录 且 未手动关闭（`landingHide` storage 标记）。一旦开始练习或点 ✕ 永久隐藏，不打扰老用户。
3. **零新依赖、零新接口**：静态文案 + 既有跳转（startDaily / /tiku/ 链接）。

## 页面结构与交互

新访客首屏块（插在 toprow 之后、既有 hero 之前）：

- 主标题：免费刷 11万+ 行测真题
- 副标题：拍题 AI 讲解 · 错题本按遗忘曲线复习 · 迷你模考 —— 免注册，打开即练
- 功能亮点 2×2 网格（≥1024px 一行 4 列）：
  1. 11万+ 真题题库（五大模块 · 三级考点）
  2. AI 拍题讲解（花生十三方法体系）
  3. 智能错题本（遗忘曲线复习 + 掌握度）
  4. 迷你模考（判分报告 + 错题自动入本）
- 主 CTA「免注册立即开练 ›」→ startDaily()；副 CTA「浏览题库」→ /tiku/（H5 同窗跳转）
- 右上 ✕ 关闭 → `landingHide=1` 永久隐藏

## 验收标准

- 构建通过（npm run build:h5）；后端无改动
- 生产 1440/375：清空 storage 的新访客可见 hero，文案/网格/CTA 正常；点「浏览题库」到 /tiku/；点 ✕ 后刷新不再出现；老用户（有 pstats）不可见
- 无横向溢出、console 0 error
