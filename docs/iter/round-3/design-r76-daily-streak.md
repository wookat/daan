# R76 设计：每日一练连续参与天数（streak）

## 取证（2026-08-31）

- 竞品对照：粉笔每日一练有「连续打卡 N 天」外显（打卡日历+连续天数），是每日题最核心的留存钩子；我站 R69–R74 已补齐同题/参与数/击败百分比/排行榜/昵称，唯独没有跨日留存激励——完成页只呈现当日成绩，用户没有「明天再来守住连续」的理由。
- 现状代码：`daily_set_entries(day, uid)` 主键天然是逐日参与记录，可直接推导连续天数，零新表；首页已有本地 dailyStreak（按本地 dailyPlan 打卡），但那是「刷题目标」维度且仅存本机，换设备即丢，与全站同题参与无关。

## 方案

1. db.py `daily_set_submit` 返回值补 `streak`：查该 uid 最近 60 天参与日集合，从今天往前逐日数连续（当天刚提交必 ≥1）；重复提交同样返回当前 streak（幂等语义不变）。
2. practice.vue 完成页 dsbeat 行追加「已连续参与 N 天」（N≥2 才显示，首日不噪）；daily 分享文案在 N≥2 时追加「连续 N 天」。
3. 不加表、不加接口、不动排行榜/SSR。

## 非目标

- 不做打卡日历 UI、不做断签提醒推送、不回填奖励体系（后续轮候选）。

## 验收

- 本地临时库：单日=1、连续两日=2、隔一天断签=1、重复提交不变；
- 生产真实作答：完成页 streak 展示正确（新 uid 首日不显示），测试 entries 清理，保护 uid 零 mutation；
- 1440/375 无溢出、console 0 error。
