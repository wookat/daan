# R81 设计：完成页「登录保进度」引导（注册转化漏斗）

## 取证（2026-08-31 生产）

- 30 天 94 个匿名活跃 uid、≥20 题重度用户 14 个，但注册用户共 14、30 天 register 事件仅 1 次。
- 匿名 uid 存 localStorage，清缓存/换设备即全部进度丢失；`mergeAnon` 登录合并链路已存在（login.vue），承诺「不丢进度」为真。
- 全站唯一登录入口在「我的」页账户 cell；home/practice（练习主闭环）零登录引导。竞品（粉笔/夸克）强制或强引导登录。

## 方案

- practice 完成页（session 完成态）追加一次性可关闭引导卡：仅当 `!isLoggedIn()` 且本地累计答题 ≥30 且未被关闭过时显示——「已累计刷 N 题 · 登录后云同步，换设备/清缓存不丢进度」+「登录保进度」按钮跳 /pkgA/user/login，右上 ✕ 关闭（storage `loginNudgeDismissed`，永久）。
- 埋点：`login_nudge_show` / `login_nudge_click` 入 api_track 白名单（后端仅白名单 2 行）。
- 阈值 30 取重度分界（≥20 题即 top 14/94，30 略高避免打扰浅度用户）。

## 非目标

- 不做强制登录、不做弹窗打断；不改「我的」页既有入口；不做首页常驻 banner（完成页情绪高点更合适，先小范围验证漏斗）。

## 验收

- 匿名 uid 累计 ≥30 题后完成一组 → 完成页出现引导卡，点按钮进登录页；✕ 关闭后再完成一组不再出现；登录态永不出现。
- 1440/375 无溢出、console 0 error；埋点 200 落库；测试数据清理、保护 uid 零 mutation。
