## 4. 取证 3：等号/运算符位缺式不是孤例

### 4.1 宽扫→收窄（先论证后写码）
- 宽规则（单位后接句读、比例词后接句读、连续标点等）：数量/资料两模块 56,848 行里活跃并集 **5,498**——大量正常表达（「…元，」「约为，」）和标点习惯混入，直接否决。
- 收窄为「运算符本身撞上句读/括号」：
  - `[＝=][，。；]`：「解得 x=。」「速度为＝60」前一半、「＝21」
  - `[，。；：（][＝=]`：「：＝21」「。＝25（米）」「，=1.428」

  - `[（(][^）)]{0,3}[×÷＋+－＝=][）)]`：「（1－）」
  - `[，。；][，；]|[，；]。`：「）。，」「，。」——排除 `。。`（R400 已证 261638 是笔误，本轮复读 261638/273655 仍为完整正文）
