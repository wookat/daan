# Round-3 设计方案：错题本桌面操作台（P0-1）

## 目标

≥1024px 视口下，错题本从 680px 单列手机流升级为双栏工作台，对齐粉笔 Web 桌面级信息密度；≤1023px（含 375px）保持现有单列布局与顺序完全不变。

## 架构决策

- 不引入新页面/新路由：仍是 `frontend-uni/src/pages/book/book.vue` 一套 DOM，多端（H5/小程序/App）共用；桌面布局仅用 H5 条件编译的 CSS 实现，避免多端回归风险。
- 布局机制：列表模式根节点内将现有块划入 `book-main`（分区 tab、搜索、错题卡列表、空态）与 `book-side`(统计卡、今日复习、本月复盘、AI 分析、错题重练、收藏入口、模块导航) 两个容器；两容器在移动端 `display: contents`（DOM 顺序即现有顺序，零视觉变化），在 H5 ≥1024px 变为 CSS grid 两列。
- App.vue 的 680px 限宽对 book 页在 ≥1024px 放宽到 1080px（仅 H5 media query，作用域限定 book 页 class，不影响其他页面）。
- 复习模式（reviewing）不分栏：单列居中（阅读态），仅加宽到 760px。

## 页面结构（≥1024px）

```
┌──────────────────────── 1080px ────────────────────────┐
│ main (1fr, ~660px)              │ side (360px, sticky)  │
│ ┌ 今日待复习横幅（跨两栏顶部） ┐ │                       │
│ │ 待掌握/已掌握/收藏 tab+筛选  │ │ 统计卡(3格)           │
│ │ 搜索栏                       │ │ AI 错题分析           │
│ │ 错题卡列表 + 分页            │ │ 错题重练              │
│ └──────────────────────────────┘ │ 本月复盘（默认展开）  │
│                                  │ 按模块查看            │
└──────────────────────────────────┴───────────────────────┘
```

- side 栏 `position: sticky; top: 16px`，独立滚动感知。
- 本月复盘在桌面默认展开（recapOpen 初值按视口宽度）。
- 错题卡 hover 抬升已有全局样式，保持。

## 交互规格

- 移动端（≤1023px）零变化：块顺序、样式、手势与现状一致。
- 桌面端点击行为不变（同一套事件）；筛选/批量 sheet、AI sheet 等浮层不变。
- 验收硬指标（SOP-10）：1440px 无横向溢出；375px 无回归；点击热区 ≥40px；0 console error。

- 本地：`npm run lint`、`npm run build:h5` 全绿。
