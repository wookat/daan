# R289：模考低时预警——5 分钟/1 分钟提醒 + 时钟低时预警态

## 取证（源码实查）

- exam.vue 计时器只有两种外显：常显红色倒计时（恒红、无状态区分）与 `leftSecs<=0` 的「时间到，自动交卷」toast + 立即 submit()——用户从「时间还多」到「被自动交卷」之间零预警。
- 粉笔做卷页在剩余 5 分钟/1 分钟有显式提醒（考场也有 15/5 分钟铃），这是限时作答产品的通用预期：低时窗口是回头补未答题/检查标记题的最后机会。
- 现有 toast 已被 R141 常驻 aria-live region 镜像，读屏用户可听到提醒；标记/未答数据已在本页可取（answeredCount）。

## 方案（纯前端，零 API/协议变化）

1. 新纯函数模块 `exam-alert.js`：`crossedTimeAlert(prevSecs, curSecs)` 按阈值表（300s/60s）判断本 tick 是否「向下穿越」阈值，只在 prev>t≥cur 时触发一次；恢复进度时 prev 初始化为当前值，不会补触发已过阈值（中断在 4 分钟处恢复不会再弹 5 分钟提醒）。
2. exam.vue 计时 tick 接入：穿越 300s 提示「剩余 5 分钟」+（有未答时）「还有 N 题未作答」；穿越 60s 提示「剩余 1 分钟，时间到将自动交卷」。toast 经既有 aria-live 镜像通报读屏。
3. 时钟低时预警态：`leftSecs≤300` 时 `.clock`/`.side-clock` 加 `low` 态（加深强调 + 轻微脉冲动画），`prefers-reduced-motion` 下关闭动画只保留静态强调，对齐 R142。
4. 边界：mini 模考（20 分钟）同样适用；时间到自动交卷语义不变；不加任何后端接口、不改 examProgress 协议、不伪造数据。
