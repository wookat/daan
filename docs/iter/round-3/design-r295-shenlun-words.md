# R295 设计：申论作答字数联动限字提示（N / 限M字 + 接近/超出警示）

## 取证（verified，一手生产 API 全量扫描）

- 生产全库 208 道申论真题逐题扫描题面：149 题「不超过N字」、41 题「A～B字」区间、16 题「N字左右」、1 题「不少于N字」、1 题无字数要求——99.5% 题目有明确字数约束。
- 详情页作答框计数只有「已自动保存 · N 字」绝对值；题面字数要求已有解析先例（列表 `qMeta` 解析「不超过N字」做 meta chip），但作答态零联动：写超了无任何提示，考生须自行心算。
- 申论阅卷字数硬约束（超字数扣分/不判），对标粉笔申论作答有「当前字数/限字」联动展示。

## 方案（纯前端，零后端/契约变化）

- 纯函数 `src/shenlun-words.js`：
  - `parseWordLimit(text)` → `{ label, max }`（max 为显式上限）或 `null`：
    - `不超过N字` → `{ label: '≤N字', max: N }`
    - `A～B字`（～/~/—/-/至）→ `{ label: 'A–B字', max: B }`
    - `N字左右` → `{ label: 'N字左右', max: 0 }`（无显式上限，只展示不判色）
    - `不少于N字` → `{ label: '≥N字', max: 0 }`
  - `wordState(len, lim)` → `''|'near'|'over'`：仅当 `max>0` 时判色，`len>max` 为 over、`len≥0.9*max` 为 near，其余空。
- 详情页作答头计数行改为「N / 限{label}」，near 橙、over 红（`aria-live` 已有全局通报机制不重复加）；无作答时也展示「限{label}」提示；解析失败题保持现状纯计数。
- 「左右/不少于」不做主观阈值判色，只如实展示要求（不伪造判定标准）。

## 不做

- 不改草稿/批改/历史链路；不改后端；不阻止超字数提交（AI 批改自会点评）；不为「左右」类编造超限阈值。

## 验证

- vitest：不超过/区间（全角～/半角-/至）/左右/不少于/无要求/near/over 边界。
- 生产 1440/375：有限字题计数联动、打字到超限变红、无字数要求题回落纯计数、溢出 0、console 0 error、性能预算。
