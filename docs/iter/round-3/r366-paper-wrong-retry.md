## 取证（代码/生产一手证据）

- 模考路径：成绩报告页自 R282 起有「本卷错题重练」CTA，复盘后可就地重练本卷错题。
- 按卷练习路径（untimed）：完成页（R364/R365 后）只有「回卷库」「分享成绩」与解析回看；
  本卷答错的题没有任何本卷范围的就地重练出路——只能去错题本全量复习或回卷库重开整卷。
- `retryGroup()` 仅服务错题重练场次（`_redoItems`）与普通模块会话（`start(lastModule)`），
  按卷会话 `lastModule=null` 且无 `_redoItems`，完成页对该场景隐藏了「再来一组」。
- 竞品：粉笔练习完成页提供「错题重做」；与我方模考报告语义一致，按卷练习是自家双路径中的口径缺口。

## 目标体验

按卷练习完成页，若本卷有答错题，主操作区新增「重练本卷错题（N 题）」：
点击后就地以本会话答错的题（保持卷面顺序）重开会话，保留 `_source/_ptitle` 归卷
（answer_log 仍归本卷、重练再答错仍经 saveWrong 入错题本）。

- 纯前端、零后端契约、零新持久化协议、零新埋点事件。
- `paper-continue.js` 新增 fail-closed 纯函数：
  ```js
  paperWrongItems(items)
  // 非数组 → []；逐题取 _picked 非空且 ≠ answer 的题，
  // 浅拷贝并清除会话态（_picked/_saved/_mid/_secs/done），保持原卷面顺序
  ```

  handler 复用 retryGroup 的会话重置口径（idx/right/streak/resultSent 等），items 换为 wrongItems。
- 不弹确认（就地行动，无破坏性）；全对时不显示。
- 不改动：普通练习/错题重练/每日/时政/背题/计时模考完成页，R364 归卷三要素与 R365 分享零变化。
