# R42 设计方案：考点掌握度地图桌面化

## 背景与证据（生产实查 2026-08-29）

- `pkgA/stats/mastery-map.vue` 是全站少数**没有任何桌面样式**的核心页面之一（grep 全站页面 `min-width: 1024px`，仅剩 mastery-map / inbox（已有 wrap 限宽）/ reminders / login 等窄表单页）。
- 1440 生产实测（截图 `r42_audit_masterymap_1440*.png`）：
  - 冷启动卡横贯 1072px 壳宽，「去刷题」按钮拉满一行，观感为拉伸的手机页；
  - 代码走查：模块 tab 为横向 scroll-x 胶囊（桌面无滚动暗示）；tag3 色格 `width: 33.33%` 在 1072px 壳内单格 ~340px，信息密度远低于粉笔「考点色阶图」的桌面形态；
  - 选中考点吸底操作条 `position: fixed; left/right: 24rpx` 在 1440 视口横贯 ~1416px。
- 对标：粉笔练习报告的「考点掌握」在宽屏为高密度色格矩阵 + 侧栏模块导航。

## 方案（仅前端 CSS/模板，≥1024px 生效，<1024 零变化）

1. `.page` 内容区 ≥1024px 改双栏：左 240px sticky 模块导航（纵向列表替代横向 scroll tabs，含模块名+掌握%），右侧为覆盖度总览卡 + 二级题型组卡流。
2. tag3 色格桌面提密：≥1024px `.tile` 改 `width: calc(20% - 12rpx)`（5 列），hover 提亮 + cursor pointer。
3. 吸底操作条 ≥1024px 限宽 720px 水平居中，圆角浮层形态。
4. 冷启动卡 ≥1024px 限宽 560px 居中，按钮自适应内容宽。
5. 不改 script 逻辑、不改接口、不改移动端样式；tabs 的 scroll-x 在桌面用 CSS 隐藏、以侧栏导航替代（同一 `curMod` 状态，两套 DOM 用媒体查询二选一显示，避免双份逻辑）。

## 验收

- 本地 `npm run build:h5` 通过；
- 生产 1440：双栏、5 列色格、sheet 居中、hover 生效、console 0 error、无横向溢出；
- 生产 375：与改前一致（单列、横向 tab、3 列色格）；
- 地图有数据态用新测试 uid 真实作答 ≥30 题解锁取证（测试数据不污染真实榜单/评论，作答记录留在一次性 uid 内即可）。
