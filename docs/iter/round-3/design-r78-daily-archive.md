# R78 设计：往期每日一练（近 7 天补练 + SSR 归档页）

## 取证（2026-08-31）

- 粉笔每日一练提供往期日期列表，错过当天仍可回看/补练历史题组；本站每日一练只有「今天」：/api/daily_set 固定 cn_day()，/tiku/daily/ 只渲染当日，昨天的题组无任何入口（选题本身按 md5(day:qid) 确定性，任意历史日期题组随时可复现，零存储成本）。
- SEO 侧 /tiku/daily/ 是单页，内容每日整体替换、历史不沉淀；按日期归档页可让每天自然新增一个可收录 URL（题干链接 + 当日榜单快照）。

## 方案

1. `api_daily_set` 增可选 `date` 参数：ISO 校验、仅接受 [今天-7, 今天) 的往期日期，非法/越界回退今天；返回该日 items+stats。边缘缓存按完整 URL 键控（含 query），往期日内容不变、60s TTL 无碍。
2. `seo.py`：新增 `/tiku/daily/{day}/` 归档页（校验同上，非法 301 回 /tiku/daily/），复用当日页渲染（题目卡+参与数+当日榜单），CTA 深链 `?daily=1&date=<day>`「去主站补练这期同题」；/tiku/daily/ 当日页尾加「往期每日一练」近 7 天链接行；sitemap 收录近 7 天归档 URL。
3. `practice.vue`：daily 深链透传 `date`；startDaily(date) 往期日直接 `/api/daily_set?date=`（跳过当日预取缓存），toast「往期每日一练 · <日期>」；完成时往期日不提交成绩（榜单/streak 均为当日语义，后端本就 400 拒绝），完成页走普通成绩展示。

## 非目标

- 不允许往期成绩入榜/计 streak；不做 7 天以前的深归档；不做在 App 内的往期列表页（SSR 页即入口，App 内后续轮候选）。

## 验收

- API：`?date=昨天` 返回昨日确定性题组（与 SSR 页一致）、非法/未来/超 7 天回退今天；
- SSR：昨日归档页 200、题目/榜单正确、CTA 深链带 date；非法日期 301；当日页含往期链接行；sitemap 含归档 URL；
- 前端：深链 `?daily=1&date=昨天` 直入昨日题组（与 API ids 一致）、完成后不发 submit、无 400 噪音；今日深链行为不变（提交/榜单/streak 正常）；
- 1440/375 无溢出、console 0 error；测试数据清理、保护 uid 零 mutation。
