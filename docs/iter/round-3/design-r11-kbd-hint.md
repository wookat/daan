# R11 设计方案：错题本快捷键可发现性（帮助面板 + 侧栏提示）

日期：2026-08-30 ｜ 依据：R10 上线复验取证

## 背景与取证
- R10 已上线桌面快捷键（列表 J/K/↑↓/Enter/空格，复习 A–D/Enter），生产 1440 走查通过。
- 但生产页面无任何快捷键提示（1440 截图取证：错题本桌面侧栏与列表均无 kbd 提示元素），用户无从得知功能存在——快捷键的价值取决于可发现性。
- 竞品范式：成熟桌面工作台（粉笔网页端题库/主流效率产品）均以「?」帮助面板或界面内 kbd 徽标暴露快捷键。

## 方案（零后端、仅 book.vue、仅 H5 ≥1024px）
1. 侧栏提示卡：桌面侧栏（≥1024 显示区）追加一张轻量「键盘快捷键」卡，列出核心键位（J/K 切题、Enter 展开、复习 A–D 作答），底部注明「按 ? 查看全部」。
2. `?` 速查面板：onKeydown 增加 `?`（Shift+/）分支，打开 kbdHelp 弹层（复用现有 .mask/.sheet 样式规范），完整列出列表/复习两组键位；Esc 或点击遮罩关闭。
3. 弹层打开时（kbdHelp=true）其余快捷键不拦截（并入现有弹层守卫链）。
4. kbd 视觉：`<text class="kbd">J</text>` 白底细描边圆角小徽标，对齐 design-v3 tokens（--line/--ink-2）。

## 交互规格
- `?` 仅在非输入焦点、无修饰键、≥1024px 时生效（沿用 R10 守卫）。
- Esc 关闭 kbdHelp；遮罩点击关闭。
- 375/移动端：提示卡与面板均不渲染（侧栏本身 ≥1024 才显示；? 分支被宽度守卫拦截）。

## 验收标准（生产 1440/375）
- 1440：侧栏出现快捷键提示卡；按 ? 弹出速查面板、Esc/遮罩关闭；面板打开时 J/K 不移动描边。
- 375：无新增可见元素、无横向溢出。
- console 0 error；R10 快捷键行为无回归。
