# R290 设计：成绩报告解析浮层逐题连看（上一题/下一题 + 只看错题/未答）

## 取证（源码实查 + 竞品对照）

- report.vue 解析浮层只能从「逐题对错」格子逐个点开：看完一题必须关浮层→回格子→再点下一题，75 题卷复盘一遍需 150+ 次点击/关闭往返；浮层内零导航。
- 粉笔模考报告支持「全部解析 / 错题解析」连续翻看，复盘是成绩报告的核心使用场景（对错格子只回答"哪题错了"，连看解析才回答"为什么错"）。
- 复盘高价值子集是「答错 + 未答」（`!it.correct`），与报告页 redo CTA 的错题口径互补（redo 只收已答错题，未答题同样需要看解析）。
- report.vue 目前无键盘监听；exam.vue 已有 H5 桌面 keydown 先例（≥1024px、输入框/修饰键守卫）。

## 方案（纯前端，零 API/协议变化）

1. 新增纯函数模块 `src/exam-review.js`：
   - `reviewFilter(items, wrongOnly)`：wrongOnly 时过滤 `!it.correct`（答错+未答）；容错非数组。
   - `reviewStep(items, curNo, dir, wrongOnly)`：在过滤序列内按卷面顺序取前/后一题；当前题不在过滤序列（如开着"只看错题"时从答对题进入）则向前取序列首题/向后取序列末题；越界返回 null。
2. report.vue 解析浮层底部新增导航行：`‹ 上一题`｜过滤切换（全部题目 ⇄ 只看错题/未答）｜`下一题 ›`；越界置灰（aria-disabled）；切题时收起材料折叠（复用 openQ 语义）。
3. H5 桌面（≥1024px）浮层打开时 ←/→ 键切题，对齐 exam.vue keydown 守卫先例（输入框/修饰键/浮层未开时不劫持）；浮层 Esc 关闭走 R126 既有弹层机制不受影响。
4. 状态 `wrongOnly` 为浮层内瞬时复盘态，不进 URL（与 R270 详情展开态不同：浮层无独立资源身份，刷新丢失可接受，粉笔同样不持久化）。

## 边界

- 不改 /api/exam/report 契约；不改逐题格子入口；不改 redo CTA 口径。
- 全部题目模式下顺序 = 卷面 no 顺序；只看错题模式跳过答对题。
- 0 错题卷开「只看错题」：序列为空，双向按钮均置灰，不报错。
- 单测覆盖：过滤口径、正反向步进、过滤态从非序列题进入、越界、空序列、非法输入。
