# R147：试卷/错题卷 PDF 资料分析同材料去重（对齐 R145/R146 App 内体验）

## 取证（一手证据）

- `pdf_export.build_paper_pdf` 现有材料去重只认两种形态：`q["material"]` 字段、或题面含 `【资料】…【问题】…` 标记对。
- 实测数据形态（生产库 SQL 直查）：
  - `questions` 表**无 material 列**；
  - ziliao 共 8593 题，其中 4368 题为「材料…问题：小题干」形态（`问题：`/`问题:` 分隔）；
  - 含 `【资料】` 标记的仅 40 题，含 `【问题】` 标记的为 0 题。
- 结论：现有去重分支对 >99% 资料题**从不触发**——错题卷 PDF / 真题卷 PDF（粉笔招牌的导出打印场景）里同材料题组每题重复整段材料（R146 实测单题 539–580 字），A4 排版浪费且阅读负担大。本地库同构（823 题中 297 题带分隔、0 题带标记）。

## 方案

纯后端 `pdf_export.py` 单文件改动，镜像 `db._material_key` / 前端 `material.js` 的既定切分语义：

```python
_MAT_SEP = re.compile(r"问题\s*[：:]")

def _split_material(qtext):
    # 可选【资料】前缀；按「问题：/问题:」一分为二；材料去空白 <120 字不切分
    ...
    return (material, stem) 或 None
```

- 循环内在现有 `material` 字段 / `【资料】…【问题】` 两分支都未命中时，走 `_split_material` 兜底：命中则材料入 `st["mat"]` 灰底块、题行只排小题干。
- 去重键用去空白后的材料文本（防相邻题材料仅空白差异判不同）；相邻同键只输出一次材料块，与 `last_mat` 既有语义一致。
- 切分失败（短材料/无分隔）完全走原路径，零回归面。
- 参考答案/解析页、答题卡（OMR）逻辑零改动。

## 验收

- pytest 新增用例锁定 `_split_material` 切分/回退语义 + 同材料相邻题去重决策。
- 本地 ruff 全绿 + pytest 全绿。
- 部署后生产实际导出真题卷 PDF（含同材料题组），验证材料块只出现一次、小题干逐题排布、答案页/答题卡正常。
