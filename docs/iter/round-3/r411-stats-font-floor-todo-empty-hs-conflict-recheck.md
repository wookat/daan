## 1. R409「3 行 hs 结论与 answer 冲突」复核（只读 + 人工演算）

R409 用「hs 尾部 `选X`」作为 hs 结论标记，得到 1046855 / 1046866 / 1046874 三行与 `answer` 冲突、登记待校源。本轮取全文核：三题 hs 结尾均为「**确认答案为 D / A / C**」，与 `answer` 一致；R409 抓到的「选C的800是错拿…」「选D的20是误按线性算的」「选D的69凑不出整数解」是 hs 对**干扰项**的解释，不是结论——**解析器误报**，非数据问题。三题都是可闭式演算的数量题，独立复算：

| id | 题 | 复算 | DB | hs |
|---|---|---|---|---|
| 1046855 | 低于市场价 20% 付 4000 元，优惠多少 | 4000÷0.8=5000，5000−4000=**1000** | D=1000 | 确认 D |
| 1046866 | 圆锥水面高度为容器一半时 10 升，满容 | 相似体积比 (1/2)³=1/8 → 10×8=**80** | A=80 | 确认 A |
| 1046874 | 888/88/8 元三档，100 人共 2480 元，三等奖最少 | a+b+c=100，888a+88b+8c=2480 → 11a+b=21 → (a,b,c)=(0,21,**79**)/(1,10,89) | C=79 | 确认 C |

结论：**3 行从校源队列移除，不改库**。R402/R409 的 hs 显式标记比对法要修正口径：优先取「确认答案为/正确答案为/故选/答案为 X」，仅在这些标记缺失时才回落到句末「选X」，且「选X的…是…」形态（后接名词/是/为）排除。本轮只更正记录，不重跑历史比对（R402 一致率结论的 3 条不一致全在 disabled 行，不受影响；R409 220/3 应为 223/0）。
