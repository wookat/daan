## 差距清单（P0/P1/P2 × 四维度）

### 1. 操作台（核心工作区）
- **P0-1 桌面端无真正操作台**：≥700px 后内容仍是 680px 单列手机流（App.vue 限宽），1440px 下两侧大量空白（ours-book-filled-1440.png），所有功能纵向堆叠需长滚动。粉笔 Web 是满幅多栏工作区。→ 错题本桌面双栏工作台：主列（分区+列表）+ 右侧粘性辅助栏（统计/今日复习/复盘/AI/重练/模块导航）。
- **P1-1 首页桌面同样是手机流**：今日目标/计划/专项入口可双栏化（后续轮次）。
- **P2-1 桌面 hover/快捷键（J/K 切题、Enter 展开）缺失。**

### 2. 功能深度
- **P0-2 错题重练无效果报告**：重练完成后直接回列表，无「本次重练正确率 / 涉及题型掌握度变化」报告（夸克核心闭环）。
- **P1-2 知识点掌握度不外显**：掌握度仅在复习完成的强化卡中出现一次，列表/模块聚合处无掌握度条。
- **P1-3 模考错题未单独成区**：粉笔强调模考错题单独复盘；我方模考错题与日常错题混在一起（仅来源字段）。
- **P2-2 错题趋势（周/月新增-消灭曲线）缺失**（统计页有部分，未进错题本）。

### 3. 落地页/首页 UI
- **P1-4 无营销落地页**：根路径直接进 H5 应用；未登录访客（含 SEO 流量从 /tiku 进来后）没有「产品价值主张 + 功能亮点 + 引导开始」的首页。粉笔 fenbi.com/page/home 为完整营销首页。
- **P2-3 /tiku SEO 页与主应用视觉一致性待复核。**

### 4. 系统架构
- **P1-5 掌握度/错因数据模型分散**：错因存前端+attempts，掌握度即时计算，无按知识点聚合的服务端接口，制约报告与推荐（P0-2/P1-2 的地基）。
- **P2-4 SQLite 单机 + 2GB 内存**：当前量级可用；重报表接口需注意查询成本，避开 05:00–07:00 采集高峰部署。
