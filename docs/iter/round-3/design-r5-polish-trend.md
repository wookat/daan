# R5 设计方案：首页桌面打磨 + 错题趋势卡（P1-1 收尾 / P2-2）

日期：2026-08-29 ｜ 轮次：本会话第 5 轮

## 现状取证（一手）

- 首页桌面双栏（≥1024 grid 两列 + 更多练习 4 列 + 侧边导航）已在线（1440 截图核实），P1-1 主体已达成。
- 打磨点：hero「继续目标 ›」按钮 `flex:1` 在 1440 下拉成约 900px 宽白条，视觉失衡；今日任务/打卡进度条同理但影响小。
- P2-2 错题趋势缺失：粉笔错题本公开形态强调错题「新增-消灭」节奏感；我方错题本侧栏（≥1024）有统计/复盘卡但无时间趋势。
- /tiku 首载 30s 长尾复测 4 条路由 ttfb 0.2–1.0s，不可复现（当时正值容器重建窗口），记录为部署期瞬态，不立项。

## 方案

1. **首页 hero CTA 桌面收敛**：≥1024 时 `.hero-acts` 不再拉伸主按钮（`flex: 0 0 auto` + 合理 padding），保持移动端不变。纯 CSS。
2. **错题本「错题趋势」卡**（≥1024 侧栏，移动端不加避免加长首屏）：
   - 数据零后端改动：错题本已全量加载 items（含 created_at、mastered），前端聚合近 4 周每周「新增错题数」与「已掌握数」双色迷你柱状图 + 摘要行「近 7 天新增 X · 掌握 Y」。
   - 空态（<1 条数据）不显示卡。
