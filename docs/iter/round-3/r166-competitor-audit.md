# R166：功能面竞品复审计（粉笔公开页/夸克，docs-only）

距上次全面功能对标（R110/R125 窗口）已 40 轮，本轮对粉笔公开 Web 页面做一手复取证，评估剩余功能差距。

## 取证（2026-08-29，Playwright 实访）

### 粉笔官网（www.fenbi.com/page/home 及公开页族）

首页信息架构（1440 实测截图）：

1. **考试日历**（`/page/exams-information-list`）：全国招考公告聚合——公告标题/报名起止/笔试时间/地区/考试类型/职位表下载，34 个地区筛选 + 类型筛选 + 分页，「26国省考公告合集：共招 217777 人、152792 职位、收录 33 考试」级别的数据聚合；
2. **职位表检索库**：考试类型×地址×学历专业三维选岗检索；
3. **备考资料/行测小讲堂**（`/page/exams-preparation-materials-list`）：按考点的讲义型内容页（集合推理/逻辑判断-原因解释等），SEO 内容库；
4. 热门直播/热门课程/全国分校（课程商业化，与我们免费定位无关）；
5. 题库入口 `spa/tiku` 需登录（App 侧能力，历轮已对标）。

### 夸克（quark.sm.cn）

公开 Web 端仅搜索壳，无独立公开刷题页族可比对（历轮对标的刷题体验在 App/小程序侧）。

### 我方现状核对（生产实测）

- 题目页「全站正确率/易错项」外显：已有（practice.vue，attempt_count≥5 才显示，数据来自真实 answer_log 聚合，当前 1693 题有值）；
- 真实作答数据体量：answer_log 累计 949 条 / 50 uid——不足以支撑可信的「全站易错榜」类页面（top 题人次仅 3–4），不立项，挂数据观察；
- App 内练习/错题本/模考/PK/申论/面试/搜索等功能面：R1–R165 已对标收口，本轮未发现新的 app 侧 verified 差距。

## 结论

剩余差距集中在**内容/数据管线**而非产品功能：

| 差距 | 性质 | 判断 |
|---|---|---|
| 考试日历/招考公告聚合 | 需持续抓取官方公告的内容管线 + 运营维护 | 立项级，需老板决策（获客价值高，但涉及长期数据运营投入） |
| 职位表检索库 | 需职位表数据源 | 同上，依附于公告管线 |
| 备考资料/考点讲堂内容库 | 需成体系的讲义内容生产 | 立项级；不做拍脑袋自动生成凑数（不造假/不注水） |

以上均不是单轮可交付的 in-app 改动，按 CHARTER「资源缺口不阻塞」申报后搁置，继续推进其他轮次。

- answer_log 体量增长后回访「全站易错榜/难度榜」立项条件。
