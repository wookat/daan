# R151：成绩报告题目详情弹层资料题材料折叠

## 取证（一手证据，生产实测）

真题卷 5《2025四川行测》真实作答后取 `/api/exam/report/{aid}`：72–75 题（资料分析同材料题组）每题 `question` 均携带同一段 510 字材料 + 29–70 字小题干。`report.vue` 详情弹层 `<text class="dq">{{ detail.question }}</text>` 整段直出——回看错题时小题干淹没在 62vh 弹层的整段材料之后，逐题回看题组时同一材料被迫重读 4 遍。R145/R146 已收口练习页与做卷页，报告回看面是同类缺口；粉笔错题回看为材料折叠可展开形态。

## 方案（零后端）

`report.vue` 详情弹层复用 `material.js` 的 `splitMaterial`（<120 字/无「问题：」分隔即回退整段直出，非 ziliao 不切）：

- 可切分时：顶部「📄 查看材料」折叠条（role=button + 动态 aria-label，默认收起，点击展开/收起整段材料），下方始终显示小题干；
- 打开新详情时折叠态重置；
- 不可切分/非资料题：原路径整段直出，零变化。

## 验收

- 本地 lint/vitest/build 全绿。
- 生产 1440/375：报告 72–75 题详情默认只见折叠条+小题干，展开可见整段材料，非资料题详情零变化；测试作答数据清理。
