## 3. 计分/预测分/统计页口径核对（结论：口径不同但各自自洽，非缺陷）

- **模考卷面分**（`/api/exam/submit`）：`score = round(100 × 答对数 / 全卷题数, 1)`，未答/多选记 0；per_module 含 n/answered/correct/secs。实测答 3 对 1（30 题卷）→ 3.3 分，报告页「已答正确率 33% / 全卷正确率 3%」两口径并列展示，自洽。
- **预测分**（`/api/predict`，统计页 predict-card）：非卷面分，是按模块满分权重（常识10/言语30/数量12/判断28/资料20）加权的**行测估分**：近30天正确率×0.5 + 全期×0.3 + 真题×0.2，再与最近 3 次模考模块正确率按 0.3 混合，带先验（0.55/伪计数12）与瞎猜下限 0.25；<30 题冷启动不出分（实测 3 题返回 cold/need 30）。与卷面分数值不同是**设计口径**（预测省考得分 vs 单卷正确率），前端文案已区分「预测分/成绩报告」。
- **统计页**：「累计刷题(含模考)」来自本地 pstats（exam.vue 交卷时逐题写入）；服务端热力图/连签来自 answer_log——模考已答题目同样落 `answer_log`（仅 status=ok 的题，空白/多选不落），与「已答正确率」口径一致。实测 uid 答 3 题 → answer_log 恰 3 行，错 2 题入错题本 2 条，一致。
