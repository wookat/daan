- **连续学习/打卡**：学习报告含「打卡天数、最长连续学习天数、本周学习天数」，用**日历热力图**展示学习连续性；官方口径：每周学6-7天的用户模考提升明显快于每周<4天。
- **学习报告分层**：日报/周报/月报三级（练习量、正确率、答题速度、考点覆盖、连续性、错题分析、模考对比七维度）。
- **模考大赛**：定期全国模考排名，重要的周期性回访钩子。
- **push 触达**：智能提醒每日学习任务与直播课开播；AI 老师含「督学提醒」场景（按学习进度个性化推送任务）。
- **积分/奖励**（粉笔四六级线）：每日签到+连续签到积分、PK 大作战答题赢能量兑红包；班级积分制（打卡/交作业/周模考得积分换礼物）。

### 1.2 华图在线（成长值/图币双轨，规则完整公开）
- **签到**：每日签到得成长值，连续签到递增（1,2,3,4,5,5,…），断签清零重计；连签满30天额外+50。
- **行为积分表**：注册+50；每周首次模考报名+10/交卷+20；每日特训全部完成+20；专题训练/智能刷题/错题重练各+10；听免费课+10/付费课+20/课评+30；任意页面分享+10（日上限20）；试题纠错被采纳得随机奖励。
- **图币可消费**：100图币=1元，可抵扣购课/申论批改——积分有真实价值出口。

### 1.3 小猿/猿题库系
- **积分自动累积**：做题即自动加分（全对+10、错题-2、连续3天额外+5），不需手动打卡；完成诊断后解锁「积分明细」颗粒度反馈。
- **勋章体系**：每日任务点亮勋章碎片，集齐合成徽章（拼图收集欲）；班级榜前3获浮动徽章、每周一重置（动态竞争）。
- **动态 push 文案**：按当日积分差距生成（"你和李明只差12分，今晚练完就能超他"），非固定模板。
- **刮刮卡**：正确率>50% 有 20% 概率随机掉落刮刮卡（随机奖励强化）。
