## 1. 本轮实施项（r73 清单编号 → 实现）

### ① P1-2 错因标注进复习揭晓面板（一键 chip 写回 error_reason）
- r73 结论：`error_reason` 字段与后端 `PATCH /api/mistakes/{id}` 早已存在，练习页也已有「错因自评」chips，但**复习流揭晓面板没有标注入口**，导致错因覆盖率低（复盘视图里大量「未标注」）。
- 实现：复习答错揭晓时展示与练习页同款四枚 chips（粗心大意/概念不清/方法不会/纯蒙的），点选即 `PATCH` 写回 `error_reason`，选中态高亮；埋点 `review_reason_tag`。答对与「加练同类」临时题不显示（无错因可标）。

### ② P2-3 复习答错自动加推同类题
- r73 结论：粉笔/小猿答错后自动推同类，我方仅有手动「练3道同类」入口。
- 实现：复习中答错真实错题时，前端自动调用 `GET /api/questions?module=&submodule=&limit=2&uid=`（排除当前题、复用未做过优先口径），把最多 2 道同类新题以「加练同类」身份追加到本轮末尾；揭晓面板给出「已为你在本轮末尾加练 N 道同类题」提示。埋点 `review_similar_auto`。
- 边界约束（防失控）：每道错题只触发一次（`_simFetched`）；本轮重出的纠错副本（`_requeued`）不再触发；加练题答错不递归加推；加练题**不写 SRS/review_log**（不影响复习记录与到期口径），判定文案区分（“答对了，这个考法稳了 ✓”）。原有手动「还不稳？练 3 道同类题巩固 ›」入口保留（埋点 `review_similar_click`）。

### ③ P2-4 错题月度复盘视图（纯前端聚合）
- 实现：错题本列表页新增「本月错题复盘 · 新增 N 道」可折叠卡（位于待复习卡之下），基于已加载的错题数据按自然月聚合：按模块 Top6 + 按错因 Top6（含「未标注」）横条图，尾注引导优先复习高频错因对应模块。零后端改动、零新接口。
- 与①形成闭环：复习流补标错因 → 月度复盘的错因分布更有信号。
