## 2. 小程序 / Flutter 首页引导同构对照（代码走查）

| 能力 | H5 | Flutter | 原生小程序 |
|---|---|---|---|
| 首次打开计划引导卡（可跳过） | ✅ | ✅（planGuideHide 同语义） | ❌ 无 |
| 三步计划设置（类型/地区/日期/目标分/自评/时长） | ✅ | ✅ plan_setup_sheet.dart | ❌ 无任何设置入口 |
| POST /api/profile 生成计划 | ✅ | ✅ | ❌（api 仅 GET profile） |
| 首页今日计划卡 | ✅ | ✅ | ✅（hasProfile 且有任务时显示） |
| 首次练习/结果页 | ✅ | ✅ | ✅ |

结论：Flutter 与 H5 引导已同构。**原生小程序缺整个计划创建链路**——首页计划卡依赖 hasProfile，但小程序内无处可创建 profile，纯小程序新用户永远看不到计划卡（只有在 H5 建过计划的同 uid 才显示）。属大项，建议立项：小程序补「制定学习计划」引导卡+三步设置 sheet（后端接口现成）。
