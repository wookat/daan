## 2. 竞品调研：粉笔 / 小猿「错题本 / 复习体验」

**访问口径（照实报）**：两家错题本均为登录后 App 内功能，Linux 环境无法安装其 App 且无账号；fenbi.com 为 SPA（题库/错题需登录），yuantiku.com 官网为展示页。故本轮为「官网/网页可达性实测 + 公开功能资料交叉验证」，逐条标注来源，未做无凭据推断。

### 2.1 粉笔错题复习流（资料交叉验证）

- 错题自动收录（做错即入本，免手动）；
- 多维归类：科目/模块/知识点/错误类型多维筛选；
- **错因标注**：预设错因标签（知识点遗漏/方法不熟/审题不清/计算失误/时间不足猜测），错因反哺推荐算法；
- **同类题推荐**：错题详情内推荐 3-5 道同考点/同题型、难度相近题目，「错题回顾+同类巩固」组合；
- **自适应间隔重复**：按遗忘曲线提醒复习，快速答对延长间隔/移出，答错缩短间隔并加推同类题；配推送通知；
- 按时间范围筛选做月度错题复盘（模块/知识点/错因分布）。

### 2.2 小猿（猿题库）错题复习流（资料交叉验证）

- 错题自动整理、按考点分类；
- 错题重练：选错题重做 → 交卷 → 练习报告；
- 管理操作：单题长按删除、批量编辑删除、左滑「标为已掌握」（保留记录不再进重练列表）、重练答对自动标掌握；
- 错题锁屏学习（碎片时间曝光错题，差异化玩法）。

### 2.3 我方现状（代码级核对 `frontend-uni/src/pages/book/book.vue` + 后端）

已具备：自动收录、模块/题型/错因筛选排序、关键词搜索、错题重练（保持同组）、同考点强化 5 题/练 3 道同类、复习完成强化卡、SRS 完整梯子（1/3/7/15/30 固定档）、错因字段、标掌握/删除、PDF 导出、复习清零庆祝、多选题判分。
