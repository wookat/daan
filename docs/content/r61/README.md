## 1. 重写规范（本轮定稿，后续批次沿用）

**红线（一律不动）**：`answer`、考点字段（tag1/tag2/tag3/module/submodule）、事实内容、正确/错误选项的实质指向、`disabled` 状态。

**题干**：
- 模板冒号收尾（`……是：`）→ 标准挖空句 `……是（　）。`（题库通行句式，自然且与正式考题一致）；
- 疑问词题干（含 哪/谁/什么/多少/何）→ 冒号改问号 `？`，不挖空（"哪座城市（　）"不通）；
- 不重述、不扩写事实，不加年份地区等未核实信息。

**选项**：仅当明显失衡（最长≥2×最短且差≥6字，多为"正确项长、干扰项两三字"泄底型）才改写：把干扰项扩为与正确项字数相当的完整短语，**只扩表述不改指向**；正确项仅在语句残缺时润色。无法在不引入未核实事实的前提下均衡的，跳过并记台账。

**解析**：不主动改写；仅当解析中逐字引用了被改写的旧选项文本时，同步替换为新文本以保持一致（本批 8 条）。
