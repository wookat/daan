## 2. 月度增补口径（确立，写入例行）

- **时间**：每月上旬增补上月未覆盖至当月已发生的时政题（本月为月初增补当月 1-7 日事件，月底或下月初再视素材补一批，保持「近半年」滚动窗口口径成立）；
- **数量**：每月 15-25 题为准（与既有各月 14-24 题分布一致，保证日抽 10 题的新鲜度）；
- **来源白名单**：新华社/新华网、中国政府网、部委官网公告原文（商务部/教育部/应急管理部等）、权威快报类栏目；不采信自媒体转述；
- **质量要求**：逐题人工整理，4 选项+答案+解析+source_note 必填；干扰项优先「相近数字/单月 vs 累计/相近提法」；题干与库内按 UNIQUE 去重；
- **入库流程**：本地格式校验 → 生产备份 → dry-run → 守卫事务（计数断言）→ 随机抽检 → 仓库 jsonl 同步提交；
