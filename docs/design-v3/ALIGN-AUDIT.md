# design-v3 原稿 vs 线上实现 对齐审计（ALIGN-AUDIT）

- 原稿：`docs/design-v3/*.html`（375px 手机框截图）
- 线上：https://kaogong.zalize.com （H5，375×812 视口截图）
- 审计范围：五个 Tab 主页面 + 练习作答/解析页
- 差异按严重度排序：**P0**（明显违背原稿视觉语言）> **P1**（可感知的样式偏差）> **P2**（细节/状态差异）
- 每条标注维度：间距 / 字阶 / 圆角 / 阴影 / 配色 / 布局 / 图标
- 「状态/数据差异」指线上为空态或真实数据导致的内容不同，不属于样式失真，单独标注不修。

对比图：`docs/design-v3/audit/before-*.png`（左＝原稿，右＝线上），修复后对比见 PR 描述。
