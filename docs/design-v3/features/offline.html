P1 · 离线做题对标腰果/粉笔「离线缓存」。通勤地铁弱网是刷题高频场景。方案：题包（题面+解析 JSON+图片）预下载到本地 SQLite/storage，作答记录本地队列，联网后增量同步。
边界AI 讲解/批改/讨论区需联网（入口置灰并提示）；判分与解析展示纯本地可用。
包策略模块高频包、弱项定向包（按用户画像生成）、错题本快照、真题卷；上限 500MB 可清理。
多端App/小程序可用本地存储（小程序 10MB storage 上限 → 用文件系统 API）；H5 用 IndexedDB + Service Worker，能力降级仅错题本。
