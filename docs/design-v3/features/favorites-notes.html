重练本收藏夹（18 题 · 乱序）
P0 · 收藏夹 + 笔记对标腰果「收藏练习+电子笔记」、粉笔「收藏/笔记」。现状仅申论素材可收藏；行测题目无收藏、无笔记，是明显缺口。
交互答题页/解析页右上角 ☆ 收藏（长按选夹）；解析卡底部「写笔记」内联输入。笔记在下次遇到该题时随解析展示（黄色便签样式）。
钩子「重练本收藏夹」复用现有定向重练引擎；笔记可一键并入 PDF 导出（复用现有导出）。
成本低：favorite / note 两张表 + 答题页两个按钮；无 AI 依赖。
