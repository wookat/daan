**结论**：做题引擎、AI 讲解/批改、错题本、导出扫描等「单人学习闭环」已达到或超越竞品；缺口集中在三类——
① **反馈与激励层**（预测分、模考排名、打卡海报、PK），② **内容组织层**（搜索、收藏/笔记、讨论区），③ **触达与场景层**（推送提醒、深色、离线、面试）。

## 2. 逐项评估（竞品做法 / 用户价值 / 实现成本 / 优先级）

### P0 —— 本期必做（复用现有数据与 AI 能力、成本低、直接补齐"竞品及格线"）

| 功能 | 竞品做法 | 用户价值 | 实现成本（复用点） | 原型 |
|---|---|---|---|---|
| 能力预测分+进步曲线 | 粉笔基于练习数据生成报告并预测考分（用户口碑「估分准差0.5」）；腰果考分预测 | 回答"我现在能考多少分/离目标多远"这一备考最核心焦虑；周环比+目标线制造持续动力 | **低-中**：作答记录/模考成绩/考点树齐备，加权正确率→IRT 渐进；AI 提分建议复用 LLM 通道与定向重练 | [predict-score.html](predict-score.html) |
| 万人模考大赛·排名 | 粉笔/华图「模考大赛」定时开考+全国排名+解析课；腰果每日 mini 模考 | 单人模考→群体坐标系，「击败 76%」是最强分享/留存钩子；周期性运营节奏 | **低**：卷库/模考/报告已有，加场次表+排名聚合；冷启动用历史作答者当分母 | [mokao-rank.html](mokao-rank.html) |
| 每题讨论区 | 粉笔每题评论区（"神评"是其内容护城河，官方也引导用户看讨论区定答案） | 一题多解/避坑经验/情绪共鸣；UGC 沉淀为免费内容资产 | **低-中**：comment 表+审核（敏感词/举报折叠+小程序内容安全 API）；冷启动 AI 官方思路置顶 | [question-discuss.html](question-discuss.html) |
| 打卡分享海报 | 粉笔打卡日历+学习报告分享，社交平台"粉笔打卡"自发传播 | 用户炫耀=免费拉新；连续打卡损失厌恶提升次留 | **低**：统计数据齐备，canvas 合成海报+小程序码；AI 一句话小结复用 LLM | [checkin-poster.html](checkin-poster.html) |
| 全局搜索 | 粉笔搜题/华图题库搜索 | "刚在别处看到一道题/一个考点"即刻定位；知识点直达定向练习 | **低**：SQLite FTS5 起步；无结果兜底到 AI 拍题（竞品没有的差异化） | [search.html](search.html) |
| 收藏夹+笔记 | 腰果收藏练习+电子笔记；粉笔收藏/笔记 | 好题二刷、个人方法沉淀；笔记随解析复现形成个人知识库 | **低**：两张表+答题页两个按钮；重练/PDF 导出全部复用 | [favorites-notes.html](favorites-notes.html) |

|---|---|---|---|---|

| 离线做题 | 腰果/粉笔离线缓存 | 通勤地铁弱网场景；作答联网自动同步 | **中**：题包 JSON+本地队列同步；AI 功能置灰降级 | [offline.html](offline.html) |

### P2 —— 观察/暂缓（重运营或与当前策略冲突）

| 功能 | 竞品做法 | 暂缓理由 |
|---|---|---|
| 课程/直播 | 粉笔/华图核心营收（名师直播+回放+缓存） | 重师资运营，非「AI 驱动刷题」主航道；用 AI 讲解替代讲师价值 |
| 会员/商业化 | 粉笔会员、腰果批改会员、智蛙按模块订阅 | 老板指令支付暂缓；建议在面试陪练/申论精批处预留会员位，待用户量验证后开闸 |
| 考友圈/信息流社区 | 粉笔圈子 | 社区冷启动成本高；先以每题讨论区积累 UGC 与审核能力 |
| 岗位库/职位筛选 | 粉笔/华图职位库+筛选 | 数据源采购与年度更新成本高；现有报考画像已覆盖核心决策 |
| 口诀歌/速记内容 | 华图口诀歌 | 内容型，可由 AI 生成小规模试点，不单列版本 |
| 无障碍进阶（读屏/动效减弱） | 各家均一般 | 持续性工程，随组件库迭代内建（design-v3 已定对比度/热区/双通道规范） |

## 3. 路线建议（短周期迭代，按 CHARTER 自主推进）

- **R1（本周期，P0 上半）**：收藏夹+笔记 → 全局搜索 → 打卡分享海报。三项均纯复用现有数据，先补"及格线"并打开增长口。
- **R2（P0 下半）**：能力预测分+进步曲线 → 模考大赛场次+排名。预测分先用加权正确率模型上线，标注置信度，随数据量迭代。
- **R3（P1 留存层）**：消息推送/提醒（App 先行）→ 每题讨论区（含审核链路）→ 深色模式。
- **R4（P1 增长与商业化探索）**：答题 PK（异步版）→ AI 面试陪练（文字版 v1 → 语音版）→ 离线做题。
- 每轮结束按惯例由 QA/UX 子会话在线上走查后进入下一轮；P2 项每季度复评。

**协同效应提示**：预测分是提醒周报、打卡海报、模考报告的共用数据资产，建议 R2 完成后回填到 R1 的海报与 R3 的周报中；讨论区+PK+海报共同构成轻社区，为未来考友圈留基础。
