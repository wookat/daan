## 1. 信息架构（IA）

```
考公错题助手
├── Tab1 刷题（首页，home.html）
│   ├── 今日目标 Hero（继续目标 / 今日计划）
│   ├── 时政每日一练（daily.html）→ 学习日历（calendar.html）
│   ├── 专项练习 ×5 模块 → 练习答题页（practice.html）
│   │       └── 组内结算 → 再来一组 / 复盘错题
│   └── 更多练习：模考（exam-list → exam → exam-report）
│                 申论（shenlun → shenlun-detail → shenlun-review）
│                 错题重练 / 拍题讲解
├── Tab2 错题本（book.html）
│   ├── 今日复习（遗忘曲线）→ practice.html
│   ├── 错题详情（book-detail.html：历次作答 / AI 错因分析）
│   ├── 手动录入（book-entry.html）· 扫描答题卡（book-scan.html）
│   └── 导出 PDF 弹层（pdf-export.html）
├── Tab3 AI 问答 / 拍题讲解（ask.html，会话式）
├── Tab4 统计（stats.html）→ 学习日历（calendar.html）
└── Tab5 我的（profile.html，新增 Tab）
    ├── 学习计划 / 报考画像（plan.html）
    ├── 收藏 / PDF 导出记录 / 提醒 / 字号 / 深色模式 / 公告 / 关于
    └── 登录 / 注册（login.html）
```

**结构性变化**：由现状 4 Tab（拍题讲解/刷题/错题本/统计）调整为 5 Tab，「刷题」升为首 Tab（高频主场景），新增「我的」收纳散落的设置/收藏/导出/公告；拍题讲解升级为会话式「AI 问答」。

## 2. 页面间导航流（主链路）

1. **刷题闭环**：首页 Hero「继续目标」→ 练习答题 → 答错自动入错题本 → 组内结算 →「复盘错题 / 再来一组」。
2. **错题闭环**：错题本「开始今日复习」→ 重练 → 详情页 AI 错因分析 →「同考点重练 5 题」。
3. **模考闭环**：卷库 → 全真答题（倒计时态）→ 成绩报告 → 主行动「复盘 21 道错题」回错题本。
4. **申论闭环**：题库 → 作答（自动保存）→ AI 批改（采分点+逐句点评）→「修改再交 / 下一题」。
5. **AI 导流**：练习解析卡 / 错题详情 →「继续问 AI」→ 问答会话 → chips「出一道同款题 / 存入错题本」回练习。

## 3. 全局设计规范

### 3.1 色板
| Token | 值 | 用途 |
|---|---|---|
| brand-500 | `#3B6FF5` | 主色（按钮/选中/链接） |
| brand-50/100 | `#EDF3FE / #DCE7FD` | 浅底、ghost 按钮、解析卡渐变起点 |
| grad-brand | `135deg #5B8AF8→#3B6FF5` | Hero / 主按钮 |
| success / bg | `#16A34A / #ECFDF5` | 答对、已掌握 |
| error / bg | `#DC2626 / #FEF2F2` | 答错、待复习、告警(<60%) |
| warning / bg | `#D97706 / #FFFBEB` | 时政暖色系、低置信 |
| 文本 t1–t4 | `#17181C / #40434E / #7D818F / #B0B4C0` | 标题/正文/辅助/占位 |
| border / fill / bg | `#E7E9F0 / #F2F3F7 / #F6F7FB` | 描边/填充/页面底 |
| 模块色 | 资料`#0D9488` 数量`#3B6FF5` 言语`#E11D48` 判断`#7C3AED` 常识`#D97706` | 仅用于图标底/tag/条形，不做页面主色 |

### 3.2 字阶（375px 基准）
Display 24 / H1 20 / H2 17 / 正文 15 / 副文 13 / 说明 12 / 大数字 22–48（tabular-nums）。行高正文 1.55、题干 1.7。

### 3.3 间距与圆角
间距 4pt 网格：4/8/12/16/20/24/32；页面左右留白 16px。圆角：chips/胶囊 999、按钮/输入 10、卡片 14、Hero/弹层 20。阴影三级（sh-1 卡片 / sh-2 hover / sh-3 弹层）。

### 3.4 组件
- **按钮**：primary（品牌渐变+投影）/ ghost（brand-50 底）/ plain（白底描边）/ danger；高度 ≥44px，页内主行动**唯一**。
- **卡片**：白底 r14 + sh-1，内边距 16；桌面 hover 升 sh-2。
- **Chips**：h30 胶囊，选中 brand-50 底 + 品牌字重 600；横向可滑，筛选态用「标签 ▾」。
- **Tag**：h20 语义色小标签（模块色/错因/状态），色+文字双通道保证色盲可读。
- **弹层**：底部 sheet（r20 顶圆角 + 抓手 + 单主行动），遮罩 `rgba(23,24,28,.45)`。
- **空态**：72px 圆角图标位 + 一句话 + 行动按钮（见错题本收藏空态规范）。
- **选项（答题）**：默认白底描边 → 正确 success 底描边 → 错误 error 底描边，右侧文字标注「✓ 正确 / ✕ 我的选择」。

### 3.5 无障碍
全部可点热区 ≥44px；正文对比度 ≥4.5:1；对错/告警均为色+文字/图标双通道；焦点态 2px 品牌描边（桌面）。

## 6. 竞品对标（粉笔等）

**学习借鉴**
- 粉笔「配置收进入口内部、导航层只放行动」：首页/练习顶栏均只保留行动，模式与设置收进入口或「⋯」。
- 粉笔练习「组内结算 + 再来一组」节奏：保留并加自适应难度提示。
- 粉笔模考「成绩报告→模块诊断」：沿用条形诊断，但主行动改「复盘错题」（见差异化）。

**差异化**
- **错题闭环是主品**：粉笔错题本是附属功能；本产品以「遗忘曲线复习 + AI 错因分析 + 同考点重练」为核心动线，首页/报告/问答全部导回错题闭环。
- **方法体系讲解**：解析统一挂「花生十三·方法名」tag，AI 讲解按方法库分步，而非通用解析。
- **申论 AI 采分点批改**：命中/漏点红绿清单 + 原文逐句高亮，粉笔人工批改收费、时效慢，这里主打即时 AI 批改。
- **克制视觉**：单品牌蓝 + 语义色，不做粉笔的多彩运营位堆叠；无广告位、无课程推销层。
