考公助手 · 管理后台 design-v3 原型总览

左侧边导航 + 顶栏 + 内容区（Ant Design Pro 类布局）· 桌面 1440px 主稿 · 768px 平板侧栏收纳为图标栏 · 与客户端 v3 同 token（品牌蓝 #3B6FF5）。设计说明见 ADMIN.md，客户端原型见 ../index.html。

深做：抽审 / 批次审核 / 题库编辑 线框级：治理 / 用户 / 时政申论 / 设置

A01

📊 数据看板

KPI 五卡（活跃/作答/新增/健康度/AI 调用）+ 趋势图 + AI 通道状态 + 集中待办入口。
A02 · 深做

📚 题库管理

表格列表 + 筛选/问题 chips + 批量操作条 + 右侧编辑抽屉（题干/选项/答案/考点/解析重产）。
A03 · 深做

📦 批次导入与审核

左批次队列（抽检进度/答案分布预警）+ 右逐题抽检工作台（键盘 1/2/S/E）+ 发布/驳回常驻栏。
A04

🌲 考点树管理

三级树表（题数常驻 + 行内题目/抽审/编辑出口）+ 右侧考点详情面板；UNKNOWN 告警行直通抽审。
A05 · 深做

🔍 考点抽审工作台

单题聚焦流：AI 建议 + 候选考点数字键直选 + Enter 审结自动下一题；近期审结栈可撤销。
A06

🛠 纠错处理队列

左队列右处理面板；同题反馈聚合；一步「保存修改并标记已修复」；备注即用户回执。
A07 · 新增

🛡 内容治理

克隆检测 / 损坏题体检 / 答案分布监控（批次级堆叠条 + 阈值预警直通审核）。
A08 · 新增

👥 用户与运营

用户列表（学习数据 + 流失预警）/ 学习数据 / 用户反馈流；ID 脱敏。
A09

📰 时政与申论管理

时政题时效生命周期 + 每日一练排期；申论按卷管理，采分点模板齐备才可上架。
A10

⚙️ 系统设置

AI 通道（状态/测试/故障切换）、导入令牌（脱敏/吊销）、运营公告、导出记录。
