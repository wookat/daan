# 考公助手 · 管理后台 design-v3 设计说明

> 交付形态：本目录 **10 个模块页 + 1 个总览页** 的静态 HTML 高保真原型（共享 `admin.css`，双击可开、无外部依赖），`png/` 下为 1440px 桌面截图。入口：[index.html](index.html)。
> 本轮为**设计稿**，不改任何应用代码；风格与客户端 design-v3（`../DESIGN.md`）同 token。核心工作台（考点抽审 / 批次审核 / 题库编辑）深做，治理/用户/时政申论/设置为线框级。

---

## 1. 信息架构（IA）与导航结构

对标 Ant Design Pro / shadcn admin 布局：**左侧边导航（232px，分组）+ 顶栏（面包屑 + ⌘K 全局搜索 + 环境标识 + 账号）+ 内容区（max 1440px）**。

```
管理后台
├── 概览
│   └── A01 数据看板（dashboard.html）——登录后落地页，待办事项集中入口
├── 内容
│   ├── A02 题库管理（questions.html）
│   ├── A03 批次导入审核（batches.html）〔红点：待审批次数〕
│   ├── A04 考点树（taxonomy.html）
│   ├── A05 考点抽审（review.html）〔红点：队列题数〕
│   ├── A06 纠错处理（reports.html）〔红点：待处理数〕
│   ├── A07 内容治理（governance.html）★新增
│   └── A09 时政与申论（content.html）
├── 用户
│   └── A08 用户与运营（users.html）★新增
└── 系统
    └── A10 系统设置（settings.html：AI 通道 / 导入令牌 / 公告 / 导出记录）
```

主链路：
1. **导入→上架闭环**：新建导入 → 批次抽检工作台（逐题合格/问题）→ 答案分布校验 → 发布/驳回。
2. **考点治理闭环**：考点树（UNKNOWN 告警行 / 每考点「抽审」入口）→ 抽审工作台（键盘流）→ 审结出队回树。
3. **纠错闭环**：用户端纠错 → 队列聚合（同题合并）→ 处理面板改题 → 标记已修复 → 回执推送用户。
4. **质量巡检**：内容治理每日扫描（克隆/损坏/答案分布）→ 修复走题库编辑抽屉或批次审核。

## 4. 组件规范

沿用客户端 v3 token（品牌蓝 `#3B6FF5`、灰阶 t1–t4、r-s/m/l/xl、sh-1/2/3，见 `../DESIGN.md`），管理端补充：

- **表格（.tbl）**：表头 12px 灰底吸附；行高 ≥44px；行 hover 浅蓝底、选中 brand-50；主列「标题+副行」双层；行内操作 ≤2 个文字链，更多收进抽屉。分页固定表尾。
- **表单**：输入高 36px（触屏页 44px），focus 品牌描边 + 2px brand-100 光晕；标签置上 12px 灰。
- **抽屉（.drawer）**：右侧 560px，头（标题+状态 tag+关闭）/滚动体/底部操作栏三段式；危险操作靠左、主行动靠右且**唯一**。用于题库编辑、用户详情。
- **工作台模式（workbench）**：核心复审场景统一「进度条头部 + 单条聚焦主体 + 常驻判定操作栏」结构；所有判定动作标注键盘键（`.kbd` 组件）；判定后自动前进；提供撤销栈。应用于考点抽审、批次抽检、纠错处理。
- **KPI 卡（.kpi）**：数字 26px tabular-nums；环比 ▲绿/▼红/持平灰（色+符号双通道）。
- **徽标/Tag**：导航红点 = 待办数；状态 tag 全部色+文字双通道（色盲可读）。
- **设计注释（.dnote）**：每页底部蓝色虚线卡为实施说明，非 UI 的一部分。

### 无障碍
可点热区 ≥44px（表格行内文字链所在行整行 44px）；正文对比度 ≥4.5:1；告警均为色+文字/图标双通道；键盘可完成核心工作台全流程；焦点态 2px 品牌描边。

## 6. 实施建议（供后续开发参考，本轮不实施）

- 保持后端 API 不变的前提下，前端可由单文件渐进重构：先抽公共布局（侧栏/顶栏）与表格组件，再逐 tab 迁移为路由页；或直接采用轻量方案（Vue3 + Naive UI / React + AntD）独立 `admin/` 构建产物挂 `/admin`。
- 抽审/抽检工作台的键盘事件与撤销栈为前端状态，审结提交沿用现有 PATCH 接口；批次「逐题抽检结论」需新增 sample_reviews 表落库。
- 内容治理三项扫描建议每日 cron 落表，页面只读查询。
