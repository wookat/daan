- 脚本：`backend/scripts/rebalance_shizheng.py`（确定性随机种子 20260804，一次性执行，**勿重复运行**，重复运行会再次打散）。

- 每道改动题构造完整的「旧字母→新字母」置换：选项内容随置换移动，答案字母同步更新。
- **解析同步重写**：将置换应用到解析文本中所有「独立的 A–D 字母」（前后均非 ASCII 字母/数字），保护 GDP、CPU、AI、HBM、ISC2026、LX2、Online Acceleration 等专有名词不被误改（逐一复核计数无变化）。
- 逐题前后对照存于 `docs/shizheng-rebalance-audit.json`。
