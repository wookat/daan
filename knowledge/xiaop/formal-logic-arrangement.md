# 形式逻辑与组合排列

## 1. 直言命题：先画确定范围

### 范围翻译

- 所有 A 都是 B：A 的范围完全落在 B 内。
- 所有 A 都不是 B：A 与 B 不相交。
- 有的 A 是 B：A 与 B 存在交集，但不能推出还有 A 不在 B 内。
- 有的 A 不是 B：存在 A 落在 B 外，但不能反推“有的 B 不是 A”。

画图时：

1. “所有”用实线，先画确定关系；
2. “有的”用虚线，后画可变关系；
3. 虚线只保留题干要求的“根据地”，其余范围可以移动；
4. 不补题干没有说的存在性或排他性。

### 集合推理捷径

- 有的 A 是 B ⇔ 有的 B 是 A。
- 所有 A 是 B，所有 B 是 C ⇒ 所有 A 是 C。
- 有的 A 是 B，所有 B 是 C ⇒ 有的 A 是 C。
- 所有 A 是 B ⇒ 有的 B 是 A / 有的 A 是 B，只在题干已保证 A 存在时使用。
- 所有 A 都不是 B ⇔ 所有 B 都不是 A。
- 所有 A 是 B，有的 A 不是 C ⇒ 有的 B 不是 C。

### 矛盾关系

- 有的 A 是 B ↔ 所有 A 都不是 B。
- 有的 A 不是 B ↔ 所有 A 都是 B。
- 某个 A 是 B ↔ 某个 A 不是 B。

否定表达统一写成“并非 + 原命题”。范围题常用：

- 所有 ↔ 有的不是；
- 是 ↔ 不是；
- 必然 ↔ 有可能不；
- 可能 ↔ 不可能。

真假题先找矛盾对。矛盾对必一真一假，可以直接确定其他命题的真假；找不到再看反对、全覆盖或代入。

## 2. 联言、选言、假言

### 基本含义

- A 且 B：两个都成立；整体为假时，至少一个为假。
- A 或 B：至少一个成立；只有两个都假时整体为假。
- 要么 A 要么 B：恰好一个成立；同真或同假时整体为假。
- 如果 A，那么 B：`A→B`。

### 假言命题只认两条

`A→B` 只允许：

- 肯前：A 真 ⇒ B 真；
- 否后：B 假 ⇒ A 假。

不能由 A 假判断 B，也不能由 B 真判断 A。凡是看到“否前”或“肯后”，先警惕无效推理。

`A→B` 为假只有一种情况：A 真且 B 假。

### 矛盾形式

- `A且B` 的矛盾是 `非A或非B`。
- `A或B` 的矛盾是 `非A且非B`。
- `要么A要么B` 的矛盾是“同真或同假”。
- `A→B` 的矛盾是 `A且非B`。

## 3. 组合排列：像抽丝剥茧一样找链条

### 找桥梁对象

先找题干中出现频率高、能连接多个条件的对象。优先级：

1. 一条条件能直接推出另一条结论；
2. 两条条件能递推成更长链；
3. 两条条件在同一结果上形成“两难”。

常见链条：

- `A→B` 与 A ⇒ B。
- `A→B` 与 `非B` ⇒ 非A。
- `A→B` 与 `B→C` ⇒ `A→C`。
- `A→非C` 与 `B→C` ⇒ `A→非B`。
- `A→B` 与 `非A→B` ⇒ B 必真。
- `A→B` 与 `非A→C` ⇒ B 或 C 至少一个真。
- `A→B` 与 `A→非B` ⇒ A 必假。

### n 选 m 的强制选择

遇到“从 n 个对象选 m 个”：

- 若选 A 就必须选 B，B 的优先级高于 A；
- 若 A 所代表的对象数 ≥ `n-m`，则 B 往往被迫选入；
- 先检查“如果选 A，则选 B”中的 B 是否为必选破题点；
- 利用恰好选 m 个造成的容量限制，不必枚举所有组合。

### 问法决定方法

- “一定”：假设该项不成立，能否推出矛盾；
- “可能”：把选项代入，看能否构造一套无矛盾方案；
- “不能”：从限制最多、最容易冲突的选项开始；
- “可以推出”：优先沿现成链条，不完整排表。

### 代入验证的四种问法

- 可能为真：正面代入，整题无矛盾即可。
- 不可能为真 / 一定为假：正面代入，出现冲突即可。
- 可以推出 / 必然为真：反面代入，出现冲突即可。
- 不能推出 / 可能为假：反面代入，整题无冲突即可。

## 4. 特殊逻辑

### 真假话

核心：找关键角色信息，假设一个选项或一句话，发现矛盾就排除；遇到两难就得到明确结论。

不要从头枚举所有真假组合。先找：

- 明确的一真一假；
- 两句互相否定；
- 一句话同时关联身份与真假；
- 选项给出的完整身份排列，可直接代入。

### 大大则大

同一组织被两种二分法划分：

- A 人数 > B 人数；
- C 人数 > D 人数；
- 两组划分彼此交叉。

则同时属于 A 与 C 的人数，通常大于同时属于 B 与 D 的人数。用于比较四格表中“两个较大集合的交集”与“两个较小集合的交集”。

### 排身份

先找关联条件最多的人或身份，一条信息尽量同时排多个位置。若选项已给完整对应表，直接代入验证比自己从零排表更快。

## 5. 常见陷阱

- “至少一个”是 A 或 B，不是 A 且 B。
- “除非 A，否则非B”要先改写成条件命题再推。
- “只有 A 才 B”是 `B→A`。
- “除非 A，才 B”通常也是 `B→A`。
- “并非所有”是“有的不是”，不是“所有都不”。
- 生活语义冲突不等于逻辑矛盾；只有覆盖全部情况且不相交才是一真一假。
