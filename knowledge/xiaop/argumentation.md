# 论证推理、加强削弱与逻辑谬误

## 1. 先拆论据—论点

先找结论词：因此、所以、说明、可见、由此认为、建议、预测。

把题干压缩为：

```text
论据：A
论点：C
断点：A 为什么能推出 C？
```

三类论证：

- 论点型：论据几乎等于观点，只看选项是否支持或反对观点。
- 逻辑型：A 经中间环节推到 C，重点找缺失的桥。
- 因果型：由现象或结果推原因，重点查因果方向和其他原因。

## 2. 强弱判断的核心

### 加强

优先级通常是：

1. 补上断点或必要前提；
2. 排除最直接的替代解释；
3. 解释因果机制；
4. 增加同向证据或重复论据；
5. 仅相关、仅背景、仅举例。

### 削弱

优先级通常是：

1. 直接否定论点；
2. 切断论据到论点的桥；
3. 指出测量、样本、概念或推理对象不一致；
4. 给出明确替代原因或因果倒置；
5. 泛泛说“还有其他因素”“样本不同”，但未连到结论。

一个选项只有“存在其他变量”但没说明它影响分组和结果，通常弱于直接切断关键前提的选项。

## 3. 必要前提：没它不行

必要前提是论证成立的必需论据。

### 否定代入法

把选项否定后放回题干：

- 论点立刻推不出来或不可能成立：该项是必要前提；
- 论证仍可成立：不是必要前提。

逻辑型断点：

- 论据 `A→B`，论点 `A→C`，需要补 `B→C`。
- 论据 `A→B`，论点 `C→B`，需要补 `C→A`。

先看论据和论点中“对象是否换了”“范围是否扩了”“可能是否变必然”。

## 4. 因果论证

### 由因推果

题干：A 发生，所以预测 B。

- 削弱：A 不足以推出 B；存在阻断条件；B 可能不发生。
- 加强：解释 A 如何导致 B；提供其他同类证据。

### 由果推因

题干：已发生 B，所以推测原因是 A。

先查六种结构：

1. 因果倒置：其实 B 导致 A；
2. 其他原因：C 导致 B；
3. 无关他因：C 也导致 B，但与 A 无关，只是干扰；
4. 共同原因：C 同时导致 A 和 B；
5. 根本原因：C→A→B，C 不一定削弱 A；
6. 解释原因：A→C→B，补出中间机制，属于加强。

不要看到“还有原因”就立刻选。只有该原因能解释观察到的 B，并能与 A 竞争，才是强削弱。

### 实验与调查

快速查：

- 分组是否随机；
- 除自变量外是否保持一致；
- 样本是否有系统性偏差；
- 指标是否真的测到题目中的概念；
- 时间先后是否支持因果；
- 是否只观察相关性；
- 是否把个体结论扩大到整体。

## 5. 特殊模型

### 反对反对者

甲提出观点①，乙反对①并提出观点②。

削弱乙，不一定要证明①错；可以：

- 说明乙若继续否认①，就无法坚持②；
- 或让乙承认①，从而承认自己的反对有问题。

先判断两方是否是互斥观点，还是可以同时成立。

### 解释现象

题干常是：“背景 A，但出现了 B。”

两条路：

1. 找能解释转折后 B 的原因；
2. 指出 A 与 B 并不真正矛盾，修正误解。

最佳选项应直接解释 B，而不是重复 A、强调背景或再描述一次矛盾。

### 论证评价

评价题问“哪一个问题的答案最有助于评价”。正确问题必须：

- 回答“是”时明显加强；
- 回答“否”时明显削弱；
- 两个方向都能改变论证强度。

只会单向加强、问了也不影响结论、或问题对象跑偏的选项排除。

## 6. 常见逻辑谬误

- 肯后推肯前：由 `A→B` 和 B，误推 A。
- 否前推否后：由 `A→B` 和非A，误推非B。
- 因果错误：只凭时间、地点或共同变化就认定因果。
- 转移论点 / 答非所问：回应了另一个问题。
- 预设前提：问法中偷偷把未证明的事实当真。
- 幸存者偏差：只看被筛选后留下的样本。
- 论据无关：证据与论点不在同一对象或层级。
- 论据不充分：局部、个案、相关不足以支持普遍结论。
- 论据虚假：前提本身不成立。
- 不当类比：只凭一个表面共同点推同一结论。
- 循环定义 / 循环论证：用结论证明结论。

做“最相似谬误”题时，先把题干抽象成箭头或结构，再匹配选项；不要被故事内容带走。

## 7. 选项排除口令

- 与论点无关：排。
- 只重复论据：弱。
- 只说背景正确：弱。
- 对象、范围、指标不一致：优先查。
- 直接补断点：强加强。
- 直接切断断点：强削弱。
- 泛泛他因：通常不如明确他因。
- 只证明“可能”：不能支持“必然”。
