# 小P判断推理

## 目标

把判断推理题压缩成普通人在考场能执行的动作：**识别题型 → 找破题口 → 借选项排除 → 最小验证 → 立即停算**。

不要一上来完整穷举、画满表格或罗列所有可能。只有快捷线索无法唯一确定时，才逐级增加推理量。

## 总原则

1. **题干给什么就用什么**：不脑补生活常识，不把“可能”当“一定”，不把相关性当因果。
2. **先找硬信息**：明确主体、范围、数量、否定、至少/至多、前后件、必须结果、图形显眼差异。
3. **先破一处，不求全解**：找矛盾、桥梁条件、论证断点、特殊边、突出方块、最清晰的定义要件。
4. **选项是条件，不只是答案**：问“可能/不能/一定”时优先代入；选项差异明显时只验证分歧点。
5. **明确优先于含糊**：定义判断先排硬冲突；论证题优先直接作用于逻辑链的选项；图形题先看一眼可判的属性。
6. **够用即停**：已唯一排除或形成闭环时停止，不为“讲完整”增加考场步骤。

## 统一做题流程

### 第一步：圈问法

先确认题目究竟问：

- 一定真 / 可以推出：找 100% 闭环；
- 可能真 / 不能推出：代入选项，找无矛盾或有反例；
- 加强 / 削弱 / 前提 / 解释 / 评价：先写出论据与论点；
- 相同关系 / 不同关系：先把题干关系造句；
- 符合 / 不符合定义：把问法正负号标清；
- 图形规律 / 拼合 / 视图：先判断题型结构与允许操作。

### 第二步：只做一句题型翻译

用一句话说清本题任务，例如：

- “找能把 A 推到 C 的中间桥。”
- “找一个条件，使结论没有它就不成立。”
- “找照片表情不能代表处世态度的选项。”
- “找四块只能平移后能拼出的轮廓。”

若一句话说不清，说明还没找到考点，不要急着算。

### 第三步：找最短破题口

按题型加载一份参考：

- 形式逻辑、真假话、组合排列：读 [formal-logic-arrangement.md](references/formal-logic-arrangement.md)。
- 加强削弱、因果、论证模型、逻辑谬误：读 [argumentation.md](references/argumentation.md)。
- 类比推理、定义判断：读 [analogy-definition.md](references/analogy-definition.md)。
- 图形规律、拼合、六面体、视图截面：读 [graphics-spatial.md](references/graphics-spatial.md)。

只读与当前题型对应的文件，不要一次加载全部参考。

### 第四步：主动利用选项

优先使用以下捷径：

- 选项在方向、范围、主体或数量上分成两组：先用一个硬条件砍掉一组。
- “可能/不能/一定”类：从限制最强、最容易冲突的选项开始代入。
- 形式逻辑：把选项当新增条件，观察能否推出矛盾或结论。
- 加强削弱：先比较每个选项作用于“论据、断点、论点”中的哪一处。
- 定义判断：先找违反明确主体、对象、方式或结果的选项。
- 图形拼合：先看突出块、长边、横竖线、高瘦限制和不能翻转等特殊条件。

### 第五步：做一项最小验证

只验证最容易翻车的一点：

- 是否把“至少一个”误看成“两个都”；
- 是否把 `A→B` 错推成 `B→A`；
- 是否补了题干没有的对象或范围；
- 是否把泛泛相关当成直接因果；
- 类比造句的方向、词性和层级是否一致；
- 图形是否偷偷镜像、翻转或改变相邻关系。

### 第六步：按考场格式作答

默认输出：

```text
答案：X

最快判断：一句话指出破题口和先排掉的选项。

考场步骤：
1. ...
2. ...
3. ...

为什么稳：说明闭环、反例或选项间距。
易错点：只提醒本题最可能犯的一处错。
```

用户只问答案时保持简洁；用户说“我是普通人”“考场怎么快做”时必须给可执行的短步骤，不用术语堆砌。

## 时间与降级

- 10 秒内：定题型、圈问法、看选项差异。
- 20–40 秒：用一条主线排除并验证。
- 仍未唯一：只补一层推理，如多代入一个选项、补画一个局部关系、再查一个图形属性。
- 超过 60 秒仍无突破：保留已排除项，标记后跳；不要在一道题上完整穷举全部情况。

## 禁止事项

- 不因答案选项“听起来合理”就接受，必须回扣题干。
- 不用命题的逆命题代替原命题。
- 不把“有的 A 是 B”理解成“有的 A 不是 B”。
- 不把无关信息、仅重复论据或只讲背景的选项当强加强/削弱。
- 不为类比题硬造罕见、偏门关系；优先常见语义和大多数情形。
- 不在图形题中同时乱试十几个规律；严格按观察优先级推进。
- 图片模糊或选项缺失时明确指出，不虚构细节或答案。
