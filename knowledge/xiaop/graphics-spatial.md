# 图形规律、拼合与空间推理

## 1. 先判题型结构

- 一组图：从前几图找共同特征、数量或运动，推下一图。
- 两组图：先在左组三图找规律，再搬到右组。
- 九宫格：优先横看三行，再竖看三列；也可查米字、九图遍历。
- 三三分组：把六图分两类，每类各有共同特征。

## 2. 图形规律的观察顺序

总口令：

- **图形不相似，找相同。**
- **图形相似，找区别。**

### 图形不相似：先自身属性，再数量

一眼可判的自身属性优先：

1. 对称性：轴/中心、轴数、轴方向、轴经过元素；
2. 开闭性：封闭、半封闭、开放；
3. 曲直性；
4. 部分数。

再查特征数量：

- 点：交点、切点、框交点；
- 线：曲直、横竖、平行；
- 面：个数、最大最小面、轮廓、相似面；
- 角：直角、锐角；
- 笔画数；
- 元素：种类、个数、相邻关系、换算。

数量型要点：若特征个数很少或特别醒目，优先数；若所有图都带曲线、都像七巧板、都有黑白块，就围绕该共同特征数。

### 图形相似：优先位置和运算

- 平移：整体、分开、交替；
- 旋转：整体、分开；
- 翻转：水平、竖直、对角；
- 连接：点连或边连；
- 同异运算；
- 黑白叠加；
- 黑白分组；
- 标记重点的数量、形状、位置、面积；
- 面积重复增加。

不要同时试所有规律。每次只验证一个候选规律能否解释全部已知图。

## 3. 先选项再规律

- 选项只在对称轴方向上不同：只查对称。
- 选项只在黑白位置不同：只查黑白运动或叠加。
- 选项只在数量上不同：只数能区分的特征。
- 两个选项互为镜像：重点检查题干是否允许翻转。
- 若前三个选项在某属性上一致，第四项孤立，先验证该属性是否为题干规律。

## 4. 平面拼合

### 俄罗斯方块拼合

1. 找突出方块。突出块因位置特殊，对应位置少，是稳定破题点。
2. 找“高个子”或“横胖子”。目标轮廓的行数、列数限制了放置位置。
3. 从限制最大的一块开始，不从最规则的一块开始。
4. 只能平移时，方向不能变；允许旋转时可转但不可镜像；明确不可翻转时尤其注意。

### 直边拼合

找特殊边：

- 横线、竖线；
- 超长边；
- 特殊凹凸边；
- 独一无二的角。

先用特殊边排选项，再注意拼合后的总边长和凹凸是否吻合。

## 5. 六面体与展开图

轴测图只看到三个面。做题只需验证其中两对相邻关系，不必把整个立方体完整折出。

快捷流程：

1. 锁定三个可见面的标记；
2. 在展开图中找这三面；
3. 验证两对相邻边和标记方向；
4. 排除相对面同时出现的选项。

技巧：

- 确定贴合的两个面可沿公共边平移或旋转；
- 展开图两两比对两次；不在一起时可“挪在一起”比较；
- 优先看非中心对称、无干扰项的图案；
- 相对面不会在同一轴测图中相邻；
- 两个展开面与轴测图的相对位置必须一致。

## 6. 视图、立体堆砌与截面

### 视图

“所见即所得”。视图只保留：

1. 轮廓边界；
2. 前后遮挡形成的距离差。

利用主视图、左视图、俯视图的轮廓和黑白位置交叉排除；不要凭想象补看不见的内部结构。

### 方块堆砌

由两个视图还原时：

- 每一列高度至少达到视图显示的高度；
- 前后方向和左右方向分别提供下限；
- 总方块数给上限或精确值；
- 先按轮廓排除，再用总数补隐藏块。

找规律型立体图仍按“移动、增减、旋转、重复结构”处理。

### 截面

截面是一个平面切过立体得到的形状，必须真的“切到”才记录。

常识：

- 圆柱/圆锥底面平行截面为圆；
- 圆柱斜截面为椭圆；
- 圆锥斜截面可为椭圆、抛物线或双曲线，取决于切面角度；
- 长方体截面可为三至六边形，但不可能凭空出现题体没有的曲线；
- 组合体截面要同时满足各部分能被同一平面切到。

## 7. 停止条件

满足任一项就停：

- 一个属性已解释全部题干图且选项唯一；
- 一个特殊边/突出块已排除三项；
- 两对相邻面已验证且只剩一项；
- 两个视图轮廓与总数已共同确定答案。

若图像模糊到无法确认点、线或黑白位置，明确要求更清晰图片，不猜图。
