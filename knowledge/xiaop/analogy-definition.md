# 类比推理与定义判断

## 1. 类比先造句

把题干词项放进一句最短、最自然的话：

- A 是一种 B；
- A 是 B 的组成部分；
- 用 A 制作 B；
- A 导致 B；
- A 用于 B；
- 先 A 再 B；
- A 与 B 功能相同；
- A 是 B 的工具 / 原料 / 结果。

选项必须同时满足：

1. 关系类型相同；
2. 方向一致；
3. 词性和主体一致；
4. 必然/或然程度一致；
5. 需要时再做二级辨析。

不要先搜索冷门知识。常见关系优先，大多数情形优先。

## 2. 基础关系

### 语义关系

- 近义：整体近义、拆分近义、程度递进、褒贬差异；
- 反义：整体反义、拆分反义；
- 同义：不同叫法、完全展开、引申指代、同字同义/不同义；
- 成语：结构、感情色彩、出处或含义。

### 集合关系

- 种属：A 是一种 B。A 具有 B 的基本属性并有额外属性。
- 全异：两者不交叉；可再分并列、矛盾或一般全异。
- 交叉：两个集合有交集但互不包含。

种属与组成的区分：

- 能用“A 是 B”自然造句，偏种属；
- 只能说“A 是 B 的一部分 / B 由 A 组成”，偏组成；
- 若词义被固定在某个已知组成集合内，常是组成关系；
- 若整体概念中根本不存在 A，是反向组成。

### 结构关系

- 主谓：主体—动作；
- 动宾：动作—对象；
- 主宾：职业—服务对象；
- 偏正：修饰语—中心词；
- 并列：词内成分并列。

## 3. 对应关系

常见类别：

- 顺序：先后、同时、循环、主体是否相同、前后等级；
- 组成：整体—部件，且查必然/或然、天然/人工；
- 原料：A 可制作 B，查直接/间接、物理/化学变化；
- 功能：主要/次要功能，结构与功能，古今同物；
- 属性：必然还是或然；
- 目的：行为能否真正实现目标；
- 因果：自然/人为、结果好坏、必然/或然；
- 充要：生活事件、科学原理；
- 命名：外形、功能、材质、特点、原理、音译；
- 比喻象征：共同点、指代；
- 工具：主体—工具—对象；
- 配套：必然或然、是否消耗；
- 公式：计算关系与对应单位。

二级辨析只在多个选项都满足一级关系时使用。常用二级点：

- 必然还是可能；
- 主体是否相同；
- 方向是否相同；
- 直接还是间接；
- 过程是物理还是化学；
- 整体是否必含该部分；
- 结果是正向还是负向。

## 4. 定义判断：硬条件先行

定义题不要求背概念，只要求忠于题干。

### 拆成五格

快速圈出：

1. 主体：谁实施；
2. 对象：对谁或什么；
3. 方式：如何实施；
4. 条件：在什么前提下；
5. 结果/目的：造成什么或为了什么。

### 做题原则

1. 明确信息优先于含糊信息；
2. 先排违反硬条件的选项，再在剩余项中择优；
3. 题干若规定明确主体、身份、领域或结果，先用这些“硬性特征”；
4. 某个模糊程度词无法精确判断时，比较选项中谁更明显符合；
5. 不把现实常识塞进定义，除非题干明确要求。

例如“金融机构向消费者发放用于消费的贷款”，先查：

- 是否金融机构；
- 是否贷款；
- 是否给消费者；
- 是否用于消费。

饭店赊账虽然像“先消费后付款”，但主体和行为不符，可直接排除。

### 明确结果

定义若给出明确后果，选项没有出现该后果，通常是迷惑项。先找结果，再回查过程，不必逐字对齐长定义。

### 同构排除

遇到晦涩、极长、否定型定义：

- 观察三个选项是否具有同一结构，剩余一项常是答案候选；
- 再用定义中的一个硬条件验证；
- 这只是省时线索，不能替代最后验证。

### 结合命名逻辑

复杂定义的名称通常已经概括核心：

- “最小干预”应同时有安全前提、最小介入、保留原貌；
- “响应性监管”应有多主体、差异化、阶段化；
- “再造性想象”应基于已有描述形成形象；
- “消费信贷”应同时有消费目的和信贷行为。

先用名称预测，再回到题干核对。

## 5. 易错点

- 问“不属于/没有体现”时漏看否定。
- 把例子中的附加特征误当定义必要条件。
- 把“目的”当“结果已实现”。
- 把“可能导致”偷换成“必然导致”。
- 只因选项与定义同领域就选择，未检查主体与方式。
- 类比题只看两词都相关，没检查具体关系和方向。
