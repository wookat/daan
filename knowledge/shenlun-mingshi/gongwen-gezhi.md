# 公文格式速查手册

本文件是公文写作题的格式速查手册，覆盖15+文种，配格式要素、示例、记忆口诀。

---

## 一、公文格式三分类

### 1.1 全格式

**要素**：标题 + 称呼（发文对象）+ 正文 + 落款（发文单位）+ 日期

**适用**：倡议书、公开信、通知、通报、建议书

**示例**：
```
关于开展XX的通知

各部门：
  （正文）

XX单位
XXXX年XX月XX日
```

### 1.2 半格式

**要素**：标题 + 称呼 + 正文

**适用**：讲话稿、发言稿、致辞

**示例**：
```
在XX会议上的讲话

各位代表：
  （正文）
```

### 1.3 文章类

**要素**：标题 + 正文

**适用**：新闻稿、短评、简报、提纲、汇报、调研报告、工作方案

**示例**：
```
XX工作取得显著成效

（正文）
```

## 三、各文种详解

### 3.1 倡议书

**格式**：全格式

**标题**：关于 + 事由 + 的 + 倡议书

**称呼**：倡议对象（如"居民朋友们""广大市民"）

**正文**：
- 开头：倡议背景 + 目的
- 主体：倡议内容（分条）
- 结尾：号召

**落款**：倡议单位

**日期**：XXXX年XX月XX日

**示例**：
```
关于开展垃圾分类的倡议书

居民朋友们：
  垃圾分类是改善人居环境、促进绿色发展的重要举措。为建设美丽社区，我们倡议：
  一、学习分类知识。
  二、养成分类习惯。
  三、参与宣传活动。
  四、监督分类工作。
  让我们共同行动起来！

XX社区居委会
XXXX年XX月XX日
```

### 3.2 通知

**格式**：全格式

**标题**：关于 + 事由 + 的 + 通知

**称呼**：通知对象（如"各部门""各单位"）

**正文**：
- 开头：通知事由
- 主体：通知内容（时间、地点、要求）
- 结尾：特此通知

**落款**：发文单位

**日期**：XXXX年XX月XX日

**示例**：
```
关于开展安全生产检查的通知

各部门：
  为加强安全生产管理，决定开展安全生产检查。现将有关事项通知如下：
  一、检查时间：XX月XX日至XX月XX日。
  二、检查范围：全单位各场所。
  三、检查内容：安全责任制落实、设施设备运行、隐患排查整改。
  四、工作要求：各部门要高度重视，认真自查，及时整改。
  特此通知。

XX单位
XXXX年XX月XX日
```

### 3.3 讲话稿

**格式**：半格式

**标题**：在 + 场合 + 的 + 讲话

**称呼**：听众（如"各位代表""各位村民"）

**正文**：
- 开头：问候 + 会议目的
- 主体：讲话内容（分点）
- 结尾：号召 + 谢谢

**示例**：
```
在乡村振兴动员大会上的讲话

各位村民：
  大家好！今天我们召开乡村振兴动员大会，目的是动员全村上下，共同推进乡村振兴。
  ...
  谢谢大家！
```

### 3.4 汇报提纲

**格式**：文章类

**标题**：关于 + 事由 + 的 + 汇报提纲

**正文**：
- 一、工作背景
- 二、主要做法
- 三、工作成效
- 四、存在问题
- 五、下一步打算

**示例**：
```
关于XX工作的汇报提纲

一、工作背景
  ...
二、主要做法
  1. ...
  2. ...
三、工作成效
  1. ...
  2. ...
四、存在问题
  1. ...
  2. ...
五、下一步打算
  1. ...
  2. ...
```

### 3.5 新闻稿

**格式**：文章类

**标题**：主标题（可加副标题）

**正文**：
- 导语：时间、地点、事件
- 主体：活动内容、效果
- 结尾：意义、展望

**示例**：
```
XX社区开展垃圾分类宣传活动

  为推进垃圾分类工作，提升居民环保意识，XX月XX日，XX社区开展了垃圾分类宣传活动。

  活动现场，工作人员通过发放宣传资料、现场讲解、互动问答等方式，向居民普及垃圾分类知识。居民们积极参与，纷纷表示要从自身做起。

  此次活动共发放宣传资料500余份，接受咨询200余人次，取得了良好效果。下一步，社区将继续开展此类活动，建立长效机制。
```

### 3.6 建议书

**格式**：全格式

**标题**：关于 + 事由 + 的 + 建议书

**称呼**：建议对象

**正文**：
- 开头：建议背景
- 主体：建议内容（分条）
- 结尾：希望采纳

**落款**：建议人

**日期**：XXXX年XX月XX日

### 3.7 公开信

**格式**：全格式

**标题**：致 + 对象 + 的 + 公开信

**称呼**：公开信对象

**正文**：
- 开头：写信背景
- 主体：信的内容
- 结尾：祝愿

**落款**：写信人

**日期**：XXXX年XX月XX日

### 3.8 短评

**格式**：文章类

**标题**：评论主题

**正文**：
- 观点：表明立场
- 分析：分析原因、影响
- 对策：提出建议

### 3.9 调研报告

**格式**：文章类

**标题**：关于 + 事由 + 的 + 调研报告

**正文**：
- 一、调研背景
- 二、调研方法
- 三、调研发现
- 四、问题分析
- 五、对策建议

### 3.10 工作方案

**格式**：文章类（可加落款日期）

**标题**：关于 + 事由 + 的 + 工作方案

**正文**：
- 一、工作目标
- 二、工作原则
- 三、工作任务
- 四、工作措施
- 五、工作要求

## 四、格式记忆口诀

### 4.1 三分类口诀

```
全格式：标题称呼正文落款日期（5要素）
半格式：标题称呼正文（3要素）
文章类：标题正文（2要素）
```

### 4.2 文种分类口诀

**全格式文种**：
- 倡议书、公开信、通知、通报、建议书
- 口诀：倡公通通建

**半格式文种**：
- 讲话稿、发言稿、致辞
- 口诀：讲发致

**文章类文种**：
- 新闻稿、短评、简报、提纲、汇报、调研报告、工作方案
- 口诀：新短简提汇调工

### 4.3 标题写法口诀

```
通用：关于 + 事由 + 的 + 文种
讲话：在 + 场合 + 的 + 讲话
新闻：主标题（可加副标题）
```

### 4.4 正文结构口诀

```
开头：事由/背景/目的
主体：内容（分条）
结尾：号召/要求/展望
```

## 五、格式易错点

| 易错点 | 说明 | 对策 |
|-------|------|------|
| 格式错 | 缺要素 | 记住格式 |
| 文种错 | 用错文种 | 看清题干 |
| 标题错 | 标题写法错 | 记住标题写法 |
| 称呼错 | 称呼不当 | 看清对象 |
| 落款错 | 落款单位错 | 看清身份 |
| 日期错 | 日期格式错 | 用XXXX年XX月XX日 |
