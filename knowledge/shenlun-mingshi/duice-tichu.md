# 提出对策题详解

提出对策题考查针对问题提出解决方案的能力。本文件整合袁东、小马哥、李梦圆等方法。

---

## 一、题型认知

### 1.1 定义

提出对策题是要求考生针对材料中的问题，提出解决方案的题型。

### 1.2 特点

- 需要发现问题
- 需要分析原因
- 需要提出对策
- 分值较高（15–20分）
- 题量稳定（0–1题）

### 1.3 题型分类

| 类型 | 常见问法 |
|------|---------|
| 直接对策 | "针对...问题，提出对策" |
| 间接对策 | "结合...经验，提出建议" |
| 流程对策 | "梳理...流程，提出改进建议" |

---

## 二、答题框架

### 2.1 通用框架

```
问题1 → 对策1
问题2 → 对策2
问题3 → 对策3
```

或：

```
一是...。针对...问题，要...。
二是...。针对...问题，要...。
三是...。针对...问题，要...。
```

### 2.2 对策来源

#### 来源1：材料直接对策

**标志词**：推动、完善、促进、加强、建立、健全、落实、强化

**方法**：找材料中的对策词，直接提炼。

#### 来源2：问题反推对策

**方法**：把问题反过来。

**示例**：
- 问题：资金不足 → 对策：加大资金投入
- 问题：人员缺乏 → 对策：加强人员配备
- 问题：制度缺失 → 对策：建立健全制度

#### 来源3：原因反推对策

**方法**：把原因反过来。

**示例**：
- 原因：管理不善 → 对策：加强管理
- 原因：认识不足 → 对策：提高认识
- 原因：监管缺失 → 对策：强化监管

#### 来源4：经验反推对策

**方法**：借鉴他人成功经验。

**示例**：
- A地经验：建立机制 → 对策：借鉴建立机制
- B地经验：加强宣传 → 对策：加强宣传教育

#### 来源5：教训反推对策

**方法**：从失败中吸取教训。

**示例**：
- 教训：监管不力 → 对策：加强监管
- 教训：制度漏洞 → 对策：完善制度

## 三、解题步骤

### 3.1 审题

**审什么**：
- 对象：针对什么问题
- 范围：哪则材料
- 字数：多少字
- 身份：以什么身份提对策

### 3.2 找问题

**方法**：关键词定位法找问题词。

### 3.3 找原因

**方法**：关键词定位法找原因词。

### 3.4 找对策

**方法**：
- 材料直接对策
- 问题反推
- 原因反推
- 经验反推
- 教训反推

### 3.5 加工对策

**加工方法**：
- 同类合并
- 对策排序（按重要性或逻辑）
- 提炼前置句

### 3.6 书写

**格式**：
```
1. 前置句。具体对策。
2. 前置句。具体对策。
3. 前置句。具体对策。
```

## 四、对策表达规范

### 4.1 对策句式

**标准句式**：动词 + 宾语 + 目的/效果

**示例**：
- 加大资金投入，保障工作经费。
- 加强人员配备，充实工作力量。
- 建立健全制度，规范工作流程。

### 4.2 对策动词

| 类别 | 动词 |
|------|------|
| 加强类 | 加强、强化、增强 |
| 建立类 | 建立、健全、完善 |
| 推进类 | 推进、推动、推行 |
| 落实类 | 落实、贯彻、执行 |
| 提升类 | 提升、提高、增强 |

### 4.3 对策层次

**层次**：
- 思想层面：提高认识、转变观念
- 制度层面：建立制度、完善机制
- 执行层面：加强执行、强化落实
- 监督层面：加强监督、严格考核

## 五、名师技巧

### 5.1 袁东：对策来源清晰

- 明确对策来自哪里
- 对策要有针对性
- 对策要可操作

### 5.2 小马哥：框架化

- 用固定框架
- 填空式作答
- 易上手

### 5.3 李梦圆：问题反推对策

- 先找问题
- 再反推对策
- 对策有针对性

## 六、真题示例

### 示例1：直接对策题

**题目**：针对给定资料中反映的基层治理问题，提出对策建议。（20分，不超过300字）

**材料**：
> 基层治理存在人员不足、能力欠缺、经费单一、居民参与度低等问题。社区工作人员反映"忙不过来"，复杂问题处理不了。经费主要靠财政拨款，来源单一。居民"事不关己"心态普遍。

**解析**：

**找问题**：
- 人员不足
- 能力欠缺
- 经费单一
- 居民参与度低

**反推对策**：
- 人员不足 → 加强人员配备
- 能力欠缺 → 提升专业能力
- 经费单一 → 拓宽经费渠道
- 参与度低 → 引导居民参与

**参考答案**：
```
1. 加强人员配备。充实社区工作力量，优化人员结构，缓解人手不足。
2. 提升专业能力。开展专业培训，提高工作人员处理复杂问题的能力。
3. 拓宽经费渠道。在财政拨款基础上，引入社会资金，多元化保障经费。
4. 引导居民参与。建立参与机制，开展共建活动，调动居民积极性。
```

### 示例2：间接对策题

**题目**：结合A市优化营商环境的经验，为B市提出建议。（20分，不超过300字）

**材料**：
> A市推进"放管服"改革，削减审批事项；建立"一窗受理"，实现"最多跑一次"；推出"一网通办"，压缩开办时间；加强事中事后监管；设立企业服务热线；出台减税降费政策。

**解析**：

**概括经验**：
- 简政放权
- 优化服务
- 提升效率
- 加强监管
- 畅通诉求
- 减轻负担

**转化为B市建议**：
- 推进简政放权
- 优化政务服务
- 提升办事效率
- 加强事中事后监管
- 畅通企业诉求
- 减轻企业负担

**参考答案**：
```
1. 推进简政放权。深化"放管服"改革，削减行政审批事项。
2. 优化政务服务。建立"一窗受理"模式，实现"最多跑一次"。
3. 提升办事效率。推行"一网通办"，压缩企业开办时间。
4. 加强事中事后监管。建立"双随机、一公开"机制，规范市场秩序。
5. 畅通企业诉求。设立企业服务热线，及时解决企业问题。
6. 减轻企业负担。落实减税降费政策，降低企业经营成本。
```

### 示例3：流程对策题

**题目**：针对农村电商发展问题，提出改进建议。（20分，不超过300字）

**材料**：
> 农村电商存在物流成本高、人才匮乏、标准化低、品牌意识弱等问题。

**解析**：

**找问题**：
- 物流成本高
- 人才匮乏
- 标准化低
- 品牌意识弱

**反推对策**：
- 物流成本高 → 完善物流体系
- 人才匮乏 → 培养电商人才
- 标准化低 → 建立标准体系
- 品牌意识弱 → 打造区域品牌

**参考答案**：
```
1. 完善物流体系。建设县乡村三级物流网络，降低配送成本。
2. 培养电商人才。开展电商培训，培育本土电商人才，吸引青年返乡。
3. 建立标准体系。制定农产品质量标准，推进标准化生产。
4. 打造区域品牌。培育特色农产品品牌，提升品牌溢价能力。
5. 加强政策支持。出台扶持政策，提供资金、技术支持。
```

## 七、易错点汇总

| 易错点 | 说明 | 对策 |
|-------|------|------|
| 无针对性 | 对策与问题不对应 | 问题反推对策 |
| 不可操作 | 对策空泛 | 对策要具体 |
| 无层次 | 对策堆砌 | 分层次提对策 |
| 漏问题 | 问题找不全 | 全面找问题 |
| 超字 | 超过字数 | 精简语言 |
| 主观 | 凭空想象 | 基于材料 |

## 八、配套速记口诀

- **对策来源**：材料直接、问题反推、原因反推、经验反推、教训反推
- **对策句式**：动词 + 宾语 + 目的
- **对策层次**：思想、制度、执行、监督
- **对策动词**：加强建立推进落实提升
- **名师**：袁东来源清晰，小马哥框架化，李梦圆问题反推
- **易错**：无针对性、不可操作、无层次、漏问题、超字、主观
