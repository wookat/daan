# 套题复盘方法与错题本模板

本文件提供申论套题复盘方法、错题本模板、归因分析，是备考过程的"错题管理工具"。

---

## 一、套题复盘认知

### 1.1 套题复盘的价值

- 发现薄弱点
- 巩固方法
- 调整策略
- 提升实战能力

### 1.2 套题复盘原则

1. **及时复盘**：做完立即复盘
2. **对照参考**：对比多家答案
3. **归因分析**：分析错因
4. **针对性改进**：针对薄弱点改进
5. **定期回顾**：定期回顾错题

---

## 二、套题复盘五步法

### 2.1 第一步：对答案

**方法**：
- 对照参考答案
- 标记遗漏要点
- 标记多余要点
- 标记错误要点

### 2.2 第二步：析错因

**四类错因**：

| 错因 | 说明 | 对策 |
|------|------|------|
| 知识盲区 | 不会方法 | 重学理论 |
| 技巧不熟 | 方法不熟 | 多练巩固 |
| 粗心大意 | 看错、写错 | 仔细审题 |
| 时间不够 | 做不完 | 提速训练 |

### 2.3 第三步：找规律

**方法**：
- 统计各题型正确率
- 找出薄弱题型
- 找出常见错因
- 总结规律

### 2.4 第四步：调策略

**方法**：
- 调整时间分配
- 调整做题顺序
- 调整答题方法
- 制定改进计划

### 2.5 第五步：定计划

**方法**：
- 针对薄弱点专项训练
- 安排下次套题
- 设定目标分数
- 持续改进

## 五、错题复习策略

### 5.1 艾宾浩斯复习法

| 复习时间 | 复习内容 |
|---------|---------|
| 当天 | 当天错题 |
| 第2天 | 昨天错题 |
| 第7天 | 上周错题 |
| 第15天 | 半月错题 |
| 第30天 | 上月错题 |
| 考前 | 所有错题 |

### 5.2 分类复习法

| 错因 | 复习频率 | 复习方法 |
|------|---------|---------|
| 知识盲区 | 每周 | 重学理论 + 做题 |
| 技巧不熟 | 每3天 | 重做 + 限时 |
| 粗心大意 | 每周 | 看错因 + 提醒 |
| 时间不够 | 每月 | 调策略 |

### 5.3 错题重做

**重做原则**：
- 遮住答案重做
- 完整写出过程
- 对比原解析
- 标记仍错的题

## 六、套题训练策略

### 6.1 套题选择

**推荐**：
- 近5年国考真题
- 目标省考真题
- 联考真题

**数量**：10–15套

### 6.2 套题训练方法

#### 第一阶段：不限时

- 重点在质量
- 把每题做透
- 不追求速度

#### 第二阶段：限时

- 模拟考场时间
- 训练速度
- 训练心态

#### 第三阶段：超限时

- 比考试少20分钟
- 训练紧迫感
- 提升效率

### 6.3 套题时间分配

**180分钟分配**：

| 题型 | 用时 |
|------|------|
| 阅读材料 | 30分钟 |
| 单一题 | 25分钟 |
| 综合分析 | 30分钟 |
| 公文写作 | 35分钟 |
| 大作文 | 60分钟 |
