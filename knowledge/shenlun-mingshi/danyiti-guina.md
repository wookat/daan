# 单一题（归纳概括）详解

单一题是申论最基础的题型，考查从材料中提炼、归纳、概括要点的能力。本文件整合李梦圆、袁东、站长、飞扬等方法，提供完整解题体系。

---

## 一、题型认知

### 1.1 定义

单一题是要求考生从给定材料中概括某一类要素（问题、原因、影响、做法、特点、变化等）的题型。

### 1.2 特点

- 答案全部来自材料
- 要点明确、客观
- 分值占比高（10–20分）
- 题量稳定（1–2题）
- 是其他题型的基础

### 1.3 常见问法

| 要素 | 常见问法 |
|------|---------|
| 问题 | "概括...存在的问题""指出...的不足" |
| 原因 | "分析...的原因""概括...的原因" |
| 影响 | "概括...的影响""分析...的作用" |
| 做法 | "概括...的做法""总结...的经验" |
| 特点 | "概括...的特点""分析...的特征" |
| 变化 | "概括...的变化""分析...的转变" |
| 内容 | "概括...的主要内容""梳理...的情况" |

## 二、审题四要素

### 2.1 作答范围

**判断方法**：看题干"根据给定资料X"。

| 表述 | 范围 |
|------|------|
| 根据给定资料1 | 只看资料1 |
| 根据给定资料1-3 | 看资料1、2、3 |
| 结合给定资料 | 看全部资料 |
| 综合给定资料 | 看全部资料 |

### 2.2 作答对象

**判断方法**：看题干"概括什么"。

| 对象 | 找什么 |
|------|--------|
| 问题 | 问题词附近 |
| 原因 | 原因词附近 |
| 影响 | 影响词附近 |
| 做法 | 对策词附近 |
| 特点 | 特征描述 |
| 变化 | 前后对比 |

### 2.3 字数要求

**判断方法**：看题干"不超过X字"。

| 字数 | 要点数 |
|------|--------|
| 100字 | 3–4个要点 |
| 150字 | 4–5个要点 |
| 200字 | 5–6个要点 |
| 300字 | 7–8个要点 |

### 2.4 作答要求

**常见要求**：
- 全面：找全要点，不漏
- 准确：用材料原词，不主观
- 有条理：分类作答，序号化
- 简明：语言简洁，不啰嗦

## 三、阅读找点

### 3.1 找点方法（李梦圆关键词定位法）

#### 找问题

**标志词**：不足、缺乏、滞后、薄弱、缺失、欠缺、短板、漏洞、困难、问题、弊端、隐患

**示例**：
> "由于资金投入不足，导致基础设施建设滞后。"
- 问题1：资金投入不足
- 问题2：基础设施建设滞后

#### 找原因

**标志词**：因为、由于、源于、缘于、归因于、导致、造成、引发、促使

**示例**：
> "由于管理不善，导致效率低下。"
- 原因：管理不善

#### 找影响

**标志词**：
- 积极：有助于、有利于、促进了、推动了、带动了、激发了
- 消极：阻碍了、违背了、损害了、影响了、制约了、限制了

**示例**：
> "这一政策促进了经济发展，但也制约了创新。"
- 积极影响：促进经济发展
- 消极影响：制约创新

#### 找做法

**标志词**：推动、完善、促进、加强、建立、健全、落实、强化、推进、实施、开展

**示例**：
> "该市建立了监管机制，加强了执法力度。"
- 做法1：建立监管机制
- 做法2：加强执法力度

### 3.2 找点技巧

#### 技巧1：逐段阅读

- 一段一段读
- 每段找要点
- 标记位置

#### 技巧2：关注并列

- 并列词前后都是要点
- 不能漏掉

#### 技巧3：关注转折

- 转折后常是重点
- 要重点标记

#### 技巧4：关注观点

- 专家、官员观点常是要点
- 要重点标记

## 四、加工逻辑

### 4.1 同类合并

**方法**：把相同类型的要点合并。

**示例**：
- 要点1：资金不足
- 要点2：人员不足
- 要点3：设备不足
- 合并：资源不足（资金、人员、设备）

### 4.2 异类分开

**方法**：把不同类型的要点分开。

**示例**：
- 要点1：资金不足（资源问题）
- 要点2：管理不善（管理问题）
- 要点3：制度缺失（制度问题）
- 分开：资源问题、管理问题、制度问题

### 4.3 分类方法

#### 按主体分

- 政府
- 企业
- 社会
- 个人

#### 按领域分

- 经济
- 政治
- 文化
- 社会
- 生态

#### 按层面分

- 思想
- 制度
- 执行
- 监督

#### 按时间分

- 过去
- 现在
- 未来

### 4.4 提炼前置句（袁东方法）

**方法**：每个要点前加一个概括性短句。

**示例**：

不加前置句：
```
一是社区工作人员只有5人，要服务2万居民。
二是工作人员能力参差不齐。
三是经费靠财政拨款。
```

加前置句：
```
一是人员配备不足。社区工作人员仅5人，需服务2万居民。
二是专业能力欠缺。工作人员能力参差不齐。
三是经费保障单一。过度依赖财政拨款。
```

**前置句要求**：
- 概括性强
- 对仗工整
- 关键词突出

## 五、书写格式

### 5.1 序号化

**常用序号**：
- 一、二、三、...
- 1. 2. 3. ...
- ①②③...

**建议**：字数有限，优先用 1. 2. 3.

### 5.2 条理化

**格式**：
```
1. 前置句。具体内容。
2. 前置句。具体内容。
3. 前置句。具体内容。
```

### 5.3 规范表达

**要求**：
- 书面化：不用口语
- 规范化：用政府用语
- 简洁化：不啰嗦
- 客观化：不主观

**口语转规范**：
- "搞"→"开展"
- "弄"→"推进"
- "想办法"→"研究对策"
- "出问题"→"出现问题"

## 六、名师技巧

### 6.1 李梦圆：关键词定位法

- 用四类标志词找点
- 用符号批注标记
- 系统全面

### 6.2 袁东：前置句提炼法

- 每个要点加前置句
- 答案更有条理
- 阅卷更易找分

### 6.3 站长：出题人视角

- 站在出题人角度思考
- 分类要符合出题意图
- 要点要全面准确

### 6.4 飞扬：精准踩分

- 多答不同核心词
- 关键词前置
- 宁可多答不漏

## 七、真题示例

### 示例1：概括问题

**题目**：根据给定资料1，概括当前基层治理中存在的主要问题。（15分，不超过200字）

**材料**：
> "我们社区只有5个工作人员，要服务2万多居民，根本忙不过来。"社区主任无奈地说。同时，社区工作人员专业能力参差不齐，很多复杂的法律问题无法处理。此外，社区治理经费主要依靠财政拨款，来源单一，难以满足日益增长的治理需求。居民参与治理的积极性也不高，"事不关己高高挂起"的心态普遍存在。

**解析**：

**审题**：
- 范围：资料1
- 对象：问题
- 字数：200字
- 要求：全面、准确、有条理

**找点**（关键词定位法）：
- "只有5个工作人员"→ 人员不足
- "专业能力参差不齐"→ 能力欠缺
- "经费主要依靠财政拨款，来源单一"→ 经费单一
- "居民参与积极性不高"→ 参与度低

**加工**（分类 + 前置句）：
- 人员问题：人员配备不足、专业能力欠缺
- 经费问题：经费保障单一
- 参与问题：居民参与度低

**书写**：
```
1. 人员配备不足。工作人员数量少，与服务对象数量不匹配。
2. 专业能力欠缺。工作人员能力参差不齐，难以处理复杂问题。
3. 经费保障单一。过度依赖财政拨款，来源渠道单一，难以满足需求。
4. 居民参与度低。居民参与治理积极性不高，存在旁观心态。
```

### 示例2：概括原因

**题目**：根据给定资料，概括农村电商发展滞后的原因。（15分，不超过200字）

**材料**：
> 某村尝试发展电商，但物流成本高，一件快递要送到镇上才能发，成本比城里高出一倍。村里懂电脑的年轻人少，大多数老年人不会上网。农产品标准化程度低，品质参差不齐，难以满足电商销售要求。此外，缺乏品牌意识，产品同质化严重，卖不上价。

**解析**：

**找点**：
- "物流成本高"→ 物流成本高
- "懂电脑的年轻人少"→ 人才匮乏
- "农产品标准化程度低"→ 标准化低
- "缺乏品牌意识"→ 品牌意识弱

**书写**：
```
1. 物流成本高。配送链条长，成本高于城市。
2. 人才匮乏。懂技术的年轻人少，老年人不会上网。
3. 标准化程度低。农产品品质参差不齐，难以电商销售。
4. 品牌意识弱。产品同质化严重，缺乏品牌溢价。
```

### 示例3：概括影响

**题目**：根据给定资料，概括数字经济发展带来的影响。（15分，不超过200字）

**材料**：
> 数字经济的发展，催生了大量新职业，如数据标注师、AI训练师等，创造了大量就业机会。同时，也提高了生产效率，降低了企业成本。但也带来了一些问题，如部分传统岗位被取代，一些工人面临失业。此外，数据安全、隐私保护等问题也日益突出。

**解析**：

**找点**：
- "催生新职业，创造就业机会"→ 积极影响
- "提高生产效率，降低成本"→ 积极影响
- "传统岗位被取代，工人失业"→ 消极影响
- "数据安全、隐私保护问题"→ 消极影响

**书写**：
```
积极影响：
1. 创造就业机会。催生数据标注师、AI训练师等新职业。
2. 提高生产效率。降低企业成本，提升效益。

消极影响：
1. 传统岗位被取代。部分工人面临失业。
2. 安全问题突出。数据安全、隐私保护问题凸显。
```

### 示例4：概括做法

**题目**：根据给定资料，概括A市优化营商环境的做法。（20分，不超过250字）

**材料**：
> A市深入推进"放管服"改革，大幅削减行政审批事项。建立"一窗受理"服务模式，实现"最多跑一次"。推出企业开办"一网通办"平台，将开办时间压缩至3个工作日。加强事中事后监管，建立"双随机、一公开"机制。设立企业服务热线，及时解决企业诉求。出台减税降费政策，减轻企业负担。

**解析**：

**找点**：
- "放管服改革，削减审批事项"→ 简政放权
- "一窗受理，最多跑一次"→ 优化服务
- "一网通办，压缩时间"→ 提效
- "双随机一公开"→ 加强监管
- "企业服务热线"→ 畅通诉求
- "减税降费"→ 减轻负担

**书写**：
```
1. 简政放权。推进"放管服"改革，削减行政审批事项。
2. 优化服务。建立"一窗受理"模式，实现"最多跑一次"。
3. 提升效率。推出"一网通办"平台，压缩开办时间。
4. 加强监管。建立"双随机、一公开"机制，强化事中事后监管。
5. 畅通诉求。设立企业服务热线，及时解决企业问题。
6. 减轻负担。出台减税降费政策，降低企业成本。
```

### 示例5：概括变化

**题目**：根据给定资料，概括M村近年来发生的变化。（15分，不超过200字）

**材料**：
> 过去的M村，道路泥泞，房屋破旧。如今，水泥路通到家门口，家家户户住进了新房。以前村民靠种地为生，收入微薄；现在发展乡村旅游，年收入翻了几番。过去村里留不住年轻人，如今返乡创业的越来越多。曾经村民文化生活匮乏，现在建起了文化广场，定期举办文化活动。

**解析**：

**找点**（前后对比）：
- 道路：泥泞→水泥路
- 房屋：破旧→新房
- 收入：微薄→翻番
- 人口：留不住→返乡创业
- 文化：匮乏→丰富

**书写**：
```
1. 基础设施改善。道路由泥泞变水泥路，房屋由破旧变新房。
2. 收入水平提升。由种地微薄收入发展为乡村旅游，年收入翻番。
3. 人口结构优化。由留不住年轻人变为返乡创业增多。
4. 文化生活丰富。由文化匮乏变为建起文化广场，定期举办活动。
```

## 八、易错点汇总

| 易错点 | 说明 | 对策 |
|-------|------|------|
| 漏点 | 并列词没注意 | 关注并列词 |
| 错点 | 标志词判断错 | 熟记标志词 |
| 重复 | 同一要点写多次 | 同类合并 |
| 无序 | 不分类不序号 | 分类序号化 |
| 口语 | 用口语表达 | 规范表达 |
| 超字 | 超过字数限制 | 精简语言 |
| 照抄 | 照抄原文 | 提炼概括 |
| 主观 | 加自己观点 | 客观陈述 |
