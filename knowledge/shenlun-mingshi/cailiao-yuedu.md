# 申论材料阅读方法

材料是申论答案的来源，阅读能力是申论的核心能力。本文件汇总七位名师的材料阅读方法，提炼为"四原则 + 一批注法"。

---

## 一、材料阅读总原则

### 1.1 核心认知

- 申论答案 80% 在材料里（李梦圆原则）
- 材料是答案的唯一来源
- 阅读的目的是"找点"
- 找点要"全、准、快"

### 1.2 阅读三步走

```
第一步：审题（明确找什么）
第二步：阅读（带着目标找点）
第三步：整理（分类合并要点）
```

---

## 二、材料阅读四原则

### 2.1 关联词原则

**原理**：关联词提示逻辑关系，关联词附近常是要点。

#### 六类关联词

| 类型 | 关联词 | 作用 |
|------|--------|------|
| 转折 | 但是、然而、却、不过、可是 | 转折后是重点 |
| 递进 | 而且、甚至、更、不仅...还 | 递进后是重点 |
| 因果 | 因为、由于、所以、因此 | 原因和结果都是要点 |
| 条件 | 只有、只要、无论、不管 | 条件和结果都是要点 |
| 并列 | 同时、此外、与此同时、一方面...另一方面 | 并列前后都是要点 |
| 假设 | 如果、假如、倘若 | 假设情况是要点 |

#### 转折词详解（高频考点）

**常见转折词**：
- 尽管...可是...
- 虽然...但是...
- ...却...
- ...然而...
- ...可是...
- ...但是...
- 虽说...然而...
- 固然...但...

**阅读技巧**：转折后是重点，要重点标记。

#### 并列词详解

**常见并列词**：
- 同时
- 此外
- 与此同时
- 一方面...另一方面
- 首先...其次...最后
- 一是...二是...三是...

**阅读技巧**：并列前后都是要点，不能漏。

### 2.2 关键词原则

**原理**：材料中的标志词提示要点类型，看到标志词就找对应要点。

#### 四类标志词（李梦圆核心方法）

##### 问题词

| 标志词 | 用法 |
|--------|------|
| 不足、缺乏、滞后 | 找问题 |
| 薄弱、缺失、欠缺 | 找问题 |
| 短板、漏洞、困难 | 找问题 |
| 问题、弊端、隐患 | 找问题 |

##### 原因词

| 标志词 | 用法 |
|--------|------|
| 因为、由于、源于 | 找原因 |
| 缘于、归因于、导致 | 找原因 |
| 造成、引发、促使 | 找原因 |

##### 影响词

| 标志词 | 用法 |
|--------|------|
| 有助于、有利于、促进了 | 找积极影响 |
| 推动了、带动了、激发了 | 找积极影响 |
| 阻碍了、违背了、损害了 | 找消极影响 |
| 影响了、制约了、限制了 | 找消极影响 |

##### 对策词

| 标志词 | 用法 |
|--------|------|
| 推动、完善、促进 | 找对策 |
| 加强、建立、健全 | 找对策 |
| 落实、强化、推进 | 找对策 |
| 实施、开展、推进 | 找对策 |

### 2.3 首尾句原则

**原理**：段落的首句和尾句常是段落主旨，要重点阅读。

#### 首句

- 段落开头的总结句
- 提出段落主题
- 引出下文内容

**示例**：
> "基层治理是国家治理的基石。"（首句，主旨）
> "近年来，各地加强基层治理..."（展开）

#### 尾句

- 段落结尾的总结句
- 总结段落内容
- 引出下一段

**示例**：
> "...因此，基层治理任重道远。"（尾句，总结）

#### 中间句

- 有时段落中间有承上启下的句子
- 也要重点阅读

### 2.4 观点句原则

**原理**：材料中引用的观点常是答题要点。

#### 观点词

| 观点词 | 示例 |
|--------|------|
| 表示 | 专家表示 |
| 认为 | 学者认为 |
| 指出 | 领导指出 |
| 强调 | 文件强调 |
| 提出 | 报告提出 |
| 说 | 主任说 |
| 建议议 | 代表建议 |

#### 观点来源

- 专家学者观点
- 政府官员观点
- 群众百姓观点
- 媒体评论观点
- 政策文件观点

**阅读技巧**：观点句常是答题要点，要重点标记。

## 三、符号批注法（李梦圆）

### 3.1 符号系统

| 符号 | 标记内容 | 示例 |
|------|---------|------|
| 波浪线 ～ | 问题 | ～资金不足～ |
| 双横线 ＝ | 原因 | ＝管理不善＝ |
| 方框 □ | 关键词 | □基础设施□ |
| 圆圈 ○ | 关联词 | ○但是○ |
| 三角 △ | 对策 | △加强监管△ |
| 问号 ？ | 疑问/不懂 | ？这段意思？ |
| 星号 * | 重点 | *核心要点* |

### 3.2 文字批注法

**方法**：在段落旁边写简短批注。

**示例**：
> "由于资金投入不足，导致基础设施建设滞后。"（旁边批注：问题1+原因1）

### 3.3 批注原则

- 及时批注：读到就标记
- 简洁明了：用符号或短词
- 分类标记：不同类型用不同符号
- 便于整理：批注要便于后续整理

## 四、高频词法

### 4.1 原理

材料中反复出现的词，往往是核心要点，要重点把握。

### 4.2 高频词类型

| 类型 | 示例 |
|------|------|
| 主题词 | "高质量发展"反复出现 |
| 问题词 | "不足""缺乏"反复出现 |
| 对策词 | "加强""完善"反复出现 |
| 概念词 | "新质生产力"反复出现 |

### 4.3 高频词应用

- **找主题**：高频词常是材料主题
- **找立意**：大作文立意常含高频词
- **找要点**：高频词附近常是要点

## 五、材料逻辑结构分析

### 5.1 材料常见结构

#### 总分结构

```
总（主题）→ 分（要点1、要点2、要点3）
```

**阅读**：先读总，再读分。

#### 转折结构

```
前半段（现象）→ 转折词 → 后半段（本质/问题）
```

**阅读**：重点读转折后。

#### 因果结构

```
原因 → 结果
```

**阅读**：原因和结果都是要点。

#### 并列结构

```
要点1 + 要点2 + 要点3
```

**阅读**：并列的都要找全。

### 5.2 段落间逻辑

| 关系 | 标志 |
|------|------|
| 递进 | 后段比前段更深 |
| 转折 | 后段与前段相反 |
| 因果 | 前段是因，后段是果 |
| 并列 | 各段平行 |

## 六、阅读速度提升

### 6.1 跳读法

**跳过**：
- 例子细节
- 数据罗列
- 重复内容

**保留**：
- 观点句
- 总结句
- 关键词附近

### 6.2 扫读法

**方法**：快速扫视，找关键词。

**适用**：第一遍通读，找标志词。

### 6.3 精读法

**方法**：逐句阅读，提炼要点。

**适用**：找到要点后，精读要点附近。

### 6.4 阅读顺序

1. 先看题目，明确找什么
2. 第一遍扫读，标记标志词
3. 第二遍精读，提炼要点
4. 整理要点，分类合并

## 七、不同题型的阅读策略

### 7.1 单一题阅读

**策略**：
- 带着明确目标读（找问题/原因/影响/对策）
- 重点找对应标志词
- 找全不漏

### 7.2 综合分析题阅读

**策略**：
- 全面阅读，理解材料逻辑
- 找观点、找原因、找影响、找对策
- 注意材料间的逻辑关系

### 7.3 提出对策题阅读

**策略**：
- 先找问题
- 再找原因
- 最后找对策（材料中的对策 + 反推对策）

### 7.4 公文写作题阅读

**策略**：
- 找发文目的
- 找主体内容
- 找发文对象
- 找发文单位

### 7.5 大作文阅读

**策略**：
- 找主题（高频词、观点句）
- 找立意（材料主旨）
- 找分论点（材料中的要点）
- 找素材（材料中的案例）

## 八、阅读常见问题

### 8.1 找不到要点

**原因**：
- 没审清题
- 没带目标读
- 标志词不熟

**对策**：
- 先审题再读
- 熟记标志词
- 多练找点

### 8.2 找漏要点

**原因**：
- 并列词没注意
- 跳读太多
- 只看首尾句

**对策**：
- 注意并列词
- 适度跳读
- 首尾句 + 中间句

### 8.3 找错要点

**原因**：
- 标志词判断错
- 把例子当要点
- 把现象当本质

**对策**：
- 准确判断标志词
- 区分例子和要点
- 透过现象看本质

### 8.4 读得太慢

**原因**：
- 逐字阅读
- 反复回读
- 没有方法

**对策**：
- 跳读 + 扫读 + 精读
- 带目标读
- 用方法提效

## 九、阅读训练方法

### 9.1 分阶段训练

#### 第一阶段：学方法

- 学习四原则
- 学习符号批注
- 学习标志词

#### 第二阶段：练找点

- 每天读1则材料
- 标记要点
- 对照参考答案

#### 第三阶段：练速度

- 限时阅读
- 1则材料5分钟
- 找全要点

### 9.2 训练素材

- 历年真题材料
- 半月谈文章
- 人民日报评论
- 政府工作报告

### 9.3 训练记录

- 记录找点准确率
- 记录阅读速度
- 分析漏点原因
- 定期回顾

## 十、配套速记口诀

- **四原则**：关联词、关键词、首尾句、观点句
- **关联词**：转折递进因果条件并列假设
- **关键词**：问题原因影响对策四类标志词
- **首尾句**：首句主旨，尾句总结
- **观点句**：专家官员群众媒体政策
- **符号批注**：波浪问题，双横原因，方框关键词，圆圈关联词，三角对策
- **高频词**：反复出现是重点
- **阅读三步**：审题、阅读、整理
- **阅读三法**：跳读、扫读、精读
- **训练三阶**：学方法、练找点、练速度
