# 综合分析题详解

综合分析题是申论中等难度题型，考查对材料内容的深度理解和逻辑分析能力。本文件整合李梦圆、站长、白鹭等方法。

---

## 一、题型认知

### 1.1 定义

综合分析题是要求考生对材料中的词句、观点、现象、比较等进行多角度分析，得出结论的题型。

### 1.2 特点

- 需要逻辑分析
- 答案有结构（是什么—为什么—怎么办）
- 分值较高（15–20分）
- 题量稳定（1题）
- 难度中等

### 1.3 题型分类

| 类型 | 常见问法 |
|------|---------|
| 词句理解 | "谈谈对...的理解""解释...的含义" |
| 观点分析 | "分析...的观点""评价...的说法" |
| 比较分析 | "比较...和...的异同" |
| 启示分析 | "分析...的启示""...给我们什么启示" |
| 现象分析 | "分析...现象""谈谈对...的认识" |

---

## 二、答题框架

### 2.1 通用框架（是什么—为什么—怎么办）

```
是什么（总述）：
  解释含义 / 表明观点 / 概括现象

为什么（分析）：
  原因分析 / 影响分析 / 利弊分析

怎么办（对策）：
  提出对策 / 总结展望
```

### 2.2 各题型框架

#### 词句理解题

```
是什么：解释词句含义
为什么：分析原因/表现
怎么办：提出对策/总结
```

#### 观点分析题

```
是什么：表明态度（认同/不认同/辩证）
为什么：分析理由
怎么办：提出对策/总结
```

#### 比较分析题

```
是什么：概括比较对象
为什么：分析异同
怎么办：提出对策/启示
```

#### 启示分析题

```
是什么：概括经验/做法
为什么：分析意义
怎么办：提出启示/对策
```

#### 现象分析题

```
是什么：概括现象
为什么：分析原因/影响
怎么办：提出对策
```

## 三、解题步骤

### 3.1 审题

**审什么**：
- 题型：哪种综合分析
- 对象：分析什么
- 范围：哪则材料
- 字数：多少字

### 3.2 阅读找点

**找什么**：
- 解释/观点/现象
- 原因/影响/利弊
- 对策/启示

**怎么找**：
- 关键词定位法
- 观点句重点读
- 关联词附近找

### 3.3 逻辑加工

**加工方法**：
- 按"是什么—为什么—怎么办"整理
- 同类合并
- 逻辑排序

### 3.4 规范书写

**书写格式**：
```
[总述] ...是指...。/ ...观点是...的。

[分析] 原因在于...。影响在于...。

[对策] 因此，要...。
```

## 四、名师技巧

### 4.1 李梦圆：是什么—为什么—怎么办框架

**特点**：框架清晰，易于上手。

**适用**：词句理解、现象分析。

### 4.2 站长：辩证分析

**特点**：辩证思维，分析透彻。

**方法**：
- 既要看正面，也要看反面
- 既要看现象，也要看本质
- 既要看当前，也要看长远

**适用**：观点分析、现象分析。

### 4.3 白鹭：深度分析

**特点**：分析有深度，适合冲高分。

**方法**：
- 多角度分析
- 挖掘本质
- 提升高度

**适用**：进阶提升。

## 五、真题示例

### 示例1：词句理解题

**题目**：谈谈对"乡村振兴，关键在人"的理解。（20分，不超过300字）

**材料**：（假设材料涉及乡村振兴的人才需求、人才外流问题、人才政策等）

**解析**：

**是什么**：
- "乡村振兴，关键在人"是指人才是乡村振兴的核心要素和根本保障。

**为什么**：
- 产业振兴需要人才：发展现代农业、特色产业，需要懂技术、会经营的人才。
- 文化振兴需要人才：传承乡土文化、培育文明乡风，需要文化人才。
- 治理振兴需要人才：提升基层治理能力，需要高素质的基层干部。
- 然而，当前农村面临人才外流、老龄化等问题。

**怎么办**：
- 加强人才培养，培育新型职业农民。
- 完善人才政策，吸引人才返乡。
- 优化人才环境，留住本土人才。

**参考答案**：
```
"乡村振兴，关键在人"是指人才是乡村振兴的核心要素和根本保障。

具体表现为：①产业振兴需要人才。发展现代农业、特色产业，需要懂技术、会经营的人才。②文化振兴需要人才。传承乡土文化、培育文明乡风，需要文化人才。③治理振兴需要人才。提升基层治理能力，需要高素质的基层干部。

然而，当前农村面临人才外流、老龄化等问题。

因此，要①加强人才培养，培育新型职业农民；②完善人才政策，吸引人才返乡；③优化人才环境，留住本土人才。
```

### 示例2：观点分析题

**题目**：有人认为"数字经济会取代传统经济"，请谈谈你的看法。（20分，不超过300字）

**解析**：

**是什么**：
- 这一观点是片面的。数字经济不会完全取代传统经济，而是促进传统经济转型升级。

**为什么**：
- 数字经济确实冲击了部分传统行业，如实体店受电商冲击。
- 但数字经济也赋能传统经济，如智能制造提升制造业效率。
- 两者是融合关系，不是取代关系。

**怎么办**：
- 推动数字技术与传统产业深度融合。
- 引导传统企业数字化转型。
- 保护传统行业就业，促进转岗培训。

**参考答案**：
```
这一观点是片面的。数字经济不会完全取代传统经济，而是促进传统经济转型升级。

一方面，数字经济确实冲击了部分传统行业，如实体店受电商冲击、传统媒体受新媒体影响。另一方面，数字经济也赋能传统经济，如智能制造提升制造业效率、数字农业提高农业效益。两者是融合关系，不是取代关系。

因此，要①推动数字技术与传统产业深度融合；②引导传统企业数字化转型；③保护传统行业就业，促进转岗培训。
```

### 示例3：比较分析题

**题目**：比较A市和B市在营商环境建设方面的异同。（20分，不超过300字）

**解析**：

**是什么**：
- A市侧重简政放权，B市侧重优化服务。

**为什么（异同分析）**：

相同点：
- 都推进"放管服"改革
- 都优化了审批流程
- 都减轻了企业负担

不同点：
- A市侧重简政放权，削减审批事项
- B市侧重优化服务，提升服务效率
- A市强调事前改革，B市强调事中事后服务

**怎么办**：
- 综合两地经验，既要简政放权，又要优化服务。

**参考答案**：
```
A市和B市在营商环境建设方面既有相同点，也有不同点。

相同点：①都推进"放管服"改革；②都优化了审批流程；③都减轻了企业负担。

不同点：①A市侧重简政放权，削减审批事项；B市侧重优化服务，提升服务效率。②A市强调事前改革，B市强调事中事后服务。

综合两地经验，营商环境建设既要简政放权，又要优化服务，二者相辅相成，缺一不可。
```

### 示例4：启示分析题

**题目**：根据给定资料，分析S市垃圾分类的成功经验给其他地区的启示。（20分，不超过300字）

**解析**：

**是什么**：
- S市垃圾分类的成功经验

**为什么（经验概括）**：
- 政府主导：成立领导小组，制定实施方案
- 宣传引导：开展宣传活动，提高居民意识
- 激励机制：建立积分奖励，调动积极性
- 设施完善：设置分类垃圾桶，配备运输车辆
- 监督考核：建立考核机制，定期通报

**怎么办（启示）**：
- 加强组织领导
- 强化宣传教育
- 建立激励机制
- 完善基础设施
- 健全监督考核

**参考答案**：
```
S市垃圾分类的成功经验给其他地区的启示主要有：

1. 加强组织领导。成立领导小组，制定实施方案，明确责任分工。
2. 强化宣传教育。开展宣传活动，提高居民分类意识。
3. 建立激励机制。推行积分奖励，调动居民参与积极性。
4. 完善基础设施。设置分类垃圾桶，配备专用运输车辆。
5. 健全监督考核。建立考核机制，定期通报，确保落实。
```

### 示例5：现象分析题

**题目**：分析"直播带货"现象。（20分，不超过300字）

**解析**：

**是什么**：
- "直播带货"是借助直播平台销售商品的新业态。

**为什么（原因+影响）**：

原因：
- 互联网技术发展
- 消费习惯转变
- 疫情催化

积极影响：
- 促进销售，带动经济
- 创造就业，新职业涌现
- 便利消费，提升体验

消极影响：
- 产品质量问题
- 虚假宣传
- 售后维权难

**怎么办**：
- 加强监管，规范市场
- 完善法规，保护权益
- 引导行业自律

**参考答案**：
```
"直播带货"是借助直播平台销售商品的新业态，其兴起源于互联网技术发展、消费习惯转变和疫情催化。

这一现象具有积极影响：①促进销售，带动经济发展；②创造就业，催生新职业；③便利消费，提升购物体验。但也存在消极影响：①产品质量问题频发；②虚假宣传时有发生；③售后维权困难。

因此，要①加强监管，规范市场秩序；②完善法规，保护消费者权益；③引导行业自律，促进健康发展。
```

## 六、易错点汇总

| 易错点 | 说明 | 对策 |
|-------|------|------|
| 无结构 | 不按框架答 | 用是什么为什么怎么办 |
| 漏分析 | 只答一方面 | 多角度分析 |
| 无对策 | 不提对策 | 最后提对策 |
| 主观 | 加自己观点 | 基于材料分析 |
| 照抄 | 照抄原文 | 提炼概括 |
| 超字 | 超过字数 | 精简语言 |

## 七、配套速记口诀

- **框架**：是什么—为什么—怎么办
- **题型**：词句理解、观点分析、比较分析、启示分析、现象分析
- **审题**：题型、对象、范围、字数
- **找点**：解释、原因、影响、对策
- **名师**：李梦圆框架，站长辩证，白鹭深度
- **易错**：无结构、漏分析、无对策、主观、照抄、超字
