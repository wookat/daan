# 大作文（申发论述）详解

大作文是申论分值最高的题型，考查立意、结构、论证、语言综合能力。本文件整合站长、白鹭、单淑玲、小马哥、飞扬等方法。

---

## 一、题型认知

### 1.1 定义

大作文是要求考生根据给定材料，围绕特定主题，撰写一篇议论文的题型，又称申发论述题。

### 1.2 特点

- 分值最高（35–40分）
- 字数最多（1000–1200字）
- 综合性强
- 拉开分差的关键
- 主观性较强

### 1.3 常见类型

| 类型 | 常见问法 |
|------|---------|
| 命题作文 | "以...为题" |
| 主题作文 | "围绕...主题" |
| 话题作文 | "结合...话题" |
| 材料作文 | "参考给定资料" |

## 二、立意方法

### 2.1 立意三步法

#### 第一步：题干关键词

**方法**：从题干中提取关键词。

**示例**：
- 题干："以'创新引领未来'为题"
- 关键词：创新、引领、未来
- 立意方向：创新的重要性

#### 第二步：材料主旨

**方法**：从材料中找主旨。

**找什么**：
- 高频词
- 观点句
- 首尾段
- 总结句

**示例**：
- 材料反复提到"高质量发展"
- 立意融入"高质量发展"

#### 第三步：自身积累

**方法**：结合自身积累深化立意。

**示例**：
- 立意：创新是引领发展的第一动力
- 深化：创新推动经济、破解难题、实现复兴

### 2.2 站长四步分析法

#### 第一步：是什么

**问**：这个主题是什么？

**示例**：
- 主题：创新
- 是什么：创新是推动发展的核心动力

#### 第二步：为什么

**问**：为什么需要这个？

**示例**：
- 为什么需要创新：经济发展需要、破解难题需要、民族复兴需要

#### 第三步：怎么办

**问**：怎么实现这个？

**示例**：
- 怎么创新：加强研发、培养人才、完善机制

#### 第四步：怎么样

**问**：实现了会怎样？

**示例**：
- 创新后会怎样：经济高质量发展、难题破解、民族复兴

### 2.3 白鹭拆题法

#### 拆题干

**方法**：把题干拆成几个关键词。

**示例**：
- 题干："创新引领未来"
- 拆为：创新 + 引领 + 未来

#### 找关键词

**方法**：分析每个关键词的含义。

**示例**：
- 创新：科技创新、制度创新、文化创新
- 引领：方向、动力、示范
- 未来：发展、复兴、进步

#### 定方向

**方法**：确定立意方向。

**示例**：
- 立意：创新是引领未来发展的核心动力

### 2.4 立意检验

**四个标准**：
- 正确：符合主流价值观
- 明确：观点鲜明
- 唯一：一篇文章一个总论点
- 深刻：有深度，不止于表面

## 三、结构方法

### 3.1 五段三分式（最推荐）

**结构**：
```
第一段：开头（150字）— 引出主题，提出总论点
第二段：分论点一（250字）
第三段：分论点二（250字）
第四段：分论点三（250字）
第五段：结尾（150字）— 总结升华
```

**总字数**：约1050字

**优点**：
- 结构清晰
- 易于掌握
- 适用80%的题目

### 3.2 六段三分式

**结构**：
```
第一段：开头（150字）
第二段：过渡段（100字）— 分析背景
第三段：分论点一（220字）
第四段：分论点二（220字）
第五段：分论点三（220字）
第六段：结尾（150字）
```

**适用**：需要更多分析空间的题目。

### 3.3 思辨型结构

**结构**：
```
第一段：开头 — 提出辩证观点
第二段：分析A的重要性
第三段：分析B的重要性
第四段：分析A与B的关系
第五段：结尾 — 总结
```

**适用**：辩证主题，如"发展与保护"。

### 3.4 递进式结构

**结构**：
```
第一段：开头
第二段：是什么
第三段：为什么
第四段：怎么办
第五段：结尾
```

**适用**：分析型题目。

## 四、分论点生成

### 4.1 拆题法（白鹭推荐）

**方法**：把总论点拆成几个方面。

**示例**：
- 总论点：创新引领未来
- 拆为：
  - 分论点1：创新引领经济发展
  - 分论点2：创新引领社会进步
  - 分论点3：创新引领民族复兴

### 4.2 就近法

**方法**：从材料中就近找分论点。

**示例**：
- 材料提到经济、社会、文化
- 分论点：
  - 分论点1：创新推动经济发展
  - 分论点2：创新推动社会进步
  - 分论点3：创新推动文化繁荣

### 4.3 概括法

**方法**：概括材料要点，提炼分论点。

**示例**：
- 材料要点：技术创新、制度创新、文化创新
- 分论点：
  - 分论点1：技术创新是核心
  - 分论点2：制度创新是保障
  - 分论点3：文化创新是灵魂

### 4.4 补充法

**方法**：材料不够，自己补充。

**示例**：
- 材料提到经济、社会
- 补充：生态
- 分论点：
  - 分论点1：创新推动经济发展
  - 分论点2：创新推动社会进步
  - 分论点3：创新推动生态改善

### 4.5 分论点要求

- 并列或递进：逻辑清晰
- 角度不同：不重复
- 服务总论点：围绕中心
- 对仗工整：语言优美

## 五、论证方法

### 5.1 举例论证

**方法**：用具体事例证明论点。

**示例**：
> 华为持续研发投入，突破芯片封锁，体现了创新的力量。

**要求**：
- 例子真实
- 例子典型
- 例子与论点相关
- 例子后要分析

### 5.2 道理论证

**方法**：用道理证明论点。

**示例**：
> 创新是发展的动力，没有创新就没有进步。历史证明，每一次重大创新都推动了社会进步。

**要求**：
- 道理正确
- 逻辑严密
- 有说服力

### 5.3 引用论证

**方法**：引用名言、政策、数据证明论点。

**示例**：
> 习近平总书记指出："创新是引领发展的第一动力。"

**要求**：
- 引用准确
- 引用相关
- 引用后要分析

### 5.4 对比论证

**方法**：通过对比证明论点。

**示例**：
> 创新的企业蓬勃发展，守旧的企业逐渐衰落，对比之下，创新的重要性不言而喻。

**要求**：
- 对比鲜明
- 对比相关
- 对比后要分析

### 5.5 比喻论证

**方法**：用比喻证明论点。

**示例**：
> 创新是发展的引擎，没有引擎，再好的车也无法前行。

**要求**：
- 比喻贴切
- 比喻易懂

## 六、开头结尾方法

### 6.1 开头方法

#### 背景引入式

> 当前，我国正处于[历史方位]，[主题]成为[意义]。然而，[问题]依然存在。面对新形势，我们必须[对策]，才能[目标]。

#### 名言引入式

> "[名言]"，这句话深刻揭示了[道理]。在[背景]的今天，[主题]更显重要。我们要[对策]，以[目标]。

#### 现象引入式

> 近年来，[现象]引发广泛关注。从[案例1]到[案例2]，[主题]已成为[意义]。这启示我们，[对策]。

#### 白鹭豹头式

**特点**：开头有力，吸引眼球。

**方法**：
- 用排比
- 用对比
- 用设问
- 用名言

### 6.2 结尾方法

#### 总结号召式

> [主题]关乎[意义]。让我们[号召1]，[号召2]，[号召3]，为[目标]而努力奋斗！

#### 展望未来式

> 展望未来，[前景]。只要我们[对策]，就一定能[目标]，[愿景]。

#### 引用升华式

> "[名言]"。[主题]之路任重道远，但只要我们[对策]，就一定能[目标]。

#### 白鹭凤尾式

**特点**：结尾有力，余味悠长。

**方法**：
- 用排比
- 用引用
- 用号召
- 用展望

## 七、名师技巧

### 7.1 站长：四步分析法 + 出题人视角

- 立意用四步分析法
- 站在出题人角度思考
- 辩证思维
- 论证符合现实需求

### 7.2 白鹭：拆题法 + 豹头凤尾

- 立意用拆题法
- 开头用豹头
- 结尾用凤尾
- 文采飞扬

### 7.3 单淑玲：大框架法

- 用大框架搭结构
- 抄材料（最多2-3句）
- 用框架填内容
- 备素材救急

### 7.4 小马哥：框架化

- 五段三分框架
- 填空式作答
- 易上手

### 7.5 飞扬：精准踩分 + 框架套用

- 框架套用求稳
- 精准踩分
- 实战导向

## 八、真题示例

### 示例1：命题作文

**题目**：以"创新引领未来"为题，写一篇议论文。（40分，1000–1200字）

**参考框架**：
```
标题：创新引领未来

开头（150字）：
  当前，世界正经历百年未有之大变局，科技创新成为国际竞争的关键。面对新形势，唯有创新才能赢得未来。

分论点一（250字）：创新是推动经济发展的核心动力。
  - 论证：举例华为、比亚迪等企业创新案例
  - 分析：创新提升竞争力，推动经济高质量发展

分论点二（250字）：创新是破解发展难题的关键钥匙。
  - 论证：举例卡脖子技术突破
  - 分析：创新解决发展瓶颈，实现自立自强

分论点三（250字）：创新是实现民族复兴的必由之路。
  - 论证：从历史角度分析
  - 分析：创新关系国家命运，决定民族未来

结尾（150字）：
  总结三个分论点，号召全社会重视创新，为实现中华民族伟大复兴而奋斗。
```

### 示例2：主题作文

**题目**：围绕"乡村振兴"主题，写一篇议论文。（40分，1000–1200字）

**参考框架**：
```
标题：全面推进乡村振兴 加快农业农村现代化

开头（150字）：
  民族要复兴，乡村必振兴。乡村振兴关系到农业农村现代化，关系到中华民族伟大复兴。必须全面推进乡村振兴，让农业强、农村美、农民富。

分论点一（250字）：产业振兴是乡村振兴的基础。
  - 论证：发展特色产业，延长产业链条
  - 分析：产业兴旺才能富民强村

分论点二（250字）：人才振兴是乡村振兴的关键。
  - 论证：培育本土人才，吸引外来人才
  - 分析：人才是乡村振兴的第一资源

分论点三（250字）：文化振兴是乡村振兴的灵魂。
  - 论证：传承乡土文化，培育文明乡风
  - 分析：文化振兴铸魂育人

结尾（150字）：
  乡村振兴是系统工程，需要产业、人才、文化协同推进。让我们共同努力，绘就乡村振兴壮美画卷。
```

### 示例3：辩证主题

**题目**：以"发展与保护"为题，写一篇议论文。（40分，1000–1200字）

**参考框架**（思辨型结构）：
```
标题：发展与保护

开头（150字）：
  发展与保护是一对矛盾统一体。有人认为发展就要牺牲环境，有人认为保护就要放弃发展。实际上，发展与保护相辅相成，缺一不可。

分论点一（250字）：发展是保护的基础。
  - 论证：经济发展为环境保护提供资金技术
  - 分析：没有发展，保护无从谈起

分论点二（250字）：保护是发展的前提。
  - 论证：环境破坏会制约发展
  - 分析：绿水青山就是金山银山

分论点三（250字）：发展与保护要统一。
  - 论证：绿色发展实现双赢
  - 分析：走可持续发展之路

结尾（150字）：
  发展与保护不是非此即彼的选择，而是相辅相成的统一。我们要坚持绿色发展，实现发展与保护的双赢。
```

## 九、易错点汇总

| 易错点 | 说明 | 对策 |
|-------|------|------|
| 立意偏题 | 没抓准主题 | 用立意三步法 |
| 结构混乱 | 没有清晰结构 | 用五段三分 |
| 分论点重复 | 角度相同 | 角度不同 |
| 论证空洞 | 只有论点无论证 | 举例 + 分析 |
| 抄材料多 | 大段抄材料 | 最多2-3句 |
| 语言口语 | 用口语 | 规范表达 |
| 字数不足 | 写不够字数 | 充实内容 |
| 字数超 | 超过字数 | 精简语言 |

## 十、配套速记口诀

- **立意三步**：题干关键词 + 材料主旨 + 自身积累
- **站长四步**：是什么—为什么—怎么办—怎么样
- **白鹭拆题**：拆题干、找关键词、定方向
- **立意检验**：正确、明确、唯一、深刻
- **结构**：五段三分最推荐
- **分论点四法**：拆题、就近、概括、补充
- **论证五法**：举例、道理、引用、对比、比喻
- **开头三式**：背景、名言、现象
- **结尾三式**：总结号召、展望未来、引用升华
- **名师**：站长立意，白鹭拆题润色，单淑玲框架，小马哥易上手，飞扬踩分
- **易错**：偏题、混乱、重复、空洞、抄多、口语、字数不足、超字
