# 申论规范表达与政府用语

本文件收录申论规范表达、政府工作用语、口语转规范表达，是申论写作的"语言库"。

---

## 一、规范表达原则

### 1.1 五化要求

| 要求 | 说明 | 示例 |
|------|------|------|
| 书面化 | 不用口语 | "搞"→"开展" |
| 规范化 | 用政府用语 | "想办法"→"研究对策" |
| 简洁化 | 不啰嗦 | "进行了研究讨论"→"研究讨论" |
| 逻辑化 | 有条理 | 用"一是、二是、三是" |
| 客观化 | 不主观 | "我觉得"→"据了解" |

### 1.2 口语转规范表达

| 口语 | 规范表达 |
|------|---------|
| 搞 | 开展、推进、实施 |
| 弄 | 推进、落实 |
| 弄好 | 落实到位、取得成效 |
| 想办法 | 研究对策、制定措施 |
| 出问题 | 出现问题、存在隐患 |
| 解决了 | 有效解决、妥善处理 |
| 做得好 | 成效显著、扎实推进 |
| 不够好 | 有待加强、仍需完善 |
| 很多 | 较多、众多、大量 |
| 很少 | 较少、稀缺、匮乏 |
| 越来越多 | 日益增多、持续增加 |
| 越来越好 | 持续改善、稳步提升 |
| 大家都 | 各界、各方、普遍 |
| 一起 | 共同、协同、合力 |
| 因为 | 由于、源于、基于 |
| 所以 | 因此、故、由此可见 |
| 但是 | 然而、但、不过 |
| 如果 | 若、倘若、假使 |

## 四、规范表达示例

### 4.1 单一题规范表达

**原文**："我们村的路太烂了，下雨天根本没法走，农产品运不出去，烂在地里。"

**规范表达**：
- 基础设施落后。道路状况差，影响农产品运输，造成经济损失。

### 4.2 对策题规范表达

**原文**："政府要多给钱，多派人，多搞培训。"

**规范表达**：
- 一是加大资金投入。增加财政支持，保障工作经费。
- 二是加强人才配备。充实工作人员，优化队伍结构。
- 三是强化培训教育。开展专业培训，提升能力素质。

### 4.3 大作文分论点规范表达

**主题**：乡村振兴

**分论点规范表达**：
- 产业振兴是乡村振兴的基础。要发展特色产业，延长产业链条，提升附加值。
- 人才振兴是乡村振兴的关键。要培育本土人才，吸引外来人才，留住青年人才。
- 文化振兴是乡村振兴的灵魂。要传承乡土文化，培育文明乡风，丰富精神生活。
- 生态振兴是乡村振兴的底色。要保护生态环境，发展绿色产业，建设美丽乡村。
- 组织振兴是乡村振兴的保障。要加强基层党建，完善治理体系，提升治理能力。

## 五、常见错误表达

### 5.1 口语化错误

| 错误 | 正确 |
|------|------|
| 搞好 | 落实好、推进好 |
| 弄好 | 落实到位 |
| 想办法 | 研究对策 |
| 出问题 | 出现问题 |
| 做得好 | 成效显著 |
| 不够好 | 有待加强 |

### 5.2 主观化错误

| 错误 | 正确 |
|------|------|
| 我觉得 | 据了解、分析表明 |
| 我认为 | 应当、需要 |
| 我建议 | 建议、应当 |
| 我相信 | 相信、预计 |

### 5.3 啰嗦错误

| 错误 | 正确 |
|------|------|
| 进行了研究讨论 | 研究讨论 |
| 做出了重要贡献 | 贡献重要 |
| 取得了显著成效 | 成效显著 |
| 开展了深入的工作 | 深入开展工作 |

## 六、配套速记口诀

- **五化**：书面化、规范化、简洁化、逻辑化、客观化
- **口语转规范**：搞→开展，弄→推进，想办法→研究对策
- **政府用语**：推进推动推行，加强强化健全，深化拓展拓宽，破解化解解决
- **动宾搭配**：汇聚力量，提升水平，推动发展，维护权益
- **避免错误**：不口语、不主观、不啰嗦
