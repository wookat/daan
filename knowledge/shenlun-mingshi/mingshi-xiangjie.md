# 七位申论名师方法详解

本文件详解七位名师的核心方法，包括方法原理、操作步骤、适用场景、示例。

---

## 一、李梦圆：关键词定位法

### 1.1 方法原理

申论答案 80% 在材料里，关键在于"找得到、提得准"。李梦圆的关键词定位法通过识别材料中的标志词，快速定位答案要点。

### 1.2 四类标志词

#### 问题词（找问题）

| 标志词 | 示例 |
|--------|------|
| 不足 | 资金不足、人员不足 |
| 缺乏 | 缺乏经验、缺乏人才 |
| 滞后 | 基础设施滞后 |
| 薄弱 | 基础薄弱、能力薄弱 |
| 缺失 | 制度缺失、监管缺失 |
| 欠缺 | 经验欠缺、能力欠缺 |
| 短板 | 短板明显 |
| 漏洞 | 制度漏洞、监管漏洞 |
| 困难 | 面临困难 |
| 问题 | 存在问题 |

#### 原因词（找原因）

| 标志词 | 示例 |
|--------|------|
| 因为 | 因为资金不足 |
| 由于 | 由于管理不善 |
| 源于 | 源于制度缺陷 |
| 缘于 | 缘于认识不足 |
| 归因于 | 归因于监管缺失 |
| 导致 | 导致问题发生 |
| 造成 | 造成损失 |
| 引发 | 引发矛盾 |
| 促使 | 促使问题暴露 |

#### 影响词（找影响）

| 标志词 | 示例 |
|--------|------|
| 有助于 | 有助于改善 |
| 有利于 | 有利于发展 |
| 促进了 | 促进了增长 |
| 推动了 | 推动了改革 |
| 阻碍了 | 阻碍了发展 |
| 违背了 | 违背了原则 |
| 损害了 | 损害了利益 |
| 影响了 | 影响了效果 |
| 制约了 | 制约了发展 |

#### 对策词（找做法）

| 标志词 | 示例 |
|--------|------|
| 推动 | 推动改革 |
| 完善 | 完善制度 |
| 促进 | 促进发展 |
| 加强 | 加强管理 |
| 建立 | 建立机制 |
| 健全 | 健全体系 |
| 落实 | 落实政策 |
| 强化 | 强化监管 |
| 推进 | 推进工作 |
| 实施 | 实施方案 |

### 1.3 符号批注法

| 符号 | 标记内容 |
|------|---------|
| 波浪线 | 问题 |
| 双横线 | 原因 |
| 方框 | 关键词 |
| 圆圈 | 关联词 |
| 三角 | 对策 |
| 问号 | 疑问/不懂 |

### 1.4 操作步骤

1. 审题，明确找什么（问题/原因/影响/对策）
2. 带着目标读材料
3. 遇到标志词，标记并提取要点
4. 整理要点，分类合并
5. 书写答案

### 1.5 适用场景

- 单一题（归纳概括）：最适用
- 综合分析题：适用
- 提出对策题：适用（找问题反推对策）
- 公文写作题：适用（找内容）
- 大作文：部分适用（找立意）

## 二、小马哥：框架化答题法

### 2.1 方法原理

申论答题有套路，掌握框架就能上手。小马哥的框架化答题法把每种题型拆成固定框架，填空式作答。

### 2.2 各题型框架

#### 单一题框架

```
总括句：...主要体现在以下几方面：
一是...。具体表现为...。
二是...。具体表现为...。
三是...。具体表现为...。
```

#### 综合分析题框架

```
总述：...是指...。
分析：原因在于...。影响在于...。
对策：因此，要...。
```

#### 提出对策题框架

```
针对...问题，提出以下对策：
一是...。具体措施...。
二是...。具体措施...。
三是...。具体措施...。
```

#### 公文写作框架

```
标题：关于...的（文种）

称呼：

  开头：背景/目的。
  主体：一是...；二是...；三是...。
  结尾：号召/要求。

落款
日期
```

#### 大作文框架

```
标题：...

开头：背景 + 论点。

分论点一：...。论证...。
分论点二：...。论证...。
分论点三：...。论证...。

结尾：总结 + 升华。
```

### 2.3 适用场景

- 零基础入门：最适用
- 时间紧：适用
- 大作文：适用（框架救急）

## 三、站长：四步分析法 + 出题人视角

### 3.1 方法原理

申论不是简单罗列要点，要站在出题人角度思考"他想得到什么答案"。站长的四步分析法用辩证思维分析问题，直击本质。

### 3.2 四步分析法

#### 第一步：是什么（定性）

- 明确概念内涵
- 判断性质属性
- 确定范围边界

#### 第二步：为什么（分析原因）

- 主观原因
- 客观原因
- 历史原因
- 现实原因

#### 第三步：怎么办（提出对策）

- 针对原因提对策
- 对策要具体可操作
- 对策要分类分层

#### 第四步：怎么样（展望影响）

- 积极影响
- 长远意义
- 价值升华

### 3.3 出题人视角

**核心问题**：出题人想通过这道题考查什么？

**分析方法**：
- 看题干关键词，判断考查方向
- 看材料主题，判断出题意图
- 看问题设置，判断能力要求

**示例**：
- 题目"概括基层治理存在的问题"
- 出题人意图：考查能否全面、准确提炼问题
- 答案应：分类全面、关键词准确、不漏点

### 3.4 辩证思维

**三大辩证关系**：
- 对立统一：问题与对策对立统一
- 质量互变：量变积累引起质变
- 否定之否定：螺旋式上升

**应用**：
- 分析问题要辩证，不偏激
- 提对策要全面，不片面
- 论证要辩证，有正有反

### 3.5 适用场景

- 大作文立意：最适用
- 综合分析题：适用
- 冲高分：适用

## 四、白鹭：60天扎马步 + 拆题法 + 豹头凤尾

### 4.1 方法原理

申论需要基本功，白鹭的"60天扎马步"强调循序渐进，通过60天系统训练打牢基础。拆题法精准定位立意，豹头凤尾提升文采。

### 4.2 60天扎马步训练法

#### 第一阶段（1–20天）：基本功

- 每天读1篇范文
- 每天积累5个金句
- 每天练1道单一题
- 每天写1段论证

#### 第二阶段（21–40天）：题型突破

- 每天练1道综合分析
- 每天练1道公文
- 每3天写1篇大作文
- 对比参考答案

#### 第三阶段（41–60天）：套题实战

- 每2天1套套题
- 限时训练
- 复盘错题
- 调整策略

### 4.3 拆题法（大作文立意）

#### 第一步：拆题干

- 提取题干关键词
- 分析关键词关系
- 判断立意方向

**示例**：
- 题干："以'创新引领未来'为题"
- 关键词：创新、引领、未来
- 关系：创新→引领→未来
- 方向：创新的重要性

#### 第二步：找关键词

- 题干关键词
- 材料高频词
- 材料观点词

#### 第三步：定方向

- 总论点：创新引领未来
- 分论点：创新引领经济发展、创新破解发展难题、创新实现民族复兴

### 4.4 豹头凤尾

#### 豹头（开头）

**特点**：简短有力，引人入胜

**三种开头法**：
1. 背景引入式：当前...，面对...，唯有...
2. 名言引入式："..."，这句话深刻揭示了...
3. 现象引入式：近年来...引发关注...

#### 凤尾（结尾）

**特点**：升华主题，余味悠长

**三种结尾法**：
1. 总结号召式：总结 + 号召
2. 展望未来式：展望 + 愿景
3. 引用升华式：引用 + 升华

### 4.5 分论点四法

#### 拆题法

- 拆题干关键词，每个关键词对应一个分论点

#### 就近法

- 从材料中就近找分论点

#### 概括法

- 概括材料内容，提炼分论点

#### 补充法

- 材料不够时，自己补充分论点

### 4.6 适用场景

- 大作文：最适用
- 公文写作：适用
- 进阶提升：适用

## 五、袁东：底层思维三维度 + 前置句提炼

### 5.1 方法原理

申论答题需要底层思维，袁东的"底层思维三维度"从初读、精读、输出三个维度系统训练。前置句提炼法让答案更有条理。

### 5.2 底层思维三维度

#### 第一维度：初读

**读什么**：
- 段首句：段落主旨
- 段尾句：段落总结
- 关联词：逻辑关系
- 关键词：要点标志
- 高频词：强调重点
- 主体：涉及对象

#### 第二维度：精读

**怎么读**：
- 逐句分析
- 提炼要点
- 判断性质（问题/原因/影响/对策）
- 标记位置

#### 第三维度：输出

**怎么写**：
- 分类整理
- 提炼前置句
- 规范表达
- 序号化

### 5.3 前置句提炼法

**原理**：每个要点前加一个概括性短句，让答案更有条理。

**示例**：

不加前置句：
```
一是社区工作人员只有5人，要服务2万居民。
二是工作人员能力参差不齐，法律问题处理不了。
三是经费靠财政拨款，来源单一。
```

加前置句：
```
一是人员配备不足。社区工作人员仅5人，需服务2万居民。
二是专业能力欠缺。工作人员能力参差不齐，难以处理复杂问题。
三是经费保障单一。过度依赖财政拨款，来源渠道单一。
```

**前置句要求**：
- 概括性强：能用一句话概括要点
- 对仗工整：各要点前置句结构一致
- 关键词突出：突出核心词

### 5.4 适用场景

- 单一题：最适用（前置句）
- 大作文结构：适用
- 系统学习：适用

## 六、单淑玲：大框架法

### 6.1 方法原理

大作文写不好，多数因为没框架。单淑玲的大框架法先搭框架再填内容，摆脱"无话可说"。

### 6.2 大框架结构

```
标题

开头（150字）：
  背景 + 论点

分论点一（250字）：
  分论点 + 论证（举例 + 分析）

分论点二（250字）：
  分论点 + 论证（举例 + 分析）

分论点三（250字）：
  分论点 + 论证（举例 + 分析）

结尾（150字）：
  总结 + 升华
```

### 6.3 摆脱"无话可说"三招

#### 第一招：抄材料（适度）

- 从材料中提炼观点
- 材料原句最多抄2–3句
- 抄宏观总结，不抄细节

#### 第二招：用框架

- 开头：背景 + 论点
- 分论点：论点 + 举例 + 分析
- 结尾：总结 + 升华

#### 第三招：备素材

- 准备5–10个通用案例
- 准备5–10句金句
- 准备3–5个分论点模板

### 6.4 适用场景

- 大作文：最适用
- 作文薄弱：适用
- 写不出：适用

## 七、飞扬：精准踩分 + 作文框架套用

### 7.1 方法原理

申论是踩分制，答到关键词就给分。飞扬的精准踩分法强调找全关键词，作文框架套用求稳分。

### 7.2 精准踩分法

#### 找关键词

- 问题词 → 找问题
- 原因词 → 找原因
- 影响词 → 找影响
- 对策词 → 找对策

#### 踩分技巧

1. **多答不同核心词**：宁可多答不漏
2. **关键词前置**：重要词放前面
3. **序号化**：①②③标清
4. **分类合并**：同类合并

#### 踩分示例

材料："由于资金投入不足，导致基础设施建设滞后，影响了居民生活质量。"

踩分：
- 原因：资金投入不足
- 问题：基础设施建设滞后
- 影响：影响居民生活质量

### 7.3 作文框架套用

**适用**：时间紧、求稳分

**框架**：
```
标题：...（题干给定或自拟）

开头：背景 + 论点（150字）

分论点一：...（250字）
  - 论点句
  - 举例（材料案例或积累案例）
  - 分析（案例说明什么）

分论点二：...（250字）
  - 论点句
  - 举例
  - 分析

分论点三：...（250字）
  - 论点句
  - 举例
  - 分析

结尾：总结 + 号召（150字）
```

### 7.4 套题实战法

#### 套题训练

- 每2天1套套题
- 限时180分钟
- 模拟考场环境

#### 班会笔记

- 记录模考共性问题
- 教师诊断与策略调整
- 针对性改进

### 7.5 适用场景

- 套题实战：最适用
- 冲刺稳分：适用
- 时间紧：适用

## 八、名师方法综合应用

### 8.1 单一题综合应用

```
李梦圆关键词法找点 → 袁东前置句提炼 → 站长分类思维 → 飞扬精准踩分
```

### 8.2 综合分析题综合应用

```
李梦圆是什么为什么怎么办框架 → 站长辩证分析 → 白鹭深度提升
```

### 8.3 大作文综合应用

```
站长四步分析法立意 → 白鹭拆题法定分论点 → 单淑玲大框架搭结构 → 白鹭豹头凤尾润色 → 飞扬精准踩分
```

### 8.4 公文写作综合应用

```
白鹭格式记忆 → 李梦圆内容找点 → 小马哥框架套用
```

## 九、配套速记口诀

- **李梦圆**：四类标志词（问题原因影响对策）+ 符号批注
- **小马哥**：五题型框架，填空式作答
- **站长**：四步分析（是什么为什么怎么办怎么样）+ 出题人视角 + 辩证思维
- **白鹭**：60天扎马步 + 拆题法 + 豹头凤尾 + 分论点四法
- **袁东**：底层思维三维度（初读精读输出）+ 前置句提炼
- **单淑玲**：大框架法 + 抄材料 + 用框架 + 备素材
- **飞扬**：精准踩分 + 作文框架套用 + 套题实战
- **综合应用**：找点用李梦圆，提炼用袁东，分类用站长，立意用站长白鹭，框架用单淑玲，润色用白鹭，踩分用飞扬
