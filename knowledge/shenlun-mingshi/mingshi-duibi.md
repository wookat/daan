# 七位申论名师方法论横向对比

本文件横向对比李梦圆、小马哥、站长、白鹭、袁东、单淑玲、飞扬七位申论名师的公开教学方法，帮助用户根据自身情况选对老师、取众家之长。

---

## 三、核心方法对比

### 3.1 材料阅读法对比

| 名师 | 核心方法 | 关键词 | 特点 |
|------|---------|--------|------|
| 李梦圆 | 关键词定位法 | 问题词、原因词、影响词、对策词 | 系统全面 |
| 袁东 | 底层思维三维度 | 段首句、段尾句、关联词、关键词、高频词、主体 | 多维度阅读 |
| 站长 | 出题人视角 | 出题人想得到什么答案 | 直击本质 |
| 白鹭 | 60天扎马步 | 基本功训练 | 循序渐进 |

### 3.2 大作文立意法对比

| 名师 | 立意方法 | 核心步骤 | 特点 |
|------|---------|---------|------|
| 站长 | 四步分析法 | 是什么—为什么—怎么办—怎么样 | 辩证深刻 |
| 白鹭 | 拆题法 | 拆题干—找关键词—定方向 | 精准定位 |
| 单淑玲 | 大框架法 | 题干 + 材料 + 积累 | 简洁实用 |
| 袁东 | 题干关键词法 | 提炼题干关键词 + 材料主旨 | 框架清晰 |

### 3.3 分论点生成法对比

| 名师 | 分论点方法 | 特点 |
|------|-----------|------|
| 白鹭 | 拆题法、就近法、概括法、补充法 | 四法灵活 |
| 站长 | 辩证法（正面/反面/辩证） | 有深度 |
| 单淑玲 | 并列法、递进法 | 简单易用 |
| 袁东 | 前置句提炼法 | 条理清晰 |

### 3.4 论证方法对比

| 名师 | 论证方法 | 特点 |
|------|---------|------|
| 站长 | 举例 + 道理 + 对比 + 辩证 | 全面 |
| 白鹭 | 豹头（开头）+ 凤尾（结尾）+ 举例 | 文采好 |
| 单淑玲 | 例证为主，道理为辅 | 易上手 |
| 飞扬 | 框架套用 + 精准踩分 | 稳分 |

## 四、名师优缺点分析

### 4.1 李梦圆

**优点**：
- 系统细致，适合零基础
- 关键词定位法实用
- 粉笔体系完整

**缺点**：
- 大作文相对薄弱
- 答案有时过于"标准"，缺乏深度

**适合**：零基础入门、单一题和综合分析薄弱者

### 4.2 小马哥

**优点**：
- 讲课生动有趣，能听进去
- 框架化，易上手
- 免费系统课资源多

**缺点**：
- 干货密度相对低
- 思路不够清晰
- 深度不足

**适合**：基础薄弱、需快速入门、喜欢轻松风格的考生

### 4.3 站长

**优点**：
- 深度思考，直击本质
- 出题人视角独特
- 辩证思维强

**缺点**：
- 入门门槛高
- 不适合零基础
- 需要一定积累

**适合**：有基础、冲高分、追求深度的考生

### 4.4 白鹭

**优点**：
- 文采飞扬，有深度
- 60天扎马步系统
- 拆题法精准

**缺点**：
- 对文字功底要求高
- 需要大量练习

**适合**：进阶提升、求深度、有一定文字基础的考生

### 4.5 袁东

**优点**：
- 框架清晰，逻辑严密
- 前置句提炼法实用
- 底层思维系统

**缺点**：
- 相对模板化
- 灵活性不足

**适合**：系统学习、求框架、需要条理的考生

### 4.6 单淑玲

**优点**：
- 简洁实用，可操作强
- 大框架法摆脱无话可说
- 适合作文困难户

**缺点**：
- 深度不足
- 文采一般

**适合**：作文薄弱、写不出、需要快速上手的考生

### 4.7 飞扬

**优点**：
- 实战导向，求稳分
- 精准踩分，效率高
- 套题训练系统

**缺点**：
- 模板化
- 缺乏深度

**适合**：实战冲刺、求稳分、时间紧的考生

## 五、选师决策树

### 5.1 按基础选

```
零基础 → 李梦圆（系统入门）+ 小马哥（轻松入门）
有基础 → 站长（冲高分）+ 白鹭（进阶）
冲刺阶段 → 飞扬（实战）+ 单淑玲（作文救急）
```

### 5.2 按薄弱题型选

```
单一题薄弱 → 李梦圆 + 袁东
综合分析薄弱 → 李梦圆 + 白鹭
对策题薄弱 → 袁东 + 小马哥
公文薄弱 → 白鹭 + 李梦圆
大作文薄弱 → 站长 + 白鹭 + 单淑玲
```

### 5.3 按目标分数选

```
目标 60 分 → 小马哥 + 单淑玲（基础分）
目标 70 分 → 李梦圆 + 袁东（中等分）
目标 80+ → 站长 + 白鹭（高分）
```

### 5.4 按学习风格选

```
喜欢系统 → 李梦圆 + 袁东
喜欢轻松 → 小马哥
喜欢深度 → 站长 + 白鹭
喜欢实战 → 飞扬
喜欢简洁 → 单淑玲
```

## 六、名师组合推荐

### 6.1 零基础入门组合

**李梦圆（小题）+ 小马哥（大作文）+ 单淑玲（作文救急）**

- 李梦圆打基础，学单一题和综合分析
- 小马哥学大作文框架
- 单淑玲救急，摆脱无话可说

### 6.2 进阶提升组合

**袁东（系统）+ 站长（深度）+ 白鹭（文采）**

- 袁东学框架和前置句
- 站长学立意和辩证
- 白鹭学文采和拆题

### 6.3 冲刺稳分组合

**飞扬（套题）+ 单淑玲（作文）+ 李梦圆（小题）**

- 飞扬练套题，精准踩分
- 单淑玲救作文
- 李梦圆巩固小题

### 6.4 全能组合

**李梦圆（小题）+ 站长（立意）+ 白鹭（文采）+ 飞扬（实战）**

- 小题稳分靠李梦圆
- 立意深刻靠站长
- 文采提升靠白鹭
- 实战训练靠飞扬

## 七、名师学习方法建议

### 7.1 不要盲目跟一个老师

申论没有标准答案，不可偏信某家。建议：
- 主跟 1–2 位老师学方法
- 对比多家答案，取其精华
- 形成自己的答题思路

### 7.2 先学方法再刷题

- 先跟老师学方法论（约 1–2 周）
- 再开始刷题（约 2–3 周）
- 最后套题实战（约 1–2 周）

### 7.3 动笔写比看课重要

申论一定要动笔写，不能因为怕麻烦就只看不练：
- 每天至少写 1 道小题
- 每周至少写 1 篇大作文
- 写完对照参考答案分析

### 7.4 建立错题本

申论错题本不是抄题，是抄遗漏的关键词：
- 每次做完题，把没写出来的关键词记下
- 分析为什么漏点
- 定期回顾
