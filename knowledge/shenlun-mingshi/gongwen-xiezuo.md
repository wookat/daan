# 公文写作题（贯彻执行题）详解

公文写作题考查公文格式与内容组织能力。本文件整合白鹭、李梦圆、小马哥等方法，覆盖15+文种。

---

## 一、题型认知

### 1.1 定义

公文写作题是要求考生根据材料，按照特定公文格式撰写文稿的题型，又称贯彻执行题。

### 1.2 特点

- 需要掌握格式
- 需要组织内容
- 分值较高（20–25分）
- 题量稳定（1–2题）
- 实用性强

### 1.3 常见文种

| 类别  | 文种             |
| --- | -------------- |
| 讲话类 | 讲话稿、发言稿、致辞     |
| 通知类 | 通知、通告、通报       |
| 倡议类 | 倡议书、公开信、建议书    |
| 汇报类 | 汇报提纲、工作总结、调研报告 |
| 新闻类 | 新闻稿、宣传稿、短评     |
| 其他  | 提纲、简报、方案、指导意见  |

## 二、公文格式

### 2.1 三种格式分类

#### 全格式

**要素**：标题 + 称呼（发文对象）+ 正文 + 落款（发文单位）+ 日期

**适用**：倡议书、公开信、通知、通报

**示例**：

```
关于开展XX的通知

各部门：
  （正文）

XX单位
XXXX年XX月XX日
```

#### 半格式

**要素**：标题 + 称呼 + 正文

**适用**：讲话稿、发言稿、致辞

**示例**：

```
在XX会议上的讲话

各位代表：
  （正文）
```

#### 文章类

**要素**：标题 + 正文

**适用**：新闻稿、短评、简报、提纲

**示例**：

```
XX工作取得显著成效

（正文）
```

### 2.3 标题写法

#### 通用标题

**格式**：关于 + 事由 + 的 + 文种

**示例**：

- 关于开展垃圾分类的倡议书
- 关于召开年度工作会议的通知
- 关于XX工作的汇报

#### 讲话类标题

**格式**：在 + 场合 + 的 + 讲话/发言

**示例**：

- 在乡村振兴动员大会上的讲话
- 在年度总结会上的发言

#### 新闻类标题

**格式**：主标题（可加副标题）

**示例**：

- XX工作取得显著成效
- 推进XX建设 提升XX水平

### 2.4 称呼写法

**格式**：发文对象 + 冒号

**示例**：

- 各部门：
- 各位居民：
- 各位代表：
- 尊敬的各位来宾：

### 2.5 落款写法

**格式**：发文单位 + 日期

**示例**：

```
XX社区居委会
XXXX年XX月XX日
```

## 三、正文结构

### 3.1 通用结构

```
开头（发文事由）：
  交代背景、目的、依据

主体（核心内容）：
  具体内容、要求、措施

结尾（号召/要求）：
  提出希望、要求、号召
```

### 3.2 各文种正文结构

#### 倡议书

```
开头：倡议背景 + 倡议目的
主体：倡议内容（分条列出）
结尾：号召参与
```

#### 通知

```
开头：通知事由
主体：通知事项（分条列出）
结尾：执行要求
```

#### 讲话稿

```
开头：问候 + 会议背景
主体：讲话内容（认识 + 做法 + 希望）
结尾：号召 + 致谢
```

#### 汇报提纲

```
开头：汇报背景
主体：工作情况（成绩 + 做法 + 问题）
结尾：下一步打算
```

#### 新闻稿

```
开头：新闻导语（时间地点人物事件）
主体：新闻详情
结尾：意义展望
```

## 四、解题步骤

### 4.1 审题

**审什么**：

- 文种：写什么公文
- 身份：以什么身份写
- 对象：写给谁看
- 目的：为什么写
- 字数：多少字

### 4.2 确定格式

**方法**：根据文种确定格式（全格式/半格式/文章类）。

### 4.3 找内容

**方法**：从材料中找相关内容。

**找什么**：

- 背景/事由
- 具体内容
- 要求/号召

### 4.4 组织内容

**方法**：按公文结构组织。

### 4.5 书写

**要求**：

- 格式完整
- 内容充实
- 语言规范
- 字数控制

## 五、名师技巧

### 5.1 白鹭：60天扎马步

**特点**：格式最全，记忆最牢。

**方法**：

- 每天记1个文种格式
- 60天记完所有文种
- 反复练习巩固

### 5.2 李梦圆：格式 + 内容系统

**特点**：系统讲解格式和内容。

**方法**：

- 先记格式
- 再找内容
- 格式 + 内容结合

### 5.3 小马哥：框架化

**特点**：框架化，易记。

**方法**：

- 每种文种一个框架
- 填空式作答
- 快速上手

## 六、真题示例

### 示例1：倡议书

**题目**：假如你是某社区工作人员，请写一份关于开展垃圾分类的倡议书。（25分，不超过500字）

**参考答案**：

```
关于开展垃圾分类的倡议书

居民朋友们：
  垃圾分类是改善人居环境、促进绿色发展的重要举措。为建设美丽社区，我们倡议：

  一、学习分类知识。了解可回收物、有害垃圾、厨余垃圾、其他垃圾的分类标准。
  二、养成分类习惯。在家中设置分类垃圾桶，按类别投放垃圾。
  三、参与宣传活动。积极向家人、邻居宣传垃圾分类知识。
  四、监督分类工作。对乱扔垃圾的行为进行劝导。

  让我们共同行动起来，从自身做起，从现在做起，为建设美丽社区贡献力量！

XX社区居委会
XXXX年XX月XX日
```

**解析**：

- 格式：全格式（标题 + 称呼 + 正文 + 落款 + 日期）
- 结构：开头（背景目的）+ 主体（倡议内容）+ 结尾（号召）
- 内容：4条倡议，分条列出

```
  四、会议内容：
    1. 总结年度工作；
    2. 部署下一年度任务；
    3. 表彰先进。
  五、会议要求：
    1. 请参会人员准时参加，不得缺席；
    2. 请提前准备本部门工作总结；
    3. 会议期间请将手机调至静音。

  特此通知。

XX单位办公室
XXXX年XX月XX日
```

### 示例3：讲话稿

**题目**：假如你是某村村主任，在乡村振兴动员大会上发言，请写一份讲话稿。（25分，不超过500字）

**参考答案**：

```
在乡村振兴动员大会上的讲话

各位村民：
  大家好！今天我们召开乡村振兴动员大会，目的是动员全村上下，共同推进乡村振兴。

  乡村振兴关系到我们每个人的切身利益。近年来，我们村虽然取得了一些发展，但与发达地区相比还有差距。我们要抓住乡村振兴的机遇，把我们的家乡建设得更好。

  下一步，我们将重点做好以下工作：
  一是发展特色产业。立足我们的资源优势，发展特色种植、乡村旅游。
  二是改善基础设施。修路、通水、通电，改善生产生活条件。
  三是整治人居环境。开展村庄清洁行动，建设美丽乡村。
  四是培育文明乡风。开展文化活动，移风易俗。

  乡村振兴，人人有责。希望大家积极参与，共同努力，把我们的村庄建设成为产业兴旺、生态宜居、乡风文明、治理有效、生活富裕的新农村！

  谢谢大家！
```

### 示例4：汇报提纲

**题目**：假如你是某部门工作人员，请写一份关于XX工作的汇报提纲。（25分，不超过500字）

**参考答案**：

```
关于XX工作的汇报提纲

一、工作背景
  为贯彻落实XX要求，我部门开展了XX工作。

二、主要做法
  1. 加强组织领导。成立工作领导小组，明确责任分工。
  2. 制定实施方案。细化工作措施，明确时间节点。
  3. 强化推进落实。定期调度，确保进度。
  4. 加强督促检查。开展专项督查，确保实效。

三、工作成效
  1. 完成了XX任务。
  2. 解决了XX问题。
  3. 取得了XX成效。

四、存在问题
  1. 部分工作推进缓慢。
  2. 经费保障不足。
  3. 协调配合有待加强。

五、下一步打算
  1. 加快工作进度。
  2. 争取经费支持。
  3. 加强部门协调。
```

## 八、配套速记口诀

- **三种格式**：全格式、半格式、文章类
- **全格式**：标题称呼正文落款日期
- **半格式**：标题称呼正文
- **文章类**：标题正文
- **正文结构**：开头事由、主体内容、结尾号召
- **15+文种**：讲话通知倡议汇报新闻
- **名师**：白鹭格式全，李梦圆系统，小马哥框架化
- **易错**：格式错、文种错、内容空、语言口语、超字、无逻辑
