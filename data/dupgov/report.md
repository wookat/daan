# 全库重复题簇治理报告（dupgov）

## 1. 范围与输入

- 输入：生产库快照（含 `dup_clusters` / `questions` / `question_simhash`），`dup_clusters` 中 `status='open'` 的 **4,160 簇 / 11,920 条成员记录**。
- 快照生成于判断推理/资料分析去重下架（data/audit1/）SQL 执行之后：簇内已 `disabled` 的成员（107 条）直接跳过，不重复下架。
- 全程离线完成，未执行任何生产 SQL，未修改后端代码。

## 2. 方法

1. **归一化与相似度**：复用 `backend/app/similarity.py` 的 `normalize` / `ngrams` / `jaccard`（题干+选项归一化、3-gram containment），在此基础上离线逐簇成对比对。
2. **逐对判定信号**：
   - 题干 containment、选项集合是否完全一致、答案字母是否一致；
   - **选项字母换序**（option permutation）：选项集合一致且"答案所指选项文本"一致 → 视为同一题；
   - **首尾差异检测**（tail_diff）：剥离公共前后缀后比较剩余片段，防止"共享大材料、仅问法/数字不同"的子题被误合（如资料分析同表多问、逻辑题同题干不同小问）；
   - **数字指纹**：合成模板题（工程/日历类）只有在题干数字序列完全一致时才允许合并，数字不同一律 not_dup；
   - **真题 PDF/OCR 变体**：is_real 且年份兼容、选项集合与答案文本一致、题干 containment≥0.90 → 视为同一真题的不同 PDF 导入。
3. **簇内分组**：以并查集（DSU）把确认重复的成对关系合并成组；每组按规则选保留版本，其余下架；组间互不影响（同簇可有多组、各留一题）。
4. **保留版本优先级**（与任务规则一致）：解析更完整（explanation+hs_explanation 长度）＞ 有来源/年份/地区（真题）＞ quality_score 更高 ＞ id 更小。答案冲突组先按"多数答案文本"过滤，再按上述优先级选保留版本。
5. **人工复核**：
   - 自动规则无法判定的 261 簇全部导出人工逐题查看（201 个边界簇 + 60 个大簇）；
   - **大簇（≥10 在架成员）全部逐题人工看**（60 簇，见 §5）；
   - 21 簇通过显式人工覆盖（manual overrides）单独裁定，理由逐簇记录在 clusters_decisions.jsonl 的 reason 字段。
6. **自动关闭**：簇内在架成员 ≤1 的簇（43 簇）自动关闭，不产生新下架。

## 3. 结果统计

- 决策记录：**4,160 簇全部有决策**（clusters_decisions.jsonl，每簇一行）。
- 动作分布：`resolve` 3,169 簇（含 43 簇 auto_close），`not_dup` 991 簇。
- 下架总数：**5,905 题**（全部为在架、非保留版本的确认重复题）。

## 4. 抽检记录（spot checks）

1. **真题多 PDF 变体（合并）**：C3080 两题均为"2025国考·下列与我国的立法权相关的说法"，仅卷种前缀不同（副省级/行政执法），选项、答案全同 → 保留解析更长的副省级版，下架另一条。类似的 2016–2023 国考/省考跨卷种重复共数百簇。
2. **材料共享子题（保留）**：C4012 两题共享同一逻辑题干（5 种茶叶装盒），但小问不同（"白茶在3号盒则黑茶在哪"vs"黑茶在5号盒则绿茶在哪"）→ not_dup 全部保留。资料分析 720 簇同理。
3. **合成模板题（数字一致才合并)**：C1（160 人簇，在架 57）：工程问题"施工队单独16天…先做7天…合作8天"，仅场景名词不同（孵化室/休息区/冷库…），数字、选项、答案完全一致 → 确认重复，留解析最完整一条，其余下架。C2 中 1 条数字不同的成员单独保留。
4. **日历模板题（数字不同即保留）**：C133/C164 等 7 簇按"日期+天数"数字指纹分组，仅数字完全一致的合并；C1599（39 天 vs 32 天）、C3281（11-11 vs 11-18）等 6 簇数字不同 → not_dup。
5. **图形推理大簇（保留）**：C4/C9/C12 题干均为"从所给四个选项中选择最合适的一个填入问号处（题干与选项见图）"样板文字，实际内容在图片中、来自不同年份/卷种 → 全部 not_dup，避免误伤。
6. **答案冲突裁定（人工）**：C3599 两条同题（刑责年龄），录入答案 A/B 冲突；按刑法第17条（已满14周岁贩卖毒品应负刑责、15岁过失致残不在八类之列）裁定 B 正确，保留 B 版本。C1336（借条签字保证责任）按 2021 担保制度司法解释裁定 D 正确。C2214 冲突无法离线裁定 → not_dup 保留双方，留给内容组复核。
7. **已 disabled 成员跳过**：43 簇因前轮下架后在架成员 ≤1 自动关闭，不产生新 SQL；所有 delist_ids 均校验为在架成员。
8. **实体不同（保留）**：C3724（鄱阳湖 vs 洞庭湖）、C1108（塔里木盆地/博斯腾湖/赛里木湖）选项相同但考察对象不同 → not_dup。

## 5. 大簇处理（≥10 在架成员，60 簇）

逐题人工查看后分三类：

- **合成模板刷题簇**（11 簇，shuliang）：同一工程问题换场景名词批量生成，数字/选项/答案全同 → 合并，各留 1 题；
- **真题多源导入簇**（46 簇，yanyu/changshi/shuliang）：同一真题被 10+ 份 PDF 重复导入（换行/OCR/卷种差异）→ 合并，按多数答案+解析完整度留 1 题；
- **图形推理样板簇**（3 簇，panduan）：题面在图片中，文本相同但题目不同 → not_dup 全部保留。

## 6. 校验

- clusters_decisions.jsonl：4,160 行，cluster_id 与快照 open 簇集合一一对应，无重复；
- 每个 keep_qid / delist_id 均属于对应簇且在架；keep 不在 delist 中；not_dup 无 delist；
- delist.sql：单事务（BEGIN/COMMIT），仅 `UPDATE questions SET disabled = 1`，共 5,905 个 id，幂等可重放；
- 未包含任何数据库文件或凭证。
