## T1 数量 8,983 题低分簇解析重写（data-report P1-1）

管线（轮1 T2 同款两阶段 + 本轮新增程序代入验算）：

1. **一审改写**（deepseek-chat, temp=0）：独立解题（不看标注答案），产出 ≤90 字成品解析（含解题步骤/公式依据、结构词、"故选X"收尾，禁元评论）+ 可 eval 的验算表达式 `expr`。
2. **二审独立作答**（deepseek-chat 独立调用，只解题不看一审）：答案须与标注一致。
3. **仲裁**（一审或二审与标注不一致的 662 题，grok-4.5 独立解题）：仲裁==标注则采用仲裁解析，否则**下架而非硬改**。
4. **程序代入验算**（Python）：expr 可求值且标注选项为数值的题，验算结果须命中标注选项；命中其他选项则下架。

| 结果 | 数量 |
|---|---|
| fix（一审/二审均==标注，用一审解析） | 8,316 |
| fix（仲裁 grok-4.5 挽回） | 659 |
| delist（三方不一致/验算命中他项/解析不可用） | 8（其中程序验算否决 4） |
| 程序验算 pass / 不适用 / 无法定论 | 8,298 / 562 / 115 |

**重打分效果（快照副本实测）**：原 <50 分 8,983 题 → 60-79 分 7,534、50-59 分 1,441、下架 8，**<50 清零**。50-59 段残余失分为缺考试元数据（exam_year/exam_region，自产题无此属性），非解析质量问题。

## T2 答案泄漏收口（data-report P1-3）

**T2a 干扰项长度均衡**：轮1 T2 改写题在架 10,541 题中 6,819 题（64.7%）正确项为最长选项（≥1.5×第二长）。LLM 扩写干扰项为与正确项长度相近的完整表述（保持错误性；**正确项内容与字母不动**），程序校验（键集不变/正确项逐字不变/无重复/不再泄漏/长度带宽）通过 5,780 题落盘；1,039 题两轮改写未过校验，记 `action=keep` 不硬改。**泄漏率 64.7% → 9.9%**。

**T2b 模板化题干抽样重写**：`…之X是`类模板题干 3,243 题，随机抽样 800（seed=42）改写为自然问句（不改选项与考点指向），改写后独立作答校验（答案不一致则弃用）：754 题落盘、46 题跳过。剩余约 2,443 题待下轮按同管线全量处理。

## T3 答案位置偏置重排（data-report P1-2）

范围：**仅 source='original' 自产题**（在架、答案∈A-D、四选项齐全无重复、解析"故选X"与标注一致者，共 97,101 题），真题保持原卷答案不动。方法：seed=4242 随机抽取超额字母的题，与目标字母**交换选项内容、同步改 answer、解析中字母引用同步轮换**（参照轮1时政重排做法），共移动 20,901 题。

## 遗留与建议

- T2a 未过校验的 1,039 题与 T2b 未抽样的 ~2,443 题模板题干，可下轮复跑同管线消化。
