# 言语理解（yanyu）三级考点打标报告

- 输入：`data/tag3/untagged_yanyu.jsonl`（26,545 题）
- 输出：`data/tag3/tagged_yanyu.jsonl`（26,545 行，id 与输入一一对应）
- 脚本：`data/tag3/scripts/tag_yanyu.py`（纯规则/关键词分类器，未调用任何外部 LLM API）
- 考点树：`devin/p5-integration` 分支 `backend/app/data/taxonomy.json` 的 yanyu 模块（18 个三级考点）

## 方法

1. 通读 taxonomy 中 yanyu 模块 6 组 18 个三级考点的 code/name/desc，明确边界。
2. 按题目 `submodule` 映射到 taxonomy 组，得到该题的候选考点集合（红线：输出 code 只能来自候选集合）。
   - submodule 缺失/为空/非法（约 5,400 题）时候选集合为全部 18 个考点，由规则自行判定。
   - 只有一个考点的组（标题填入→YY-BT-01、篇章阅读→YY-PZ-01）允许直接映射。
3. 从数据中归纳特征（提问句式、选项形态、解析结构词），写成规则；规则强命中给 0.85–0.95，弱命中/兜底给 0.6–0.8；判断不了输出 UNKNOWN（confidence=0）。
4. 每个考点随机抽样 ≥20 题（不足全抽）逐题人工核对，修正正确率不达标的规则后重跑，共迭代 4 轮。

## 规则清单（按判定顺序）

| 规则 | 判定 | 置信度 |
|---|---|---|
| 选项均为 ①②③… 序号排列 / 题干问"排列顺序" | YY-JB-01 语句排序 | 0.95 |
| 选项为"①和②之间"（句子放回原文位置） | YY-JB-02 | 0.8 |
| 题干含"标题" | YY-BT-01 | 0.95 |
| "接下来（最可能）讲述/说明…"、"这是一篇文章的开头" | YY-JB-03 接语选择 | 0.95 |
| 题干/题首/解析含 语病、病句、歧义、表述有误 | YY-JB-04 | 0.7–0.9 |
| 画线/加点/引号词句的 意思、含义、指代、寓意、作用 | YY-XJ-03 词句理解 | 0.9 |
| 填空题：明确"最恰当的一句"或选项为长句 | YY-JB-02 语句填空 | 0.9 |
| 填空题：多空（选项为多词组合） | YY-LJ-04 多空综合 | 0.9 |
| 填空题：单空且选项均为四字成语（或多数为四字） | YY-LJ-02 成语辨析 | 0.75–0.9 |
| 填空题：单空且选项为短实词（≤6 字） | YY-LJ-01 实词辨析 | 0.85 |
| 填空题：单空且选项为关联词 | YY-LJ-03 | 0.9 |
| 逻辑填空 submodule 下单空、选项为短语/短句（靠语境定空） | YY-LJ-03 语境对应 | 0.6–0.7 |
| "提取的关键词" | YY-ZX-04 | 0.85 |
| "意在说明/强调"、"目的是"、"想批评" 等意图句式 | YY-ZX-05 意图判断 | 0.9 |
| 主旨句式 + 解析行文分析段含转折结构提示 | YY-ZX-01 转折结构 | 0.7–0.8 |
| 主旨句式 + 解析行文分析段含对策结构提示 | YY-ZX-03 对策结构 | 0.7–0.8 |
| 主旨句式 + 解析行文分析段含因果结构提示 | YY-ZX-02 因果结构 | 0.7–0.8 |
| 其余主旨句式（总分/主题词/无结构提示） | YY-ZX-04 主题词与行文脉络 | 0.7 |
| "说法正确/不符/未提及/可知" 等细节判断句式 | YY-XJ-01 细节判断 | 0.85 |
| "属于/原因是/哪一种/可作为证据" 等定位查找句式 | YY-XJ-02 细节查找 | 0.75 |
| submodule 组内唯一考点（标题填入、篇章阅读） | 直接映射 | 0.85 |
| 其余 | UNKNOWN | 0 |

关键工程点：解析文本先截去"第二步/对比选项/拓展/故正确答案"之后的选项辨析段，只用行文分析段判定中心理解结构，避免选项讲解中顺带出现的"对策/因果"词污染判定（抽样中发现并修复）。
