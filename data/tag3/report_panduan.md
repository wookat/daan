# 判断推理（panduan）三级考点打标报告

## 1. 任务与数据

- 输入：`data/tag3/untagged_panduan.jsonl`，共 **23,568** 题。
- 输出：`data/tag3/tagged_panduan.jsonl`，每行 `{"id", "tag3", "confidence", "method"}`，与输入一一对应（ID 顺序、数量完全一致，已程序校验）。
- 考点树：`devin/p5-integration` 分支 `backend/app/data/taxonomy.json` 中 `panduan` 模块的 5 组 22 个三级考点（PD-TX-01~06、PD-DY-01~03、PD-LB-01~04、PD-LJ-01~07、PD-FX-01~02）。
- 方法：规则/关键词分类器（`data/tag3/scripts/tag_panduan.py`），特征词由人工阅读数据归纳；未调用任何外部付费 LLM API。所有行 `method="rule"`（规则即人工归纳的判定标准，逐考点人工抽样核对）。

## 2. 数据画像与预处理

按 `submodule` 分布：逻辑判断 10,505、定义判断 6,552、类比推理 5,373、分析推理 418、图形推理 259，另有数百行 submodule 为空/异常。观察到的关键数据问题：

1. **算术应用题混入**：`分析推理` 下混入大量小学算术应用题（如“一批灯笼椒按每筐15个正好分装232筐……”），不属于判断推理任何考点 → 一律 `UNKNOWN`（`is_math_contamination`，通过“数量×单价/分装/多少个”等模式 + 排除推理特征词识别）。
2. **submodule 缺失**：对空 submodule 行，先用题干/解析特征推断题型组（`guess_submodule`：定义句式→定义判断、“之于/相当于”→类比、削弱/加强/推出→逻辑、见图→图形、排序分配→分析），推断不出则 `UNKNOWN`。
3. **归属跨组的题**：`逻辑判断` 下的排序题、人员-任务匹配题，内容实为分析推理，分别归入 `PD-FX-02`、`PD-FX-01`（taxonomy 中排序/信息匹配仅在 PD-FX 组，且题目实质一致；未做整 submodule 无脑映射，仅按题干特征逐题命中）。
4. **解析缺失/与题干不符**：解析为空且题干无特征的行 → `UNKNOWN`。

## 3. 规则设计（摘要）

各 submodule 只允许输出该组（或第 2 节第 3 条所述跨组情形）的候选 code；判定不了输出 `UNKNOWN`（宁缺勿错）。

- **图形 PD-TX**：按“特殊规律(分类/汉字)→空间重构(折纸盒/三视图)→样式(叠加/去同存异)→属性(对称/曲直/开闭)→位置(平移/旋转/翻转)→数量(线条/笔画/交点/封闭区域)”的先特殊后一般顺序匹配。
- **定义 PD-DY**：提取“X 是指/：指”定义项；≥2 个定义项或“划分为…类”→ 多定义 PD-DY-02；“原则”类 → PD-DY-03；其余含“根据上述定义”→ 单定义 PD-DY-01。
- **类比 PD-LB**：以解析中最先出现的关系类别为准（解析惯例是先陈述题干关系再逐项排除）。四类特征词：
  - PD-LB-01 语义：近义/反义/比喻/象征/典故/词义；
  - PD-LB-02 逻辑：全同/并列/包容/种属/组成/交叉/反对/矛盾（taxonomy 中 PD-LB-02 为“全同、并列、包容、交叉”，反对/矛盾是并列关系的细分，归此）；
  - PD-LB-03 语法：主谓/动宾/偏正/造句；
  - PD-LB-04 对应：功能/原材料/工艺/时间顺序/场所/因果等对应。
  - **代入型解析**（“逐一代入选项”）：题干关系写在当选选项段落里，按选项分段后取“逻辑关系一致，当选/符合”段内的关系词，避免被排除项干扰。
- **逻辑 PD-LJ**：提问句式优先——削弱/质疑→06；前提/假设→07；加强/支持→05；解释矛盾现象→04；真假话/一真一假→02；条件句+“可以推出”或解析含逆否/充分必要→01；“可以推出/不能推出”无条件句→03（归纳推理）。
- **分析 PD-FX**：人员-任务/职业/地点分配（“分别负责/每人一项”）→01；名次/排序/位次约束→02。

置信度：强句式命中 0.9；解析关系词命中 0.85；较弱特征 0.6–0.8；UNKNOWN 为 0。

迭代中修正过的规则（修正后已重跑全量）：

1. 类比“代入型”解析原先取全局最先关系词，会被排除项的关系描述污染（如 PD-LB-03 误判）→ 改为按选项分段、取当选段落内关系词。
2. “反对关系”成语对比题最初误入语义关系 → 按 taxonomy 归 PD-LB-02（并列细分）。
3. “因果关系”解析原先误入 PD-LB-01/02 → 加入 PD-LB-04 特征词。
4. 图形规则原先“位置关系”等宽泛词优先级过高 → 调整为先特殊后一般。
5. 排序题“存粮最少的是”类未覆盖 → 补充“最(多|少)的是”。

## 6. UNKNOWN 说明（6.8%，低于 30% 阈值）

抽样显示 UNKNOWN 主要来源：

1. 混入的算术应用题（分析推理 submodule 下的分装/买卖/和差问题）——不属于判断推理任何考点，刻意不打标；
2. 解析为空且题干特征不足的题（含个别资料分析、常识题混入，如“平均每家综合医院……多少倍”）；
3. 图形推理中题面仅写“见图”且解析未点明规律类别的题；
4. 类比推理中解析用非标准表述（如“事物+功能+作用对象”变体未命中）的少量长尾题。

## 7. 校验

- 输出行数 = 输入行数 = 23,568；ID 顺序一致、无重复无缺失（脚本断言）。
- 全部非 UNKNOWN code ∈ taxonomy `panduan` 模块 22 个三级考点（脚本断言，0 违规）。
- confidence ∈ {0}∪[0.6,1]，UNKNOWN 恒为 0；method ∈ {rule}。
- `python3 -m py_compile scripts/tag_panduan.py` 通过。

cd data/tag3
python3 scripts/tag_panduan.py --untagged untagged_panduan.jsonl --out tagged_panduan.jsonl
