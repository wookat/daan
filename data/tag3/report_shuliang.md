# 数量关系（shuliang）三级考点打标报告

- 输入：`data/tag3/untagged_shuliang.jsonl`（39,212 题）
- 输出：`data/tag3/tagged_shuliang.jsonl`（39,212 行，与输入一一对应）
- 考点树：`devin/p5-integration` 分支 `backend/app/data/taxonomy.json` 的 shuliang 模块（14 个二级题型组、55 个三级考点）
- 脚本：`data/tag3/scripts/tag_shuliang.py`（纯规则，无任何外部 LLM API 调用）
- 复现：`python3 scripts/tag_shuliang.py untagged_shuliang.jsonl <taxonomy.json> tagged_shuliang.jsonl`

## 一、方法

两阶段规则判定：

1. **定组（二级题型）**：优先用 `submodule` 别名映射到 taxonomy 组（如 牛吃草问题→SL-GC、抽屉原理→SL-ZZ、钟表问题→SL-ZQ 等约 50 个别名）。`submodule` 缺失或为混杂值（数学运算/其他应用题）时，用题干+解析关键词判组（`detect_group`），其中解析里的"本题考查XX"标签优先。
2. **组内定三级考点**：每组一个 `topic_*` 函数，按特征强弱排序匹配（强特征 0.85–0.9，弱特征/默认 0.6–0.8）。数字推理另做了数值规律解析（`parse_seq`/`seq_kind`）：直接解析题干数列，程序判定等差/等比/递推/幂次/交叉。

输出的 code 全部经 taxonomy 有效性校验（无效即报错退出，实际运行 0 违规）。判定不了的输出 `UNKNOWN`、confidence 0。所有行 `method: "rule"`（最终标签全部由脚本规则产出；人工工作体现在从数据归纳规则与抽样核验，未对单题人工改写标签）。

### 防误判护栏（针对源数据 submodule 误标）

抽样发现源数据存在系统性 submodule 误标（如晨备清单题标成"行程问题"、数列题标成"容斥原理"、最值构造题标成"钟表问题"）。为此加入护栏，题面缺乏该组特征时宁可输出 UNKNOWN：

- 行程组：基础行程要求题面含速度/时速/里程要素，否则 UNKNOWN；
- 容斥组：解析"考查XX"非容斥、或题面为整除/数列/倍数语境时 UNKNOWN；
- 周期日期组：解析"考查XX"非周期/日期/钟表、约数倍数语境、年龄语境时 UNKNOWN；钟表须有钟表要素（时针/分针/快慢钟等）；
- 年龄组：题干无"岁/年龄"时 UNKNOWN。

## 三、抽样人工核验

- 抽样方式：程序随机抽样（`random.seed` 固定，seed=42/43/44 三轮），每个产出考点抽 ≥20 题（产出不足 20 的全抽），逐题人工阅读题干+解析核对。
- 共三轮：第 1 轮全量 55 个标签 1,010 题；发现问题修规则重跑后，第 2 轮针对受影响的 17 个标签复检 346 题；再修后第 3 轮复检 8 个标签 135 题。
- 第 1 轮发现并修复的问题（正确率 <95% 的规则均已修正并全量重跑）：
  - SL-RC 弱兜底把整除/数列题误判为三集合容斥（约 80%）→ 加护栏，删除 `RC-02` 默认兜底；
  - SL-XC-01 把误标为"行程问题"的晨备清单题收入基础行程（约 55%）→ 要求速度/里程要素；
  - SL-NL-01 收入了误标 submodule 的工程/推理题（85%）→ 要求题干含岁/年龄；
  - SL-ZQ-03 把无钟表要素的误标题收入钟表（80%）→ 要求钟表特征词；
  - SL-SZ-03/04 递推、幂次误判（85%/60%）→ 等差应用题优先规则、"平方/立方"排除"平方米/立方米"；
  - SL-QT-01 电梯楼层题、SL-ZQ-01 日期跨度题归类偏差 → 调整规则。

## 五、UNKNOWN 说明与已知数据问题

UNKNOWN（1,947，4.97%）主要构成：

1. **submodule 误标且题面与该组无关**：大量"开工晨备"式清单加总题被源数据标为"行程问题/容斥原理/钟表问题"等，按红线不强行归入该组考点，输出 UNKNOWN；
2. **非数量关系混入题**：少量判断推理/定义判断题混在数据里；
3. **候选清单内无合适考点**：如 sub=最值问题 但题目为普通比例/计税题；
4. **真困难题**：题面特征不足、解析缺失或乱码（OCR 噪声）。

其他已知源数据问题：部分题的 explanation 与题干不匹配（疑似串题）、公式图片 OCR 丢失导致解析残缺；判定以题干为准，受影响个题可能误判但抽样未见成规模影响。

设计取舍说明：sub=最值问题 的"至少要备多少（ceil 型保证够用）"合成题族数量大（约 1,900），候选仅限 SL-ZZ 三个考点，按"保证型最值"归入 SL-ZZ-01 并统一给弱置信 0.6，已在抽样中逐一核对一致性。
