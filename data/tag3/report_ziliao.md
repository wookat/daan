# 资料分析（ziliao）三级考点打标报告

- 输入：`data/tag3/untagged_ziliao.jsonl`（4445 题）
- 输出：`data/tag3/tagged_ziliao.jsonl`
- 考点树：`devin/p5-integration` 分支 `backend/app/data/taxonomy.json` 的 `ziliao` 模块（7 个题型组、29 个三级考点）
- 未调用任何外部付费 LLM API，全部由本地规则分类器 + 人工判定完成。

## 一、方法

1. **通读考点定义**：先读取 taxonomy 中资料分析 7 组（基期与现期 ZL-JQ、增长率 ZL-ZZL、增长量 ZL-ZZLL、比重 ZL-BZ、平均数与倍数 ZL-PJ、简单计算与读数 ZL-JS、综合分析 ZL-ZH）共 29 个三级考点的 code/name/desc，明确边界（如"增长量计算 vs 基期量计算"、"两期比重 vs 基期比重"）。
2. **规则分类器**（`scripts/tag_ziliao.py`）：
   - 提取提问句（题干最后一问，兼容 `【问题】`/`问题：`/`问：`/提问在材料前等多种格式）；
   - 按优先级依次匹配：综合分析句式 → 解析显式声明题型 → 年均类 → 间隔类 → 增长量句式 → 比重 → 平均数 → 倍数 → 增长率 → 基期/现期量 → 简单计算兜底；
   - 特征词均从数据中人工归纳（见下方规则清单）；
   - 用 taxonomy 的 group aliases 将 submodule 映射为候选考点簇，弱命中（confidence<0.65）且与候选簇冲突时降级为 UNKNOWN（宁缺勿错）；
   - 所有输出 code 均校验存在于 taxonomy，杜绝编造。
3. **人工抽样验证**：每个三级考点随机抽 ≥20 题（不足 20 全抽）逐题核对，多轮迭代（详见第三节）。
4. **规则盲区人工判定**：规则判不了的 73 题逐题人工判定，其中 67 题可确定考点（写入 `scripts/manual_overrides_ziliao.json`，`method="manual"`），6 题为混入的判断推理/数学运算题，保持 UNKNOWN。

## 二、规则清单（摘要）

| 优先级 | 特征 | 判定 |
|---|---|---|
| 1 | 提问含"说法正确/错误的是、能够推出、无法推出、不正确的是、不准确的是、发生变化的是"等 | ZL-ZH-01 (0.95) |
| 2 | 解析显式声明（"本题考查/可判定本题为 + 间隔基期/两期比重/增长量比较/基期倍数/比值计算…"） | 对应 code (0.92) |
| 3 | submodule=综合分析 且非判断句式 | ZL-ZH-02 (0.6) |
| 4 | 提问含"年均增长率/年均增速/年均复合增长" | ZL-ZZL-03 (0.9) |
| 5 | 提问含"年均增长量/平均每年增长(增加/减少)/年均增加" | ZL-ZZLL-04 (0.85) |
| 6 | 含"隔年/间隔增长"：按问量/率/值分流 | ZL-ZZLL-03 / ZL-ZZL-02 / ZL-JQ-02 |
| 7 | "（比上年）增加/减少了(约)多少 + 单位"（排除倍/百分点/百分之） | ZL-ZZLL-01 (0.9)，含年均则 ZL-ZZLL-04 |
| 8 | 比重/占比类：与上年比较升降/百分点/变化趋势→ZL-BZ-03；提问年份早于材料现期→ZL-BZ-02；否则→ZL-BZ-01 |
| 9 | 平均数类（平均每/人均/亩产/月均…，排除"倍/之比"）：问增长率→ZL-PJ-03；两期比较→ZL-PJ-04；基期→ZL-PJ-02；否则→ZL-PJ-01 |
| 10 | 倍数类（几倍/多少倍/之比约为/翻番）：提问年份早于材料现期→ZL-PJ-06；否则→ZL-PJ-05 |
| 11 | 增长量关键词（增长量/净增/增加额/多多少）：比较类→ZL-ZZLL-02；否则→ZL-ZZLL-01 |
| 12 | 增长率关键词（增长率/增速/增幅/降幅…）：最快最慢/排序→ZL-ZZL-05；混合→ZL-ZZL-04；否则→ZL-ZZL-01 |
| 13 | 基期类（提问年份 < 材料最新年份，或含"上年/去年"）：和差→ZL-JQ-03；比较排序→ZL-JQ-04；否则→ZL-JQ-01；预计/将达到→ZL-JQ-05 |
| 14 | 简单计算类：之和/之差→ZL-JS-02；排序/最大最小→ZL-JS-03；读数→ZL-JS-01；submodule=简单计算的兜底按解析算式分流（含%→ZL-BZ-01，纯加减→ZL-JS-02） |

年份判断：`_asks_earlier_year` 取材料中最大年份为现期，提问年份全部小于现期则视为基期问题。

## 三、人工抽样验证

每轮对全部已分配考点各随机抽 ≥20 题（不足全抽）逐题人工核对：

- **第 1 轮（seed=42）**：发现"比上年增加多少亿元"类增长量题被误判为 ZL-JQ-01（基期量），约 15% 误判 → 新增规则 7（增长量句式提前）后重跑。
- **第 2 轮（seed=7）**：发现 (a) 解析显式声明题型未被利用（"该题是/可判断本题是"句式未匹配）；(b) 部分基期倍数题（问 2015 年、材料 2016 年）被判为现期倍数 ZL-PJ-05；(c) "不准确的是/根据资料可知"未识别为综合分析；(d) submodule=简单计算 的"比重求量"题被误判 ZL-JS-01 → 逐项修正规则后重跑。
- **第 3 轮（seed=99/2024）**：发现 (a) "人均…多少倍"被平均数规则抢占（应为倍数类）；(b) "不超过…数量"误入 ZL-JQ-04；(c) 提问句+①②③列表格式的综合分析题漏判 → 修正后重跑。
- **第 4 轮（seed=777，最终轮）**：全部 27 个非空考点抽样逐题核对，**每个考点正确率均 ≥95%**（大簇 ZL-JQ-01 / ZL-BZ-01 / ZL-ZH-01 / ZL-ZZLL-01 / ZL-ZZL-01 各抽 20 题全部正确；小簇全抽核对，仅个别边界题存在归类争议，如"比率上升多少"归 ZL-JS-02 与"两期比重"边界，均属可辩护判定）。

整体抽样正确率（第 4 轮，共核对约 320 题）：**≈98%**。
