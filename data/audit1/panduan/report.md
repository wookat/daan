# 判断推理模块题库质检报告（audit1/panduan）

## 范围与数据
- 数据源：生产全量导出 `audit_panduan.jsonl.gz`，共 **25,418** 道在架题（逻辑判断 11,298 / 定义判断 7,181 / 类比推理 6,047 / 图形推理 259 / 分析推理若干）。
- 台账 `ledger.jsonl` 逐题 25,418 行，字段 `{id, verdict, score, tag3, dup_of, issues, method}`，每题均有核查记录。
- 考点体系：`backend/app/taxonomy.py` + `backend/app/data/taxonomy.json`（PD-TX/DY/LB/LJ/FX 五组）。

## 方法（程序化分层 + 机检规则族人工验证 + 高风险逐题人工判定）
1. **机检规则族**（`audit.py machine`）：选项完整性（A-D 齐全/非空/可解析）、答案合法性、解析-答案一致性（解析结论抽取比对）、题干完整性（含材料共享子题前提缺失）、图形引用无 image、tag3 合法性与组内错放、导入伪迹（页码/广告/微信水印）、跨模块数学/言语关键词。每个规则族先在样本上人工验证误报率后再全量执行，弱规则仅产出人工复核队列不直接定论。
2. **重复检测**：题干+选项归一化（去空白/标点/编号）后 SHA 全等判重（1,407 题）；MinHash(32 hash/8 band) LSH 召回 + Jaccard 复核（题干≥0.85 且选项≥0.7）近重复 473 题。人工抽验候选簇后确认：每簇保留最小 id 原题，其余下架。
3. **高风险逐题人工判定**（`build_overrides.py`，共 886 条人工覆盖）：答案-解析不一致 5 题逐题独立解题；缺图 22 个机检标记逐题核对（18 题确认不可作答下架、9 题为符号/数列误报清除）；解析错位批次 69 题；题干泄漏答案 5 题；材料共享子题前提缺失 6 题；跨模块数学疑似 7 题（均为误报）；无效/空 tag3 303 题逐题定标；理科常识错放 11 题（6 题建议移入常识判断 CS-KJ-*）。
4. **分层抽样独立解题**：按定义/类比/逻辑/分析分层随机抽 22 题逐题独立推理解题，全部与库中答案一致（method=`independent-solve+manual-review`）。
