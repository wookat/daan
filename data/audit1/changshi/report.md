# 常识判断模块题库质检报告（audit1/changshi）
- 覆盖范围：全量 36431 道在架题，逐题核查，台账 `ledger.jsonl` 每题一条记录。
## 一、方法
1. **机检五项**（`mcheck`，全量）：解析结论字母 vs answer 一致性、解析完整性、选项完整性（空/重复/串题/截断/解析失败）、题干完整性（缺图表引用、下划线丢失、OCR 残缺、广告页码噪声）、tag3 三级考点有效性。机检规则经多轮人工抽样迭代修正误报（如“图中国”误判缺图、冒号结尾误判截断等），每族规则均有人工验证记录。
2. **独立解题核实答案**（不只信解析）：约 18,137 题在外部 API 可用期间完成双模型盲解（`llm-solve`，分歧题以第二模型仲裁并人工复核）；其余 **18,294 题按老板要求由人工逐条读题、独立解题后与库内答案比对**（`manual-review`，分批推进，每题有台账记录），共 354 题人工解题与库内答案分歧，全部逐题回读完整原文裁定并写明理由（见 `manual_overrides`，其中确认库内答案缺陷者出修复 SQL，人工误判者维持原答案并记录理由）。
3. **高风险题逐题人工裁定**：机检高风险题（答案/解析冲突、结构硬伤、疑似缺图等）逐题人工核查并形成人工覆盖裁定记录。
4. **重复题筛选**：文本归一化（去噪声/标点/广告）+ 3-gram shingle + SimHash 分桶 + SequenceMatcher 相似度聚类，得候选簇后**全部人工确认**：低相似簇逐题比对题干与选项（确认 1 个假阳性簇：376266 嵩山 vs 426344 华山，非重复，移出）；23 个答案冲突簇逐簇独立解题裁定正确答案并选保留题；同答案簇按质量（人工覆盖状态、真题标记、机检缺陷、噪声、解析完整度）选保留题。
5. **tag3 定标**：无效/UNKNOWN 的 tag3 先经模型建议+规则校验定标，剩余 267 题人工逐题定标至三级考点，最终全部在架题 tag3 有效。
6. **打分**：每题 0-100 综合分（解析完整度/结论明确性、题干与选项完整性、答案可靠性、噪声与规范性扣分制）。
